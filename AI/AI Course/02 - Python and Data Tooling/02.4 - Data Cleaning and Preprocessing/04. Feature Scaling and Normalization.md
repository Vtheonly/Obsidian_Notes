# 4. Feature Scaling and Normalization

> **Prerequisites:** [[03. Outlier Detection and Treatment Methods]] (Z-score, IQR)
> **Connections:** [[01. K-Means Clustering]], [[01. K-Nearest Neighbors (KNN) - Comprehensive]] (algorithms that require scaling), [[01. Fundamentals of Neural Networks]] (NN inputs)

Machine Learning algorithms that calculate **distance** (e.g., KNN, K-Means, SVM) or use **gradient descent** (Neural Networks, Logistic Regression) perform poorly if features have different scales.

- *Example:* Age (0-100) vs. Salary (20,000 - 100,000). Without scaling, Salary will dominate every distance calculation simply because the numbers are bigger — even if Age is more predictive.

---

## 4.1 Standardization (Z-Score Normalization)

Rescales data to have **Mean = 0** and **Standard Deviation = 1**.

- **Formula:** $z = \frac{x - \mu}{\sigma}$
- **Use Case:** When algorithms assume Gaussian distribution (Logistic Regression, SVM, Neural Networks). Preserves outliers (they remain far from the mean, just on a standardized scale).
- **When NOT to use:** For tree-based models (Decision Trees, Random Forests, XGBoost) — trees split on feature values directly and are scale-invariant.

```python
from sklearn.preprocessing import StandardScaler
scaler = StandardScaler()
df_scaled = scaler.fit_transform(df[['Age', 'Salary']])
```

## 4.2 Min-Max Normalization

Rescales data to a fixed range, usually **[0, 1]**.

- **Formula:** $x_{norm} = \frac{x - x_{min}}{x_{max} - x_{min}}$
- **Use Case:** Image processing (pixels 0-255), Neural Networks input layers (sigmoid/tanh activations work best with [0,1] or [-1,1] inputs). Sensitive to outliers (a single extreme value compresses the rest).
- **When NOT to use:** Same as standardization — tree-based models do not need it.

```python
from sklearn.preprocessing import MinMaxScaler
scaler = MinMaxScaler()
df_norm = scaler.fit_transform(df[['Age', 'Salary']])
```

## 4.3 Robust Scaler

Scales data using **Median** and **IQR** (Interquartile Range), instead of Mean and Std.

- **Formula:** $x_{robust} = \frac{x - \text{median}}{Q3 - Q1}$
- **Use Case:** When the data contains significant outliers that you don't want to remove but also don't want influencing the scale. The median and IQR are robust to outliers (unlike the mean and std).

```python
from sklearn.preprocessing import RobustScaler
scaler = RobustScaler()
df_robust = scaler.fit_transform(df[['Age', 'Salary']])
```

## 4.4 MaxAbs Scaler

Scales data to **[-1, 1]** by dividing by the maximum absolute value. Does not shift/center the data.

- **Formula:** $x_{maxabs} = \frac{x}{\max(|x|)}$
- **Use Case:** Sparse data (CSR matrices) — preserves sparsity (zeros stay zeros). Centering would destroy sparsity.

```python
from sklearn.preprocessing import MaxAbsScaler
scaler = MaxAbsScaler()
df_maxabs = scaler.fit_transform(df[['Age', 'Salary']])
```

## 4.5 Power Transformer (Box-Cox, Yeo-Johnson)

Applies a parametric transformation to make the data **more Gaussian-like**. Useful for skewed features.

- **Box-Cox:** requires strictly positive data.
- **Yeo-Johnson:** handles positive and negative data.
- **Use Case:** When a feature is highly skewed and the downstream algorithm assumes Gaussianity (linear models, Gaussian processes).

```python
from sklearn.preprocessing import PowerTransformer
scaler = PowerTransformer(method='yeo-johnson')  # or 'box-cox'
df_power = scaler.fit_transform(df[['Age', 'Salary']])
```

## 4.6 Quantile Transformer

Transforms features to follow a **uniform** or **normal** distribution, by mapping each value to its quantile.

- **Use Case:** When you want to remove all distributional structure (heavy tails, skewness) and produce a uniform/normal output. Robust to outliers.
- **Caveat:** Distorts correlations and distances — the transformation is non-linear.

```python
from sklearn.preprocessing import QuantileTransformer
scaler = QuantileTransformer(output_distribution='normal')
df_quant = scaler.fit_transform(df[['Age', 'Salary']])
```

---

## Comparison Table

| Scaler | Output Range | Robust to Outliers? | Preserves Sparsity? | When to Use |
| :--- | :--- | :--- | :--- | :--- |
| StandardScaler | Unbounded (mean 0, std 1) | No | No | Default for most ML; Gaussian-assuming models |
| MinMaxScaler | [0, 1] | No | No | NN inputs, image pixels |
| RobustScaler | Unbounded | **Yes** | No | Data with significant outliers |
| MaxAbsScaler | [-1, 1] | No | **Yes** | Sparse data |
| PowerTransformer | Unbounded | Partially | No | Skewed data, Gaussian-assuming models |
| QuantileTransformer | [0, 1] or unbounded | **Yes** | No | Heavy-tailed data, want uniform/normal output |

---

## The Critical Practice: Fit on Train, Transform Both

> [!DANGER] Data Leakage Warning
> **Never fit the scaler on the full dataset.** If you fit on train + test together, the scaler's statistics (mean, std, min, max) are influenced by the test data — this is **data leakage**, and it inflates your test performance.

**Correct pattern:**
```python
scaler = StandardScaler()
X_train_scaled = scaler.fit_transform(X_train)  # Fit on train ONLY
X_test_scaled = scaler.transform(X_test)        # Transform test with train's statistics
```

Or, better, use a **Pipeline** to guarantee no leakage:
```python
from sklearn.pipeline import Pipeline
pipe = Pipeline([
    ('scaler', StandardScaler()),
    ('model', LogisticRegression())
])
pipe.fit(X_train, y_train)  # Scaler fits on train only, automatically
pipe.score(X_test, y_test)
```

This is the single most important preprocessing practice. See [[07. Preprocessing Pipelines and Train-Test Hygiene]] for the full treatment.

---

## When You Do NOT Need to Scale

**Tree-based models** (Decision Trees, Random Forests, XGBoost, LightGBM, CatBoost) are **scale-invariant**. They split on feature values directly (`if Age > 30`), and the threshold is chosen from the data — the scale does not matter. Scaling before tree-based models is wasted computation.

**Naive Bayes** is also largely scale-invariant (it works on probabilities, not distances).

For all other models (KNN, K-Means, SVM, Logistic Regression, Neural Networks, PCA), scaling is essential.

---

## What you should walk away with

1. **StandardScaler** (Z-score): default for most ML; mean 0, std 1; not robust to outliers.
2. **MinMaxScaler**: [0, 1] range; for NN inputs and image pixels; sensitive to outliers.
3. **RobustScaler**: median + IQR; robust to outliers.
4. **MaxAbsScaler**: [-1, 1]; preserves sparsity.
5. **PowerTransformer / QuantileTransformer**: for skewed or heavy-tailed data.
6. **Always fit on train, transform both** — or use a Pipeline to guarantee no leakage.
7. **Tree-based models do not need scaling** — they are scale-invariant.
