# 00. Global Index — Image Processing

This is your roadmap for the Image Processing chapter. The chapter covers classical digital image processing from first principles, with bridges to the deep learning approaches that have extended (and in some cases replaced) the classical methods.

---

## How to read this chapter

The chapter is organized sequentially: fundamentals → intensity transforms → spatial filtering → frequency domain → morphology and segmentation. Each section builds on the previous. If you are new to image processing, read linearly. If you are looking for a specific topic, use the index below.

**The key connection:** classical image processing and CNNs are the same operation (convolution) — the difference is whether the kernel is designed by a human or learned from data. See [[5.6 The Classical-to-Deep Bridge]] for the explicit connection.

## Connection to the rest of the vault

- **CNNs (Chapter 05):** classical filters (Sobel, Gabor) are mathematically identical to CNN first-layer filters. See [[5.6 The Classical-to-Deep Bridge]] and [[03. The Bridge - From Basic Convolution to Learned Weights]].
- **Advanced CNN operators (Ch. 05.07):** dilated convolutions (DeepLab), transposed convolutions (U-Net decoders) build on the classical foundations here.
- **Modern CV tasks (Ch. 05.08):** object detection and segmentation use the metrics (IoU, mAP, Dice) from [[05. Computer Vision Metrics - IoU, mAP, Dice]] and the architectures (U-Net, FCN) previewed in [[5.5 Deep Learning for Imaging]].
- **Vision Transformers (Ch. 08.3):** ViT's patch embedding is the deep-learning analog of the block-based processing used in JPEG and classical image analysis.
- **Evaluation metrics (Ch. 03.6):** image quality metrics (MSE, PSNR, SSIM) are the image-specific counterparts of the regression metrics in [[03. Regression Metrics - MAE, MSE, RMSE, R2, MAPE]].
