# Modern Computer Vision Tasks — Detection and Segmentation

> **Prerequisites:** [[01. Introduction and Foundations of CNNs]], [[01. Advanced Convolutional Operators - Depthwise, Dilated, Transposed, Grouped]], [[05. Computer Vision Metrics - IoU, mAP, Dice]]
> **Connections:** [[03. Evolution of CNN Architectures]] (the backbones used for these tasks)

The vault's CNN chapter covers image classification in depth but completely omits **object detection** (bounding box prediction) and **semantic segmentation** (pixel-level classification). These are the tasks that drove CNN research from 2014 to 2020 and that underpin self-driving cars, medical imaging, and surveillance. This note fills the gap.

---

## The three levels of visual understanding

| Task | Output | Example question |
| :--- | :--- | :--- |
| **Classification** | One label per image | "Is there a cat in this image?" |
| **Object detection** | Bounding boxes + labels | "Where are the cats, and how many?" |
| **Semantic segmentation** | Pixel-level labels | "Which pixels belong to cats?" |
| **Instance segmentation** | Pixel-level labels, separate instances | "Which pixels belong to *this* cat vs *that* cat?" |

Classification (covered throughout the vault) tells you *what* is in the image. Detection tells you *where*. Segmentation tells you *exactly which pixels*. Each level requires a different architecture and a different loss function.

## Object Detection

### The detection problem

Given an image, predict a set of bounding boxes, each with:
- **Location:** $(x, y, w, h)$ — center, width, height.
- **Class:** what object is in the box.
- **Confidence:** how sure the model is.

The number of objects varies per image (0 to many), so the output is a variable-length list, not a fixed-size vector.

### Anchor boxes

The key challenge: how does a neural network output a variable number of boxes? The standard answer: **anchor boxes** (also called priors).

Predefine a set of $K$ anchor boxes at each spatial position of the feature map, with different scales and aspect ratios (e.g., 3 scales × 3 ratios = 9 anchors per position). For a $7 \times 7$ feature map with 9 anchors each, the model predicts $7 \times 7 \times 9 = 441$ boxes. Each prediction is:

- **Objectness score:** is there an object in this anchor? (binary classification)
- **Box regression:** offsets to adjust the anchor to fit the actual object ($\Delta x, \Delta y, \Delta w, \Delta h$).
- **Class probabilities:** what class is the object? (multi-class classification, only if objectness is high)

At inference, the model outputs hundreds or thousands of boxes (one per anchor). Most have low objectness and are discarded; the rest are filtered by **Non-Maximum Suppression** (below).

### Non-Maximum Suppression (NMS)

Multiple anchors may detect the same object (overlapping boxes). **NMS** removes duplicates:

1. Sort all boxes by confidence (descending).
2. Take the highest-confidence box, add it to the output.
3. Remove all boxes with IoU > threshold (e.g., 0.5) with the selected box — they are detecting the same object.
4. Repeat with the next-highest-confidence box.
5. Stop when all boxes are processed or a max count is reached.

NMS is essential — without it, each object is detected 5-10 times.

### Two-stage detectors: Faster R-CNN

**Faster R-CNN** (Ren et al., 2015) is the canonical two-stage detector:

**Stage 1 — Region Proposal Network (RPN):** a small CNN examines the feature map and proposes candidate object regions (anchors with high objectness). This stage does not classify — it just says "there is probably an object here."

**Stage 2 — Classification and refinement:** for each proposed region, the model crops the corresponding feature map region (via **RoI Pooling** or **RoI Align**), applies a classification head to predict the class, and refines the bounding box.

**Pros:** high accuracy (the two stages allow the model to focus on promising regions).
**Cons:** slower (two forward passes), more complex.

### One-stage detectors: YOLO and SSD

**YOLO (You Only Look Once)** (Redmon et al., 2016) and **SSD (Single Shot MultiBox Detector)** (Liu et al., 2016) skip the region proposal stage and predict boxes directly from the feature map in a single pass.

**YOLO:** divides the image into a $S \times S$ grid. Each grid cell predicts $B$ bounding boxes (with objectness and class probabilities) directly. A single forward pass produces all predictions. YOLO is extremely fast (real-time on a GPU) but historically less accurate than two-stage detectors.

**SSD:** similar idea but uses multiple feature maps at different scales (multi-scale detection). Lower-resolution maps detect large objects; higher-resolution maps detect small objects. This improves small-object detection over YOLO.

**Modern YOLO (YOLOv5, v8, v9, v10):** the YOLO family has been continuously improved and is now both fast *and* accurate. YOLOv8 and later are competitive with two-stage detectors on accuracy while remaining real-time. They are the default choice for practical object detection.

### The accuracy-speed tradeoff

| Detector | Accuracy | Speed | Use case |
| :--- | :--- | :--- | :--- |
| Faster R-CNN | High | Slow | High-accuracy, offline |
| YOLO (modern) | High | Real-time | Production, video, edge |
| SSD | Medium | Fast | Good baseline |
| DETR (Transformer-based) | High | Medium | Modern, end-to-end |

The **DETR** (Carion et al., 2020) is a Transformer-based detector that removes the need for anchors and NMS entirely — it directly outputs a fixed set of predictions using a Transformer decoder with learned object queries. It is elegant but currently slower than YOLO for practical use.

## Semantic Segmentation

### The segmentation problem

Given an image, predict a **class label for every pixel**. The output is a $H \times W$ label map, the same size as the input.

### Fully Convolutional Networks (FCN)

**FCN** (Long, Shelhamer, and Darrell, 2015) is the foundational architecture: take a classification CNN (VGG, ResNet), replace the fully-connected layers with convolutional layers, and add a **transposed convolution** (or upsampling) to restore the spatial resolution. The output is a $H \times W \times C$ prediction (per-pixel class scores).

The key insight: a CNN's convolutional layers already produce spatial feature maps; you just need to upsample them back to the input resolution and apply a per-pixel classifier.

### U-Net

**U-Net** (Ronneberger et al., 2015) — covered briefly in [[5.5 Deep Learning for Imaging]] — is the dominant architecture for medical segmentation. Its innovation is **skip connections** from encoder to decoder:

```
Encoder                          Decoder
[Conv 64] ───────────skip────────▶ [Conv 64]
   ↓ (pool)                            ↑ (transpose conv)
[Conv 128] ──────────skip───────▶ [Conv 128]
   ↓ (pool)                            ↑
[Conv 256] ──────────skip───────▶ [Conv 256]
   ↓ (pool)                            ↑
[Conv 512] ──────────skip───────▶ [Conv 512]
   ↓ (pool)                            ↑
[Conv 1024] (bottleneck) ──────────────▶
```

The encoder downsamples (capturing context); the decoder upsamples (restoring resolution). The skip connections pass high-resolution detail from encoder to decoder, so the decoder has both the global context (from the bottleneck) and the local detail (from the skips).

Without the skip connections, the decoder would have to reconstruct pixel-level detail from a heavily-compressed bottleneck, which is impossible. The skips are what make U-Net work.

### DeepLab

**DeepLab** (Chen et al., 2017+) takes a different approach: instead of downsampling then upsampling (U-Net), it uses **dilated convolutions** (see the previous note) to maintain resolution while expanding the receptive field. This avoids the information loss from downsampling.

DeepLabv3+ adds an **ASPP (Atrous Spatial Pyramid Pooling)** module that applies dilated convolutions with different dilation rates (6, 12, 18) in parallel, capturing context at multiple scales. It also adds a decoder module that refines the boundaries.

### Instance segmentation: Mask R-CNN

**Instance segmentation** (separate pixel masks for each object instance) is harder than semantic segmentation (one label per pixel, regardless of instance). **Mask R-CNN** (He et al., 2017) extends Faster R-CNN by adding a third output: in addition to the class and bounding box, the model predicts a binary mask for each detected instance.

The architecture:
1. **RPN** proposes regions (same as Faster R-CNN).
2. **RoI Align** crops the feature map for each proposed region (with bilinear interpolation to avoid quantization).
3. Three heads: classification (what class), box regression (where), and **mask prediction** (a small FCN that predicts a per-pixel binary mask within the box).

Mask R-CNN is the standard for instance segmentation and won the COCO 2017 challenge.

### Panoptic segmentation

**Panoptic segmentation** (Kirillov et al., 2019) unifies semantic and instance segmentation: every pixel is assigned a class label *and* an instance ID. Background classes (sky, road, grass) get one label for all pixels; "thing" classes (person, car, dog) get a separate label per instance. This is the current frontier of segmentation research.

## The architecture landscape

| Task | Canonical architecture | Key innovation |
| :--- | :--- | :--- |
| Object detection (two-stage) | Faster R-CNN | Region Proposal Network |
| Object detection (one-stage) | YOLO, SSD | Single-pass, anchors |
| Object detection (Transformer) | DETR | Learned object queries, no NMS |
| Semantic segmentation | FCN, U-Net, DeepLab | Encoder-decoder / dilated convs |
| Instance segmentation | Mask R-CNN | Adds mask head to Faster R-CNN |
| Panoptic segmentation | Panoptic FPN, MaskFormer | Unifies semantic + instance |

---

## What you should walk away with

1. **Object detection** predicts bounding boxes + classes. Anchors are predefined boxes; the model predicts offsets and objectness. NMS removes duplicate detections.
2. **Two-stage detectors** (Faster R-CNN) propose regions then classify — accurate but slow.
3. **One-stage detectors** (YOLO, SSD) predict directly in a single pass — fast, and modern YOLOs are also accurate.
4. **Semantic segmentation** labels every pixel. FCN is the foundation; U-Net uses encoder-decoder with skip connections; DeepLab uses dilated convolutions.
5. **Instance segmentation** (Mask R-CNN) adds per-instance masks to detection.
6. **Panoptic segmentation** unifies semantic and instance segmentation.
7. These tasks use the metrics from [[05. Computer Vision Metrics - IoU, mAP, Dice]]: mAP for detection, mIoU/Dice for segmentation.
