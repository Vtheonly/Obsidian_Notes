## The block, in one diagram

A Transformer encoder block takes a sequence $X \in \mathbb{R}^{T \times d}$ and produces a sequence of the same shape. It has two sublayers:

```
        X
        │
        ▼
┌───────────────────┐
│  Multi-Head       │◀── residual
│  Self-Attention   │
└───────────────────┘
        │
        ▼
┌───────────────────┐
│  LayerNorm        │
└───────────────────┘
        │
        ▼
┌───────────────────┐
│  Feedforward      │◀── residual
│  (MLP)            │
└───────────────────┘
        │
        ▼
┌───────────────────┐
│  LayerNorm        │
└───────────────────┘
        │
        ▼
      Output
```

In equations:

$$Z = \text{LayerNorm}(X + \text{MultiHeadSelfAttention}(X))$$
$$\text{Output} = \text{LayerNorm}(Z + \text{FFN}(Z))$$

where FFN is a position-wise feedforward network (a small MLP applied independently to each position).

That is the entire block. Stack $N$ of them (typically 6–24) and you have a Transformer encoder. Let's dissect each piece.

---

## Sublayer 1: Multi-Head Self-Attention

This is the self-attention operation from [[01. Self-Attention - When the Sequence Attends to Itself]], wrapped in multi-head form from [[04. Multi-Head Attention - Parallel Relationship Patterns]]. It contextualizes each token's representation by letting it attend to all other tokens.

The input $X$ is projected to Q, K, V, the attention is computed, and the output is projected back to dimension $d$. The output has the same shape as the input — a sequence of $T$ vectors of dimension $d$ — but each vector is now a contextualized representation that incorporates information from all other positions.

---

## Sublayer 2: Position-wise Feedforward Network (FFN)

After attention, each position passes through a small MLP **independently** — there is no interaction between positions in this sublayer. The standard FFN is:

$$\text{FFN}(x) = \text{ReLU}(x W_1 + b_1) W_2 + b_2$$

where $W_1 \in \mathbb{R}^{d \times d_{ff}}$, $W_2 \in \mathbb{R}^{d_{ff} \times d}$, and $d_{ff}$ is typically $4d$ (so $d_{ff} = 2048$ when $d = 512$). The FFN expands the dimension by 4×, applies ReLU, and projects back.

**Why have a FFN at all?** Self-attention is a linear operation (ignoring the softmax) — it computes weighted averages of values, which are linear combinations. The FFN provides the **nonlinearity** that lets the model compute complex functions of its input. Without the FFN, a stack of self-attention layers would collapse to a linear model (just like a stack of linear layers without activations — see [[03. Activation and Pooling Layers]]).

**Why "position-wise"?** The same FFN is applied to each position independently. This is intentional: attention handles inter-position interactions, the FFN handles intra-position transformations. Separating these concerns is cleaner than mixing them.

Modern variants (GELU in ViT/BERT, SwiGLU in LLaMA) replace ReLU with smoother activations and sometimes use a gated structure, but the role is the same: provide per-position nonlinearity after the linear attention operation.

---

## Residual connections

Each sublayer is wrapped in a residual connection: $\text{Output} = X + \text{Sublayer}(X)$. This is the same idea as ResNet ([[08. The Degradation Problem and Residual Connections]]) — the residual path lets gradients flow directly through the block, preventing vanishing gradients in deep stacks.

The residual connections are essential: without them, a 24-layer Transformer would be untrainable. With them, gradients flow through the additive paths and training is stable. This is the same lesson as ResNet (2015) and LSTM (1997) — **additive paths preserve gradient flow** — applied to the Transformer.

---

## LayerNorm

After each sublayer (attention or FFN), a LayerNorm is applied. LayerNorm normalizes **across the feature dimension** for each token independently:

$$\text{LayerNorm}(x) = \gamma \cdot \frac{x - \mu}{\sigma} + \beta$$

where $\mu, \sigma$ are the mean and std of $x$ across the feature dimension, and $\gamma, \beta$ are learnable.

**Why LayerNorm, not BatchNorm?** Three reasons:

1. **Batch independence.** BatchNorm depends on batch statistics, which are ill-defined for variable-length sequences and small batches. LayerNorm uses only per-token statistics, so it is batch-independent.
2. **No train/test discrepancy.** BatchNorm has different behavior in training (batch stats) and inference (running stats), which is a source of bugs. LayerNorm behaves identically in training and inference.
3. **Sequence-length independence.** BatchNorm on sequence data would need to normalize over the time dimension, which conflates position and batch. LayerNorm normalizes only over features, so it works at any sequence length.

This is the same reason RNNs use LayerNorm — the constraints are identical. See [[05. Batch Normalization]] for the broader normalization comparison.

### Pre-LN vs Post-LN

The original Transformer applies LayerNorm *after* the residual addition ("Post-LN"):

$$Z = \text{LayerNorm}(X + \text{Sublayer}(X))$$

Modern Transformers (GPT-2 onward) apply LayerNorm *before* the sublayer ("Pre-LN"):

$$Z = X + \text{Sublayer}(\text{LayerNorm}(X))$$

Pre-LN is more stable to train in deep stacks because the residual path is purely additive (no normalization in the gradient highway), which preserves gradient flow better. Most modern Transformers use Pre-LN. The diagram above shows Post-LN for historical fidelity; in practice, use Pre-LN.

---

## Stacking blocks

A single encoder block transforms the input but does not dramatically change its representational power — the block is a contextualizer (attention) plus a nonlinear transform (FFN), both of which are relatively shallow operations. The power comes from **stacking** $N$ blocks.

Each block refines the contextualization: block 1 lets each token attend to its immediate neighbors, block 2 lets each token attend to tokens that have already incorporated their neighbors' information (effectively a 2-hop neighborhood), and so on. After $N$ blocks, each token's representation incorporates information from across the entire sequence, mediated by $N$ rounds of attention.

This is structurally analogous to stacked CNN layers, where each layer expands the receptive field. In a CNN, the receptive field grows linearly with depth (for fixed kernel size); in a Transformer, the receptive field is global from block 1, but the *complexity* of the relationships that can be modeled grows with depth. A 1-block Transformer can model "token A attends to token B"; a 12-block Transformer can model "token A attends to the token that itself attended to the token that resolved the coreference of token B."

Typical stack depths: BERT-base = 12, BERT-large = 24, GPT-2 small = 12, GPT-3 = 96, ViT-Base = 12.

---

## What you should walk away with

1. A Transformer encoder block is: multi-head self-attention → residual + LayerNorm → feedforward → residual + LayerNorm.
2. Self-attention contextualizes (inter-position interaction); FFN transforms (intra-position nonlinearity). They play complementary roles.
3. Residual connections are essential for training deep stacks — same lesson as ResNet and LSTM.
4. LayerNorm (not BatchNorm) is used because it is batch-independent, has no train/test discrepancy, and works at any sequence length.
5. Pre-LN (normalize before the sublayer) is the modern default, more stable than the original Post-LN.
6. Stacking $N$ blocks deepens the contextualization — each block refines the representations produced by the previous one.
