## The one-sentence intuition

An LSTM is a recurrent cell that maintains a **separate memory channel** — the cell state $C_t$ — whose update rule is *additive* rather than *multiplicative through a nonlinearity*, so gradients can flow backward through hundreds of time steps without being crushed.

Everything else — the three gates, the tanh, the specific formulas — is implementation detail around that one idea. If you remember nothing else, remember: **the cell state is a highway, and the gates are traffic controllers that decide what gets on, what gets off, and what exits as the hidden state.**

---

## The cell state — the highway

The vanilla RNN has one state, $h_t$, which both stores memory and is read out for prediction. The LSTM splits these roles:

- **Cell state** $C_t \in \mathbb{R}^h$ — the long-term memory. This is the highway.
- **Hidden state** $h_t \in \mathbb{R}^h$ — the short-term output. This is what the rest of the network sees.

The cell state update is the heart of the LSTM:

$$C_t = f_t \odot C_{t-1} + i_t \odot \tilde{C}_t$$

Read this carefully:

- $f_t \in [0,1]^h$ is the **forget gate** — per-dimension, how much of the old memory $C_{t-1}$ to keep.
- $\tilde{C}_t \in \mathbb{R}^h$ is the **candidate memory** — new information computed from the current input and previous hidden state, passed through $\tanh$.
- $i_t \in [0,1]^h$ is the **input gate** — per-dimension, how much of the candidate memory to write in.
- $\odot$ is element-wise (Hadamard) product.

So the cell state at time $t$ is: *keep some of the old, add some of the new*. That is it. Notice what is **not** there: no $\tanh$ wrapping the whole update. The cell state evolves additively, and the only thing that can erase information from it is the forget gate actively driving $f_t$ toward 0.

This is the structural fix for vanishing gradients. The gradient $\partial C_t / \partial C_{t-1} = f_t$ — a vector of forget-gate values. When $f_t \approx 1$ (which the network can learn to do for dimensions that need long-range memory), the gradient passes through **multiplied by 1**, exactly like a residual connection. The product of $T$ such terms is $\prod_t f_t$, which stays near 1 as long as the network learns to keep $f_t$ near 1. Contrast this with the vanilla RNN, where the product was $\prod_t W_h^\top \mathrm{diag}(1-h_t^2)$ — a matrix product that shrinks geometrically.

## The three gates — the traffic controllers

Each gate is a small feedforward network with a sigmoid output in $[0,1]$:

| Gate | Formula | Role |
| :--- | :--- | :--- |
| Forget gate $f_t$ | $\sigma(W_f \cdot [h_{t-1}, x_t] + b_f)$ | How much of old memory to keep |
| Input gate $i_t$ | $\sigma(W_i \cdot [h_{t-1}, x_t] + b_i)$ | How much of new candidate to write |
| Output gate $o_t$ | $\sigma(W_o \cdot [h_{t-1}, x_t] + b_o)$ | How much of cell state to expose as hidden state |

The candidate memory uses $\tanh$ (so it is centered at zero and bounded):

$$\tilde{C}_t = \tanh(W_C \cdot [h_{t-1}, x_t] + b_C)$$

And the hidden state — what the rest of the network actually reads — is a filtered view of the cell state:

$$h_t = o_t \odot \tanh(C_t)$$

The $\tanh$ on $C_t$ keeps $h_t$ bounded (the cell state itself can grow large; the tanh squashes it for output). The output gate $o_t$ decides which dimensions of the squashed cell state are relevant right now.

## The full LSTM cell, one diagram

```
                    C_{t-1} ──────●──────●────── C_t
                                  │      │
                              f_t ⊙  i_t ⊙ ̃C_t
                                  │      │
                                  ▲      ▲
                         σ(W_f·[h_{t-1},x_t])  σ(W_i·[h_{t-1},x_t])  tanh(W_C·[h_{t-1},x_t])
                                  ▲      ▲      ▲
                                  └──────┴──────┘
                                         │
                                   [h_{t-1}, x_t]
                                         │
                                  ┌──────┴──────┐
                                  │   concat    │
                                  └─────────────┘
                                         │
                    h_{t-1} ─────────────┘
                                         │
                                   o_t = σ(W_o·[h_{t-1},x_t])
                                         │
                    h_t = o_t ⊙ tanh(C_t) ──────▶ h_t
```

The horizontal top line — $C_{t-1} \to C_t$ — is the highway. The three gates are vertical controls that tap into it. This is the picture to hold in your head.

## Why this works — three perspectives

### Perspective 1: The gradient argument (the rigorous one)

We already noted that $\partial C_t / \partial C_{t-1} = f_t$, so the gradient along the cell-state highway is $\prod_t f_t$. When the forget gate learns to stay near 1 for dimensions that encode long-range information, this product stays near 1 and the gradient flows. The vanilla RNN had no such knob — the equivalent multiplier was $(1 - h_t^2)$, which is not learnable per-step and which saturates to 0 whenever $h_t$ is large.

### Perspective 2: The "constant error carousel" (the original 1997 framing)

Hochreiter and Schmidhuber, who introduced the LSTM in 1997, called this the **constant error carousel**. The cell state is a carousel that carries the error backward through time at constant magnitude, and the gates are the only things that can let error in or out. If you imagine the gradient as a package being passed backward through time, the vanilla RNN shrinks the package at every step; the LSTM lets it through at full size unless a gate actively decides to shrink it.

### Perspective 3: The learned-residual view (the modern framing)

Notice that the cell-state update $C_t = f_t \odot C_{t-1} + i_t \odot \tilde{C}_t$ is a **generalization of a residual connection**. A residual block computes $y = x + F(x)$ — keep all of $x$, add some learned correction. The LSTM computes $C_t = f_t \odot C_{t-1} + i_t \odot \tilde{C}_t$ — keep *some* of $C_{t-1}$ (as decided by $f_t$), add *some* of the correction (as decided by $i_t$). The residual block is the special case $f_t = 1, i_t = 1$. The LSTM learns, per dimension and per time step, whether to behave like a residual block (pass memory through) or like a fresh computation (overwrite memory). This is why LSTMs (1997) anticipated ResNets (2015) by almost 20 years — they are the same idea applied to time instead of depth.

## What the gates actually learn, in practice

When you train an LSTM on a language modeling task and then inspect the gate activations, you find interpretable patterns:

- **Forget gates** often go to 1 for dimensions tracking long-range agreements (subject gender, tense, dialogue speaker) and to 0 for dimensions tracking transient features (the current word's part of speech).
- **Input gates** spike when a semantically heavy word arrives (a noun that establishes a new entity) and go to 0 for function words ("the", "of").
- **Output gates** open when the network needs to *use* the stored information (e.g., when a verb needs to agree with a subject stored 20 tokens ago).

This interpretability is a happy accident of the architecture: because the gates are explicit multiplicative controls, you can read them out. In a vanilla RNN, the equivalent decisions are smeared across the recurrent matrix $W_h$ and are not directly inspectable.

---

## Parameter count — the cost of the design

An LSTM has **four sets of weights** (forget, input, candidate, output), each of size $(h \times (h+d))$ where $h$ is hidden size and $d$ is input size. That is roughly $4 \times$ the parameter count of a vanilla RNN cell of the same hidden size.

| Cell | Weights per step | Relative cost |
| :--- | :--- | :--- |
| Vanilla RNN | $h(h+d) + h$ | 1× |
| LSTM | $4h(h+d) + 4h$ | ~4× |
| GRU | $3h(h+d) + 3h$ | ~3× |

This is the price of the gates. In practice it is worth paying: a 4× larger vanilla RNN still vanishes, while a 4× larger LSTM learns dependencies across hundreds of steps.

## What you should walk away with

1. The LSTM splits state into a **cell state** $C_t$ (long-term memory, additive update) and a **hidden state** $h_t$ (short-term output, gated view of the cell state).
2. The cell-state update $C_t = f_t \odot C_{t-1} + i_t \odot \tilde{C}_t$ is the structural fix for vanishing gradients: the gradient along this path is $\prod_t f_t$, which the network can keep near 1.
3. The three gates (forget, input, output) are learned, per-dimension, per-time-step traffic controllers. They are what make the cell state *selectively* persistent rather than blindly persistent.
4. The LSTM update is a learned generalization of a residual connection ($f_t=1, i_t=1$ recovers the residual form), which is why it anticipates ResNet by 20 years.
5. The cost is ~4× the parameters of a vanilla RNN — worth paying because the alternative (a larger vanilla RNN) still vanishes.

The next note covers the GRU, which simplifies the LSTM by merging gates and removing the separate cell state — at a small cost in expressiveness and a useful gain in speed.
