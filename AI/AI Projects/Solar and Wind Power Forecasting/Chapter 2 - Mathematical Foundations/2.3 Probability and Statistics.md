# 2.3 Probability and Statistics

## Why Statistics Matters for This Project

Every prediction this project makes is fundamentally a statistical statement. When the solar model outputs "200 kW with sigma = 15," it is saying: "Based on the distribution of historical errors, I expect the true value to be near 200 kW, and about 95% of the time, the true value will fall within 200 +/- 30 kW." Understanding probability distributions, statistical estimators, and calibration metrics is essential for interpreting these outputs correctly.

## Random Variables and Distributions

A **random variable** is a variable whose value is determined by a random process. Solar power output at 2 PM tomorrow is a random variable: we do not know its value yet, but we can describe the probability of different outcomes based on historical patterns.

### The Normal (Gaussian) Distribution

The most important distribution in statistics and machine learning. Its probability density function is defined by two parameters: the mean (mu) and the standard deviation (sigma). The heteroscedastic loss function in this project assumes that the residuals follow a Gaussian distribution whose variance depends on the input. When the model predicts log_var = s, it is specifying the sigma of a Gaussian centered at delta. The loss function is the **negative log-likelihood** of this Gaussian, which means training the model is equivalent to maximum likelihood estimation.

### The Weibull Distribution (Wind Speed)

Wind speed at any location typically follows a **Weibull distribution**, which is right-skewed: most of the time, wind speed is moderate, but occasionally there are strong gusts. Understanding this distribution helps explain why wind power forecasting is harder than it might seem: the "average" wind speed is not the most common wind speed, and the cubic relationship between wind speed and power amplifies the right tail.

## Key Statistical Estimators

### Mean and Variance

The **sample mean** is the average of observations, and the **sample variance** measures spread around the mean. The `StandardScaler` in this project computes the mean and standard deviation of each feature on the training set, then uses these statistics to transform both training and test data. This is why the scaler must be **fit only on training data**: using test data would leak information about the test distribution.

### Quantiles and the Interquartile Range

The **median** is the 50th percentile. The **interquartile range** (IQR) is the difference between the 75th and 25th percentiles. The `RobustScaler` used in the wind model scales features using the median and IQR instead of the mean and standard deviation. This makes it **robust to outliers**: a few extreme wind gust measurements will not distort the scaling.

## Maximum Likelihood Estimation (MLE)

MLE is the principle behind training most machine learning models. Given observed data, choose the model parameters that make the observed data most probable. The heteroscedastic loss function is exactly the negative log-likelihood of a Gaussian distribution, meaning training the model is equivalent to maximum likelihood estimation.

## Confidence Intervals and Prediction Intervals

A **confidence interval** quantifies uncertainty about a parameter estimate. A **prediction interval** quantifies uncertainty about a future observation. This project computes prediction intervals. The 95% prediction interval is constructed as `[y_hat - 1.96 * sigma, y_hat + 1.96 * sigma]`, where 1.96 comes from the standard normal distribution.

### PICP (Prediction Interval Coverage Probability)

PICP measures what fraction of true values actually fall within the predicted intervals. If the model claims 95% confidence, PICP should be approximately 0.95. A PICP of 0.90 means the model is overconfident (intervals are too narrow). A PICP of 0.98 means the model is underconfident (intervals are too wide, wasting information).

### MPIW (Mean Prediction Interval Width)

MPIW measures the average width of prediction intervals. The ideal model has PICP close to the nominal level with the **smallest possible MPIW**. Wide intervals that always contain the true value are useless; narrow intervals that miss the true value half the time are dangerous.

## Correlation and Feature Selection

The project uses correlation analysis to select features. The **Pearson correlation coefficient** measures linear dependence. In the solar dataset, GHI and solar generation have a correlation near 0.95, which is expected since irradiance is the primary physical driver. **Multicollinearity** occurs when features are highly correlated with each other. The research paper uses Variance Inflation Factor (VIF) checks to detect this and retains only the most physically interpretable variable.

## Key Takeaways

- The heteroscedastic loss is derived from maximum likelihood estimation of a Gaussian with input-dependent variance
- StandardScaler uses mean and std; RobustScaler uses median and IQR
- PICP measures whether prediction intervals are well-calibrated
- MPIW measures whether prediction intervals are unnecessarily wide
- Wind speed follows a Weibull distribution, explaining the asymmetric difficulty of wind forecasting
- Correlation analysis guides feature selection but must account for multicollinearity
- All scaling must be fit on training data only to prevent data leakage

> **Important Reminder**: A common mistake is to interpret a 95% prediction interval as "there is a 95% probability that the true value is in this interval." This is technically a Bayesian interpretation. The frequentist interpretation is: "If we constructed this interval many times, 95% of those intervals would contain the true value."
