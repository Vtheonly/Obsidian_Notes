# 3D-SynTree Vault

A complete, deeply hierarchical learning knowledge base for **3D-SynTree** — a structure-based, synthesis-constrained molecular design system that builds drug-like molecules inside protein binding pockets by assembling purchasable Enamine REAL synthons through certified medicinal-chemistry reactions.

## How to Open

1. Unzip this archive anywhere on your computer.
2. Open **Obsidian** → **Open folder as vault** → select the `3D-SynTree Vault` folder.
3. Start reading at [[0. Master Vault Index]].

## What Is Inside

- **10 modules**, each split into **chapters**, each chapter containing numbered **concept notes** (58 in total).
- **10 module MOCs** (Maps of Content) acting as navigation hubs, plus **6 system-map notes** in `00. Master Index and System Map`.
- Every concept note follows a strict 9-section schema: definition → motivation → mechanism → components → pitfalls and must-knows → prerequisites → project connection → required depth → further dependencies.
- Dense `[[wikilinks]]`, meaningful tags, and Mermaid mind maps that visualize the knowledge hierarchy and learning paths.
