# 4.2. 3D-RISM Theory and Numerical Solvers

3D-RISM is retained as a theoretical and computational reference method for molecular solvation.

## Role in SynPath-3D

3D-RISM may be used for:

- controlled methodological comparison;
- auxiliary hydration teacher data;
- sensitivity analysis of closure assumptions.

It is **not** the mandatory runtime solvation engine.

The production runtime interface is HENF:

\[
(\mathcal P,r)\rightarrow
[\Delta\mu_{\mathrm{excess}}(r),g_O(r)].
\]

## Numerical theory

3D-RISM solves site-site integral equations on a spatial grid using a closure relation. KH is one possible closure and remains useful for studying approximation error.

Any benchmark using 3D-RISM must record:

- solvent model;
- grid spacing;
- closure;
- convergence criterion;
- number of structures;
- CPU/GPU cost.

Statements that SynPath-3D “runs 2,500 production pockets through 3D-RISM” are obsolete.
