# 8.2. Comprehensive Evaluation Suite

The canonical validation stack contains:

1. physical validity evaluation with the installed PoseBusters configuration;
2. retrosynthetic feasibility with the declared AiZynthFinder inventory and depth;
3. short explicit-solvent OpenMM MD;
4. target/scaffold-stratified metrics for OOD evaluation.

Report per-check failures, synthesis route failures, MD stability measures and calibration metrics separately.

A benchmark result is evidence for a claim only when the evaluator version and configuration are recorded.
