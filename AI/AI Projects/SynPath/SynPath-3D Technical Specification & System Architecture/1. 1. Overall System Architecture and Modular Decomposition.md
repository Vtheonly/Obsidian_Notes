# 1.1. Overall System Architecture and Modular Decomposition

SynPath-3D is a goal-directed structure-based drug-design system coupling structural context, hydration, pharmacophore targets, discrete chemistry and constrained geometric generation.

~~~text
POCKET ENSEMBLE
  3–5 conformers
      │
      ▼
6-LAYER EQUIFORMER-LIGHT
  Stage-0 self-supervised pretraining
      │
      ├── HENF: continuous hydration field
      └── CPDF: continuous pharmacophore field
              │
              ▼
SPATIAL PLANNING
  handle state + pocket + active targets → z_t
              │
              ├── 24-class legal reaction head
              └── 263-D synthon target predictor
                         │
                         ▼
              TOP-128 RETRIEVAL + RE-RANKING
                         │
                         ▼
COMPLIANT PoE + ENERGY-GUIDED TORUS FLOW
                         │
                         ▼
PHYSICAL / SYNTHETIC VALIDATION
                         │
                         ▼
PRUNED SubTB GFlowNet ALIGNMENT
~~~

## Runtime Stages

1. **Pocket context and solvation:** ensemble-aware Equiformer-Light + HENF.
2. **Teleological planning:** CPDF predicts a continuous six-channel interaction field and adaptive target set.
3. **Hierarchical synthesis:** legal reaction selection followed by metric retrieval and contextual re-ranking.
4. **Geometric generation:** compliant PoE and guided torus flow.
5. **Validation and alignment:** hard validity gates followed by calibrated reward and pruned SubTB.

This note is authoritative for module ordering and data dependencies.
