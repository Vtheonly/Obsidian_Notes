# 1.8. Continuous Head: Energy-Guided Coupled Torus Flow Matching

Rotatable bonds live on:

\[
\mathbb T^K=[-\pi,\pi)^K.
\]

The base-to-target path is

\[
\gamma_s
=
\phi_0+s\,\operatorname{wrap}(\phi_1-\phi_0).
\]

The guided velocity is

\[
v_{\mathrm{guided}}
=
v_\theta(\phi_s,s,z_t,E_B)
-
\eta(s)J(\phi_s)^\top\nabla_xV_{\mathrm{rep}}(x(\phi_s)).
\]

The analytical repulsion term provides in-flight steric guidance rather than a hidden post-hoc optimizer.

## Default sampler

Use an explicit midpoint solver with four steps:

\[
k_1=v(\phi_n,s_n),
\]

\[
\phi_{\mathrm{mid}}
=
\operatorname{wrap}(\phi_n+\tfrac12\Delta s\,k_1),
\]

\[
k_2=v(\phi_{\mathrm{mid}},s_n+\tfrac12\Delta s),
\]

\[
\phi_{n+1}
=
\operatorname{wrap}(\phi_n+\Delta s\,k_2).
\]

Four steps is a performance target, not a mathematical guarantee.

## Removed production stages

Mandatory DLS clash correction and mandatory MMFF94s minimization are removed from the generation path. External relaxation remains available as a baseline/validation experiment.

Validate solver accuracy, clash rates, angle fidelity and PoseBusters performance across different step counts.
