# 6.3. Pre-Featurized In-RAM Sharding Infrastructure

Use pre-featurized shards to reduce repeated preprocessing while remaining robust to datasets larger than host RAM.

## Shards

- Stage-0 structural shards;
- Stage-1 experimental trajectories;
- Stage-1 synthetic-route data;
- validation-only data.

## Loader policy

Use full in-RAM caching only when measured to fit. Otherwise use memory mapping, compressed shards or lazy loading.

The 75k catalog descriptor index is precomputed and can be resident on GPU or efficiently served from host memory depending on benchmark results.

Checksums, dataset version, split seed and preprocessing version are mandatory metadata.
