# 0.1. Master Architectural Overhaul and Canonical Revision

This note is the master architectural baseline for SynPath-3D.

## Canonical Changes

### Biophysics
- Replace rigid single-state receptors plus independent Gaussian sidechain perturbations with 3–5-state ensemble conditioning.
- Replace 3D-RISM/KH as the production solvation backbone with the continuous Hydration Energy Neural Field (HENF).
- Retain 3D-RISM as a scientific reference / optional teacher rather than the runtime dependency.

### Model architecture
- Replace fixed M=5 TIF anchors with a Continuous Pharmacophore Density Field (CPDF) and adaptive peak extraction.
- Replace flat 75k synthon classification with reaction filtering → 263-D target prediction → top-128 retrieval → contextual re-ranking.
- Replace the DPDA synthesis-state abstraction with explicit vectorized functional-handle bitsets.
- Replace rigid-only PoE with bounded valence-angle compliance.
- Move analytical steric guidance inside torus flow and remove mandatory post-hoc DLS/MMFF94s generation repair.

### Training and alignment
- Add Stage 0 self-supervised structural pretraining.
- Stage 1 jointly learns CPDF, reaction selection, metric retrieval and geometric flow.
- Stage 2 uses legal/retrieved action support, pruned SubTB and entropy regularization.
- Terminal quality scoring is protected by hard physical and synthesis gates.

Numeric thresholds, sample counts, latency claims and pass-rate targets are engineering hypotheses until measured.
