# 0.1. Master Architectural Overhaul and Canonical Revision

This note is the master specification for the revised SynPath-3D system. It consolidates the architectural, biological, mathematical, computational and training changes required to move from the brittle legacy composition to a modular, testable and physically defensible SBDD pipeline.

## 1. Biophysical and Chemical Foundations

### 1.1 Pocket Flexibility and Ensemble Conditioning

**Remove:** rigid receptor conditioning plus independent Gaussian perturbations of isolated sidechain torsions.

**Adopt:** 3–5 physically supported conformations per target, pooled with permutation-invariant conformer attention.

\[
\mathcal P=\{P_1,\dots,P_K\},\qquad K\in[3,5]
\]

\[
h_{p,i}
=
\operatorname{ConformerAttention}
\left(
q_i,\{k_{i,k},v_{i,k}\}_{k=1}^{K}
\right).
\]

The representation must expose both consensus structure and conformational variance. MD, normal-mode or experimentally supported ensemble construction is preferred; random independent rotamer noise is only an ablation.

### 1.2 Hydration Energy Neural Field

**Remove:** a production pipeline that depends on thousands of offline 3D-RISM/KH solves.

**Adopt:** HENF as a continuous runtime field:

\[
\Psi_\phi(r\mid\mathcal P)
\rightarrow
[\Delta\mu_{\mathrm{excess}}(r),g_O(r)].
\]

HENF is dual-scale:

- global continuum GB/SA-style electrostatic/desolvation component;
- local learned hydration/dewetting field.

GIST/WaterMap-style explicit-solvent references are preferred teacher signals where available. 3D-RISM remains available as a theory/reference/auxiliary teacher.

Candidate hydration thresholds are calibration parameters, not universal constants.

### 1.3 Compliant Lie-Kinematic Geometry

**Remove:** a completely rigid internal-coordinate model in which all valence angles are effectively immutable.

**Adopt:** a compliant joint vector:

\[
\Theta=[\phi\in\mathbb T^K,\delta\theta\in\mathbb R^M]
\]

with bounded elastic angle variables, initially around:

\[
\delta\theta_m\in[-0.07,0.07]\text{ rad}.
\]

The elastic penalty is:

\[
E_{\mathrm{elastic}}
=
\frac12
\sum_m k_{\theta,m}\delta\theta_m^2.
\]

Bond-length invariance remains a hard property of the PoE rigid transforms. Chemical geometry that cannot be represented by the compliant parameterization remains an explicit chemistry constraint.

## 2. Model and Algorithm Redesign

### 2.1 Hierarchical Synthon Retrieval

**Remove:** the flat 75k-way synthon softmax.

**Adopt:**

\[
\text{reaction}
\rightarrow
q_{\mathrm{target}}\in\mathbb R^{263}
\rightarrow
\text{legal catalog filter}
\rightarrow
\text{top-128 ANN retrieval}
\rightarrow
\text{in-pocket re-ranking}.
\]

The 263-dimensional target profile contains a 256-D chemical embedding target plus spatial/physical descriptors such as exit-vector direction, fragment volume and an electronic descriptor.

The ANN lookup is intentionally non-differentiable. Stage 1 learns the continuous metric space with contrastive supervision; contextual re-ranking learns the pocket-conditioned preference over the retrieved support.

### 2.2 Continuous Pharmacophore Density Field

**Remove:** fixed \(M=5\) TIF anchors and Hungarian matching as the production target decoder.

**Adopt:** a continuous six-channel field:

\[
\Phi_\theta(r\mid\mathcal P)\in[0,1]^6.
\]

Channels:

1. H-bond donor;
2. H-bond acceptor;
3. aromatic;
4. hydrophobic;
5. cationic;
6. anionic.

Extract local maxima with spatial NMS or clustering:

\[
\mathcal Y^*
=
\{(x_m^*,R_m^*,\tau_m^*,\Delta G_m^*)\}_{m=1}^{M}.
\]

An initial \(1\le M\le12\) decode cap is a compute budget, not a biological law.

A scalar field gradient alone does not uniquely define an SO(3) frame. Directional frames therefore require additional local geometry, derivatives or a learned directional head.

### 2.3 Unified Energy-Guided Torus Flow

**Remove:** the fragmented production sequence:

\[
\text{flow}\rightarrow\text{PoE}\rightarrow\text{DLS repair}\rightarrow\text{MMFF94s minimization}.
\]

**Adopt:** a guided vector field:

\[
v_{\mathrm{guided}}
=
v_\theta(\phi_s,s,z_t,E_B)
-
\eta(s)J(\phi_s)^\top\nabla_xV_{\mathrm{rep}}(x(\phi_s)).
\]

Use a four-step midpoint solver as the initial fast sampler. Four steps are a benchmark target, not a guarantee of sufficient numerical accuracy.

DLS and MMFF94s remain available only as explicit external baselines/validation experiments.

### 2.4 Reaction-State Simplification

**Remove:** DPDA stack execution as the canonical state machine.

**Adopt:** explicit finite-state functional-handle bitsets. Use one-hot bit positions inside the 64-bit word so bitwise operations represent categories correctly.

Example allocation:

~~~text
Bits  0–7   functional-handle class
Bits  8–15  protection state
Bits 16–23  chemical environment
Bits 24–31  substitution / steric class
Bits 32–63  reserved
~~~

Legal reaction masking:

\[
\operatorname{legal}(u,k)
=
((m_u\&R_k)\neq0)\land((m_u\&F_k)=0).
\]

Integer bitwise kernels are GPU-friendly but should not be described as Tensor Core operations.

## 3. Data, Pretraining and Self-Supervision

### 3.1 Stage 0 Structural Pretraining

Pretrain the six-layer Equiformer-Light pocket encoder on a large leakage-controlled PDB-derived structural corpus.

Objectives:

**Masked residue recovery**

\[
\mathcal L_{\mathrm{MRR}}
=
-\sum_{i\in\mathcal M}
\log p(a_i\mid\mathcal P_{\setminus\mathcal M}).
\]

**Coordinate denoising**

Perturb clean coordinates and predict the displacement back toward the clean structure.

The project target is 100k+ structural examples / cavities, but the actual dataset manifest is authoritative.

### 3.2 Stage 1 Synthetic Chemistry Expansion

Use a larger synthetic-route corpus to pretrain reaction-selection and synthon-retrieval behavior.

The planning target is on the order of 500k synthetic routes. These approximate synthetic records teach chemical compatibility and route grammar; they must not be used as ground-truth supervision for experimental 3D conformational geometry when the coordinates are merely docked/approximate.

Fine-tune the complete 3D model on the curated experimental crystal trajectories, with the current target around 30k purified trajectories.

### 3.3 Leakage Control

Maintain separate controls for:

- protein sequence similarity (MMseqs2);
- protein structure similarity (Foldseek);
- chemical scaffold similarity (Bemis-Murcko);
- exact molecular identity / duplicates.

The held-out evaluation set must be protected across all relevant axes.

## 4. Reinforcement Learning and Alignment

### 4.1 Hard-Gated Consensus Reward

Validity must be separated from quality:

\[
G(\mathcal M)
=
I_{\mathrm{PoseBusters}}(\mathcal M)
I_{\mathrm{Synth}}(\mathcal M).
\]

For stable logarithms:

\[
R(\mathcal M)=
\begin{cases}
\epsilon,&G=0\\
\exp(-\Delta G_{\mathrm{consensus}}/E_0+\beta R_{\mathrm{div}}),&G=1.
\end{cases}
\]

The consensus energy combines calibrated interaction, polar desolvation, HENF hydration/dewetting and conformational strain terms.

A high proxy score cannot compensate for a failed geometry or synthesis gate.

### 4.2 Pruned SubTB with Entropy

Define the actual action support:

\[
\mathcal A_t=
\mathcal A_t^{\mathrm{legal}}
\cap
\mathcal A_t^{\mathrm{retrieved}}.
\]

Restricting synthon actions to the retrieved top-128 set is part of the Stage-2 policy definition.

Use:

\[
\mathcal L_{\mathrm{SubTB}}
=
\sum_{i<j}
\lambda^{j-i-1}\Delta_{i,j}^2,
\qquad \lambda=0.90
\]

and

\[
\mathcal L_2
=
\mathcal L_{\mathrm{SubTB}}
-
\alpha_{\mathrm{ent}}
\sum_t\mathcal H(P_F(\cdot|s_t)).
\]

Initialize Stage 2 from a converged Stage-1 policy and monitor entropy, \(\log Z\), invalid trajectories and chemical-series diversity.

## 6. Decisions That Remain

| Subsystem | Canonical choice |
|---|---|
| Reaction grammar | 24 certified reaction classes |
| Provenance | isotopic atom offsets / explicit atom mapping |
| Continuous manifold | flat torus \(\mathbb T^K\) |
| Data leakage | MMseqs2 + Foldseek + Bemis-Murcko |
| Mixed precision | BF16 / TF32 with FP32-sensitive reductions |
| Catalog | 75k-synthon index |
| Retrieval support | top-128 initial budget |

These are architectural decisions. Performance numbers must remain experiment-backed claims.

- build the catalog index;
- implement handle bitsets;
- curate structural and synthetic-route manifests;
- pretrain the pocket encoder.

### Phase 2 — Hierarchical Generation
- implement CPDF;
- implement reaction + retrieval hierarchy;
- implement compliant PoE;
- implement energy-guided torus flow;
- run Stage 1 training.

### Phase 3 — Alignment and Validation
- implement gated reward;
- implement pruned SubTB + entropy;
- run PoseBusters, retrosynthesis and explicit-solvent MD validation;
- execute ABL-01 through ABL-05 and the ensemble/pretraining/guidance controls.
