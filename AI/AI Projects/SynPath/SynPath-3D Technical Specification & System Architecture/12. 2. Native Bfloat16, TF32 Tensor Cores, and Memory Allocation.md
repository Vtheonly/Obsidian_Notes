# 12.2. Native BF16, TF32 Tensor Cores, and Memory Allocation

BF16 is the preferred mixed-precision format for compatible neural operations. TF32 may be enabled for FP32 matrix multiplication on supported NVIDIA hardware.

## Numerical policy

- BF16 for major neural layers where validated;
- FP32 for sensitive geometry, distance accumulation, reductions and physical quantities when required;
- TF32 enabled for supported FP32 matmul;
- explicit finite-value checks during development.

BF16 has a wider exponent range than FP16, reducing some overflow/underflow failure modes, but it does not eliminate numerical instability.

## Hardware verification

Runtime startup must verify CUDA availability, device capability and BF16 support. A target RTX 6000 Ada-class workstation is an execution profile, not a substitute for detecting the actual device.

VRAM estimates must be measured on the complete model, including activations, optimizer state, conformer dimension, retrieval buffers and allocator overhead.
