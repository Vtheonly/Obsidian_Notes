# 2.1. End-to-End Tensor Shape and Dtype Trace

Reference configuration: per-device batch B=32, K=5 pocket conformers, Np_max=150, Nq=512, M_max=12.

| Stage | Tensor | Shape | Dtype |
|---|---|---|---|
| Pocket ensemble | pocket_pos | [B,K,Np,3] | float32 |
| Pocket atoms | pocket_z | [B,Np] | int64 |
| Charges/SASA | pocket_features | [B,Np,2] | float32 |
| Ensemble backbone | h_p | [B,K,Np,256] → pooled | bfloat16 |
| Ensemble vectors | v_p | [B,K,Np,3,64] → pooled | bfloat16 |
| HENF query lattice | r_q | [B,Nq,3] | float32 |
| HENF output | delta_mu, g_O | [B,Nq] | float32 |
| CPDF field | Phi | [B,Nq,6] | float32 |
| Adaptive targets | Y* | [B,12,...] | mixed |
| Planning state | z_t | [B,256] | bfloat16 |
| Reaction logits | l_rxn | [B,24] | float32 |
| Handle states | m_handle | [B,n_handles] | uint64/int64 |
| Target profile | q_target | [B,263] | float32 |
| Retrieved IDs | top128_idx | [B,128] | int64 |
| Re-ranking | l_syn | [B,129] | float32 |
| Torus angles | phi | [B,K_torsion] | float32 |
| Compliant angles | delta_theta | [B,M_angle] | float32 |
| Guided joint velocity | v_guided | [B,K_torsion + M_angle] | float32 |
| Ligand coordinates | X_lig | [B,N_lig,3] | float32 |

The extra conformer dimension is the dominant architecture-level activation increase. Reduce per-device batch size and use gradient accumulation rather than silently dropping ensemble information.

Exact VRAM usage must be profiled from the real graph, allocator behavior and activation checkpointing configuration.
