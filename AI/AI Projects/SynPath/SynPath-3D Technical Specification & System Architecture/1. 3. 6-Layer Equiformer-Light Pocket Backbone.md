# 1.3. 6-Layer Equiformer-Light Pocket Backbone with Self-Supervised Pretraining

The canonical pocket encoder is a six-layer Equiformer-Light model operating on an ensemble of 3–5 receptor conformations.

\[
X_P\in\mathbb R^{K\times N_p\times3},\qquad K\in[3,5].
\]

Per-atom context includes element identity, charge/context descriptors, SASA and ensemble-derived flexibility. The backbone produces:

\[
h_p\in\mathbb R^{N_p\times256},
\qquad
v_p\in\mathbb R^{N_p\times3\times64}.
\]

## Stage-0 Self-Supervised Pretraining

Pretrain on a large leakage-controlled PDB-derived structural corpus.

### Masked Residue Recovery

\[
\mathcal L_{\mathrm{MRR}}
=
-\sum_{i\in\mathcal M}
\log p(a_i\mid\mathcal P_{\setminus\mathcal M}).
\]

### Coordinate Denoising

Apply controlled training perturbations to coordinates and learn the equivariant displacement field required to recover clean geometry. This noise process is a training augmentation, not the biological receptor-dynamics model.

## Ensemble Conditioning

Use permutation-invariant conformer pooling/attention so the representation contains both consensus geometry and conformational variance.

Independent Gaussian perturbations of isolated sidechain dihedrals are not the canonical production representation.

## Fixed architectural defaults

- six equivariant layers;
- scalar width 256;
- vector width 64;
- radial cutoff 6.0 Å;
- BF16/TF32 where numerically validated.

All throughput and accuracy claims remain benchmark hypotheses.
