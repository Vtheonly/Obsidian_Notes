# 1.3. 6-Layer Equiformer-Light Pocket Backbone with Self-Supervised Pretraining

The canonical pocket encoder is a six-layer Equiformer-Light model operating on an ensemble of 3–5 receptor conformations.

## Representation

For each target:

\[
X_P\in\mathbb R^{K\times N_p\times3},
\qquad K\in[3,5].
\]

The model produces scalar and vector states with target width 256 and vector channels \(3\times64\).

Per-atom features include element identity, charge/context descriptors, surface information, residue/atom identity and ensemble-derived flexibility information.

## Stage 0

Pretrain on a large leakage-controlled PDB-derived structural corpus with:

- masked residue recovery;
- coordinate denoising.

The project may target 100k+ structural samples, but the dataset manifest is authoritative.

## Equivariance

The backbone must implement the actual selected Equiformer-Light/equivariant block design. Any small PyTorch snippet in educational notes is an interface illustration, not a claim that a custom simplified message-passing block is mathematically identical to the published architecture.

## Runtime

Radial cutoff is initially \(6.0\) Å. BF16/TF32 are preferred where validated; sensitive geometric reductions may use FP32.

Latency and VRAM numbers are benchmark outputs, not architectural constants.
