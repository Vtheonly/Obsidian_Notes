# 1.3. 6-Layer Equiformer-Light Pocket Backbone

## Inputs

For each target:

\[
\mathcal P=\{P_1,\dots,P_K\},\qquad K\in[3,5].
\]

Each conformer provides atomic coordinates, element identity, charge descriptors, residue context and surface features.

## Backbone

- 6 Equiformer-Light layers.
- Scalar width \(d=256\).
- Vector channels \(3\times64\).
- Radial cutoff \(r_{\mathrm{cut}}=6.0\) Å.
- Smooth radial basis encoding.
- BF16/TF32 where numerically stable.

## Ensemble Pooling

The conformer axis is processed with permutation-invariant attention:

\[
h_i=\operatorname{Pool}_{k=1}^{K}\operatorname{Attention}(q_i,k_{i,k},v_{i,k}).
\]

The pooled representation must retain both consensus structural information and conformational variance.

Independent Gaussian perturbation of isolated sidechain torsions is not the canonical receptor-dynamics model.

## Stage-0 Pretraining

Use masked residue recovery and coordinate denoising on a large leakage-controlled structural corpus.

\[
\mathcal L_{\mathrm{MRR}}
=
-\sum_{i\in\mathcal M}
\log p(a_i\mid\mathcal P_{\setminus\mathcal M}).
\]

Coordinate denoising trains the equivariant representation to recover clean local geometry after controlled perturbation.

## Outputs

\[
h_p\in\mathbb R^{N_p\times256},
\qquad
v_p\in\mathbb R^{N_p\times3\times64}.
\]

The outputs feed HENF, CPDF and the spatial planning core.
