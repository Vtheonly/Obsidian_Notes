# 1.2. Component Lifecycle: Kept, Removed, Replaced, and Redesigned

| Component | Canonical decision |
|---|---|
| Equiformer-Light | Keep backbone family; add Stage-0 pretraining and ensemble conditioning |
| Single rigid receptor + Gaussian torsion noise | Remove |
| ENSF / 3D-RISM-only runtime solvation | Replace with HENF; retain 3D-RISM as reference/teacher |
| Fixed M=5 TIF | Replace with CPDF |
| Flat 75k synthon softmax | Replace with hierarchical retrieval |
| DPDA stack | Replace with explicit finite-state handle bitsets |
| Rigid-only PoE | Redesign as compliant PoE |
| DLS post-hoc clash resolver | Remove from production generation path |
| Mandatory MMFF94s minimization | Remove from production generation path |
| Unpruned SubTB action space | Replace with legal top-128 support |
| Additive proxy reward | Replace with gated consensus reward |
| 24 reaction classes | Keep |
| Atom provenance / isotope offsets | Keep |
| MMseqs2 + Foldseek + scaffold leakage controls | Keep |
| BF16 / TF32 execution target | Keep with runtime verification |

Legacy components remain useful as explicit ablation baselines only.
