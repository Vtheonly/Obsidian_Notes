# 5.2. Solvation Teacher Data: 3D-RISM Reference and Explicit-Solvent Targets

3D-RISM remains useful as a reference/auxiliary teacher but is no longer the required runtime path.

## Teacher hierarchy

1. explicit-solvent hydration observables where available;
2. GIST / WaterMap-style local water thermodynamics;
3. analytical GB/SA quantities;
4. 3D-RISM as an optional reproducible reference.

The exact mixture is recorded in the dataset manifest.

## Runtime interface

\[
(\mathcal P,r)\rightarrow(\Delta\mu_{\mathrm{excess}}(r),g_O(r))
\]

is implemented by HENF.

The purpose of retaining this note is to preserve 3D-RISM theory for benchmarking and teacher-data generation without making thousands of CPU solves mandatory during generation.
