# 12.1. NVIDIA RTX 6000 Ada Memory Map and VRAM Anatomy

This note describes a target execution profile. It is not a fixed measured memory map.

## Reference hardware

- target GPU: RTX 6000 Ada-class, 96 GB VRAM;
- preferred neural precision: BF16;
- preferred FP32 matmul mode: TF32 where supported.

## Memory categories

| Category | Behavior |
|---|---|
| model parameters | persistent |
| gradients | persistent during backward |
| optimizer states | persistent for training |
| catalog descriptors | persistent or cached |
| ensemble activations | scales with K and batch |
| CPDF/HENF query buffers | scales with spatial query count |
| flow/Jacobian buffers | scales with ligand atoms and active joints |
| CUDA workspaces / allocator reserve | runtime dependent |

The old hard-coded 42 GB / 53.9 GB split is removed. Real usage depends on implementation, graph sparsity, activation checkpointing, allocator state and the actual conformer count.

## Profiling rule

Every production run records:

\[
\text{peak allocated},\quad
\text{peak reserved},\quad
\text{batch},\quad
K,\quad
N_p,\quad
N_q,\quad
\text{checkpointing}.
\]

No memory guarantee is inferred from arithmetic estimates alone.
