# 16.2. Device-Placement Safeguards and Hub Synchronization

Checkpoint tensors are serialized independently of the training device. Restore onto the available device after load rather than embedding a permanent \`cuda:0\` assumption in tensors.

## Hub synchronization

Remote synchronization is optional infrastructure. A checkpoint is considered valid locally before upload.

Every uploaded artifact is associated with:

- checkpoint hash;
- experiment ID;
- source commit;
- dataset manifest;
- stage/epoch.

Model-card or Hub metadata must not be treated as the scientific experiment registry itself.
