# 19.1. Concrete Rationale for the Twelve Core System Decisions

## ADR-01
**Decision:** Dual-track hierarchical discrete chemistry + continuous torus flow.
**Reason:** discrete reaction selection and continuous conformation are different learning problems but require a shared planning state.

## ADR-02
**Decision:** Six-layer Equiformer-Light with Stage-0 structural pretraining.
**Reason:** downstream SBDD data alone are insufficient for robust structural representation learning.

## ADR-03
**Decision:** 3–5 conformer ensemble conditioning.
**Reason:** avoid treating receptor motion as independent Gaussian torsion noise.

## ADR-04
**Decision:** HENF continuous hydration field.
**Reason:** provide differentiable runtime hydration context without mandatory thousands-of-CPU-hour integral-equation inference.

## ADR-05
**Decision:** CPDF with adaptive targets.
**Reason:** remove the arbitrary fixed M=5 anchor budget.

## ADR-06
**Decision:** reaction mask → 263-D profile → top-128 retrieval → contextual re-ranking.
**Reason:** avoid sparse supervision across a very large flat catalog.

## ADR-07
**Decision:** compliant PoE.
**Reason:** bounded angle compliance reduces artificial kinematic dead ends while retaining explicit strain control.

## ADR-08
**Decision:** energy-guided torus flow.
**Reason:** integrate steric avoidance into generation rather than hiding it in post-hoc correction.

## ADR-09
**Decision:** bitset functional-handle state.
**Reason:** the certified reaction grammar does not require recursive stack semantics.

## ADR-10
**Decision:** pruned SubTB + entropy regularization.
**Reason:** make the policy support explicit and reduce branching variance.

## ADR-11
**Decision:** hard physical/synthetic validity gates.
**Reason:** proxy quality scores must not compensate for invalid molecules.

## ADR-12
**Decision:** BF16/TF32-capable workstation profile with measured memory budgets.
**Reason:** optimize numerical throughput while verifying actual hardware limits.

CANONICAL means architectural intent. Empirical superiority remains a falsifiable experimental claim.
