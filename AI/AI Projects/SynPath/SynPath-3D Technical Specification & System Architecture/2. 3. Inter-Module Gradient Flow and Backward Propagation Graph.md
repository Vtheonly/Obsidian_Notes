# 2.3. Inter-Module Gradient Flow and Backward Propagation Graph

## Stage 0

Backbone → masked-residue recovery + coordinate denoising.

## Stage 1

Backbone → HENF / CPDF / planner → reaction head + retrieval target head + torus flow → multi-task loss.

The continuous retrieval target is trained by metric learning. The discrete ANN lookup is intentionally non-differentiable; its output support is consumed by the contextual re-ranker.

## Stage 2

Planner → legality mask → top-128 retrieval support → re-ranker → synthesis trajectory → terminal validity gates → consensus reward → SubTB.

The pruning operation changes the policy support and therefore must be part of both forward and backward probability calculations.

## Physical guidance

The repulsion potential contributes through:

\[
J^\top\nabla_xV_{\mathrm{rep}}.
\]

There is no hidden DLS correction or mandatory MMFF94s optimizer in the production autograd path.

Every module must be tested for finite gradients, correct device placement, periodic wrapping, and safe FP32/BF16 boundaries.
