# 17.1. PoseBusters Physical Integrity Protocol

PoseBusters is an external validation gate for generated conformations.

The installed evaluator version, exact checks and thresholds are pinned in the experiment environment. The architecture note must not hard-code a check count or tolerance that can drift from the installed tool.

## Reward role

A candidate failing the configured physical-validity gate receives the numerical floor reward and is excluded from positive-quality scoring.

## Reporting

Record total pass rate, each failed check, failure class, synthesis depth and target family. The validator is never replaced by hidden DLS or MMFF94s repair.
