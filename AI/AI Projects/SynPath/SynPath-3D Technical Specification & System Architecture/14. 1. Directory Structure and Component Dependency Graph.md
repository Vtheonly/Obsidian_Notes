# 14.1. Directory Structure and Component Dependency Graph

The code structure should mirror the canonical mathematical decomposition.

~~~text
src/
├── data/
├── chemistry/
│   ├── reaction_grammar.py
│   ├── handle_bitmask.py
│   └── atom_provenance.py
├── models/
│   ├── equivariant_backbone.py
│   ├── henf.py
│   ├── cpdf.py
│   ├── spatial_planner.py
│   ├── reaction_head.py
│   ├── retrieval_head.py
│   ├── torus_flow.py
│   └── compliant_poe.py
├── retrieval/
│   ├── catalog_index.py
│   └── reranker.py
├── training/
│   ├── stage0_pretrain.py
│   ├── stage1_imitation.py
│   └── stage2_gflownet.py
├── rewards/
└── validation/
~~~

Compatibility aliases may remain for older module names, but new implementation work must use HENF, CPDF, hierarchical retrieval, compliant PoE and energy-guided torus flow nomenclature.
