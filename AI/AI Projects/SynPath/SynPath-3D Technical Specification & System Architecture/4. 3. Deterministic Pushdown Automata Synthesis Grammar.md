# 4.3. Vectorized Bitmask Reaction State Tracker

The certified 2–4 step reaction grammar uses explicit finite-state functional handles. A recursive DPDA stack is not part of the canonical implementation.

## 64-bit representation

\`\`\`
Bits 0–7   : one-hot functional-handle class
Bits 8–15  : one-hot protecting-group state
Bits 16–23 : one-hot chemical environment
Bits 24–31 : one-hot substitution / steric class
Bits 32–63 : reserved
\`\`\`

Categories use one-hot bit masks so bitwise compatibility is meaningful.

## Legality

\[
\operatorname{legal}(u,k)
=
((m_u\&R_k)\neq0)\land((m_u\&F_k)=0).
\]

The legal result becomes the reaction-logit mask.

Protection and deprotection are explicit transitions. Atom provenance and stereochemical parity remain separate state tracked by the provenance module.

Integer bitwise operations are GPU-friendly, but they are not Tensor Core operations.

## Validation

Test legal/illegal handles, protection transitions, deprotection, provenance preservation, stereochemical conservation and termination for all 24 reaction classes.
