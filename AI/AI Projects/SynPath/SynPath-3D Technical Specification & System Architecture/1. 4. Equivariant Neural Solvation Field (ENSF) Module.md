# 1.4. Hydration Energy Neural Field (HENF) Module

HENF is the canonical runtime representation of local hydration thermodynamics.

## Design

\[
\Psi_\phi(r\mid\mathcal P)
\rightarrow
[\Delta\mu_{\mathrm{excess}}(r),g_O(r)].
\]

The module combines:

1. a global continuum GB-style polarization/desolvation component;
2. a local learned coordinate field for structured and frustrated hydration environments.

## Spatial encoding

For query position \(r\),

\[
d_j=\|x_j-r\|_2
\]

and local pocket states are filtered with smooth radial basis functions:

\[
z(r)=\sum_{j:d_j\le r_c}W(d_j)\odot h_{p,j}.
\]

A residual MLP produces the continuous outputs.

## Teacher data

Preferred teacher sources are explicit-solvent hydration data and GIST/WaterMap-style observables, supplemented by GB/SA quantities. 3D-RISM can provide controlled reference data but is no longer the required production inference pipeline.

## Interpretation

\(\Delta\mu_{\mathrm{excess}}(r)\) is a learned local hydration quantity. Candidate thresholds such as \(+1.5\) kcal/mol are calibration parameters and must be validated on held-out data.

HENF is not a direct experimental binding-free-energy predictor.
