# 1.7. Hierarchical Action Space: Reaction Selection and Two-Tier Synthon Retrieval

\[
z_t
\rightarrow
24\text{-class legal reaction}
\rightarrow
q_{\mathrm{target}}\in\mathbb R^{263}
\rightarrow
\operatorname{ANN}_{128}
\rightarrow
\text{contextual re-ranking}.
\]

The target profile is:

\[
q_{\mathrm{target}}
=
[e^*\Vert v_{\mathrm{exit}}^*\Vert V^*\Vert\mu^*]
\in\mathbb R^{263}.
\]

The catalog is first filtered for chemical/reaction legality. ANN retrieval then produces at most 128 candidates.

**ANN backend is not architecturally fixed.** HNSW is a valid CPU option; GPU-supported FAISS index families are valid alternatives. The implementation is chosen from measured recall/latency/memory results on the actual workstation.

The lookup is non-differentiable. Metric learning trains the continuous target space; contextual re-ranking learns pocket-conditioned preference over retrieved candidates.

STOP and deprotection are explicit legal actions, not hidden molecular-weight heuristics.
