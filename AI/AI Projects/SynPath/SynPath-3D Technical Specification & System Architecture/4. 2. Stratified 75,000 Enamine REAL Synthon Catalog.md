# 4.2. Stratified 75,000 Enamine REAL Synthon Catalog

The canonical SynPath-3D catalog contains up to 75,000 curated building blocks/synthons.

## Functional strata

| Stratum | Approximate planning allocation | Role |
|---|---:|---|
| Mono-functional caps | 45,000 | terminal scaffold decoration |
| Bi-functional linkers | 22,500 | propagation between regions |
| Multi-functional hubs | 7,500 | branching / specialized assembly |

These counts are curation targets. The catalog manifest, not the percentages, is authoritative.

## Descriptor index

Every catalog member receives a stable identifier and precomputed descriptors:

\[
k_j=[e_j\Vert v_{\mathrm{exit},j}\Vert V_j\Vert\mu_j].
\]

Where available, \(e_j\in R^{256}\) is the normalized molecular embedding. The remaining terms encode exit-vector geometry, size and an electronic descriptor.

The canonical retrieval path is:

\[
q_{\mathrm{target}}\rightarrow
\mathcal K_{\mathrm{legal}}
\rightarrow
\operatorname{ANN}_{128}
\rightarrow
\text{pocket-context re-ranking}.
\]

HNSW or FAISS is the implementation choice. The previous 2-D kd-tree / flat 75k softmax is not the production path.

## Catalog integrity

Each entry stores:

- stable catalog ID;
- molecular graph;
- reaction-handle annotations;
- protection state;
- descriptor version;
- provenance;
- validation status.

Catalog size and coverage are measured from the actual frozen manifest.
