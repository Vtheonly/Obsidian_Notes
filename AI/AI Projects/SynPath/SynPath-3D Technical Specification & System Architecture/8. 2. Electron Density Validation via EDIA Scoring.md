# 8.2. Electron Density Validation via EDIA Scoring

EDIA is used as a ligand electron-density quality metric.

A project profile may define acceptance criteria such as a ligand-level median EDIA threshold and an atom-level minimum threshold. These values are curation parameters and must be pinned in the dataset manifest.

For example, a strict profile can use:

\[
\operatorname{median}(\mathrm{EDIA}_{ligand})\ge0.75,
\qquad
\min(\mathrm{EDIA}_{ligand})\ge0.40.
\]

Do not collapse these two statistics into a single “EDIA ≥ 0.75” rule when reporting dataset counts.
