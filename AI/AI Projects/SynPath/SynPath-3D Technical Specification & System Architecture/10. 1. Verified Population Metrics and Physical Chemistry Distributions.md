# 10.1. Dataset Population Metrics and Physical Chemistry Distributions

This note is a statistics schema and reporting template. It must not mix planning targets with measured counts.

| Metric | Status |
|---|---|
| Raw PDB structures / complexes | read from acquisition manifest |
| Stage-0 structural samples | read from pretraining manifest; target may be 100k+ |
| Stage-1 experimental trajectories | read from curated trajectory manifest; project target may be ~30k |
| Stage-1 synthetic routes | read from synthetic-route manifest; project target may be ~500k |
| Transition states | derived from actual trajectory manifest |
| Catalog entries | derived from frozen catalog manifest; target up to 75k |
| Reaction classes | 24 certified classes |
| Train/validation/test split | derived from leakage-safe split manifest |
| Scaffold overlap | computed from the actual split |
| Protein sequence/structure overlap | computed from MMseqs2/Foldseek split manifests |

## Reporting rule

Every published number must include:

- source manifest/version;
- population definition;
- inclusion/exclusion criteria;
- split assignment;
- generation timestamp.

Numbers such as 47,800 raw complexes, 30,000 QC-passing structures or 20,000 trajectories are historical/planning values until reproduced by the current manifests.
