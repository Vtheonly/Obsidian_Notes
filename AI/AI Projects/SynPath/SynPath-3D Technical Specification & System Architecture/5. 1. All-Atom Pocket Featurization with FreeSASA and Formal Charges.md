# 5.1. All-Atom Pocket Featurization with FreeSASA, Charges, and Ensemble Context

Each pocket conformer is featurized independently before ensemble aggregation.

## Per-atom inputs

- atomic number / element;
- charge descriptor;
- residue and atom identity;
- FreeSASA surface descriptor;
- local geometric context;
- conformer identifier.

HENF is queried dynamically from coordinates when hydration information is needed. It is not treated as a permanent static atom feature.

## Ensemble tensor

\[
X_P\in\mathbb R^{K\times N_p\times3},
\qquad K\in[3,5].
\]

All conformers retain consistent atom identity where possible. Alternate locations and missing atoms are normalized before batching.

## Integrity checks

- protonation and charge provenance;
- alternate-location handling;
- duplicate detection;
- conformer alignment;
- leakage-safe target assignment.
