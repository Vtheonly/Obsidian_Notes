# 14.2. Module Specification: Inputs, Outputs, and Interfaces

| Module | Inputs | Outputs |
|---|---|---|
| EquiformerLightBackbone | pocket ensemble + atomic features | h_p, v_p |
| HydrationEnergyNeuralField | query coordinates + pocket states | delta_mu, g_O |
| ContinuousPharmacophoreDensityField | pocket states + query coordinates | Phi + adaptive targets |
| SpatialPlanner | handle + pocket + targets | z_t ∈ R^256 |
| ReactionHead | z_t + legal mask | 24 reaction logits |
| RetrievalHead | z_t + reaction | q_target ∈ R^263 |
| CatalogIndex | q_target + legal subset | top-128 IDs |
| CandidateReranker | candidates + pocket context | candidate/STOP logits |
| CompliantPoE | graph + joint state | coordinates + Jacobian |
| TorusFlow | torus state + conditioning | guided velocity |
| ConsensusReward | molecule + validation | terminal reward |

Every interface must define shape, dtype, device, masking semantics and gradient behavior.
