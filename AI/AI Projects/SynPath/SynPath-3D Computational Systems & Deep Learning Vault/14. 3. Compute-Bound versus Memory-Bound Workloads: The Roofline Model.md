# 14.3. Compute-Bound versus Memory-Bound Workloads: The Roofline Model

The Roofline model classifies kernels by arithmetic intensity:

\[
I=\frac{\mathrm{FLOPs}}{\mathrm{bytes\ transferred}}.
\]

For hardware peak compute \(P_{\mathrm{peak}}\) and memory bandwidth \(B_{\mathrm{peak}}\),

\[
I^*=\frac{P_{\mathrm{peak}}}{B_{\mathrm{peak}}}.
\]

## SynPath workloads

Memory-sensitive stages include sparse graph access, coordinate transforms, distance evaluation and ANN traversal.

Compute-heavy stages include dense projections, attention, equivariant mixing and top-128 candidate re-ranking.

There is no canonical 75k dense synthon dot-product head.

The model should be optimized from measured profiler traces rather than assumed arithmetic-intensity labels.
