# 20.2. Lab 2: Spatial Planner with CPDF Targets and Distance Bias

Implement the planning core that combines the reacting handle, pocket states, HENF context and adaptive CPDF targets.

Use invariant distance bias:

\[
A_{ij}=\frac{q_i^\top k_j}{\sqrt d}+b(\|x_i-x_j\|).
\]

The output planning state \(z_t\in\mathbb R^{256}\) must feed the reaction, retrieval and flow heads.
