# 15.2. VRAM Sizing Methodology for the 96 GB RTX 6000 Ada

A previous fixed B=64 calculation is no longer the canonical profile because ensemble conditioning changes activation scaling.

## Reference workload

\[
B=32,\quad K=3\text{–}5,\quad N_p^{max}\approx150.
\]

The exact activation footprint is measured from the real model.

A useful decomposition is:

\[
M_{\mathrm{VRAM}}
=
M_{\mathrm{params}}
+
M_{\mathrm{grads}}
+
M_{\mathrm{opt}}
+
M_{\mathrm{catalog}}
+
M_{\mathrm{activations}}
+
M_{\mathrm{workspace}}
+
M_{\mathrm{allocator}}.
\]

Activation memory scales approximately with batch, conformer count, hidden width, number of graph edges and query count. Therefore the conformer dimension cannot be treated as a constant-free implementation detail.

## Required benchmark output

Record allocated and reserved memory, peak memory by module, activation-checkpointing status and OOM margin. Do not state “safe” from a paper arithmetic estimate; verify on the actual graph.
