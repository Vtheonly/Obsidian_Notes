### 1. Mathematical Formulation
When training multiple heads concurrently (TIF Anchor Prediction $\mathcal{L}_{\text{TIF}}$, 24-Class Reaction Selection $\mathcal{L}_{\text{rxn}}$, 75k-Synthon Selection $\mathcal{L}_{\text{syn}}$, and Torsion Flow Matching $\mathcal{L}_{\text{flow}}$), a static linear combination $\sum \lambda_k \mathcal{L}_k$ often fails because task scales drift during training.

We parameterize multi-task loss using **Homoscedastic Task Uncertainty (Kendall et al., 2018)**. We define a learnable log-variance parameter $s_k = \log \sigma_k^2$ for each task:
$$\mathcal{L}_{\text{total}}(s) = \frac{1}{2} e^{-s_{\text{TIF}}}\mathcal{L}_{\text{TIF}} + e^{-s_{\text{rxn}}}\mathcal{L}_{\text{rxn}} + e^{-s_{\text{syn}}}\mathcal{L}_{\text{syn}} + \frac{1}{2}e^{-s_{\text{flow}}}\mathcal{L}_{\text{flow}} + \frac{1}{2}\sum_{k} s_k + \lambda_{\text{reg}}\sum_k s_k^2$$
* As a task becomes noisy or difficult, its associated variance $s_k$ increases, reducing its gradient contribution.
* The penalty term $\frac{1}{2} s_k$ prevents $s_k \to \infty$.
* The $L_2$ regularization term $\lambda_{\text{reg}} \sum s_k^2$ ($\lambda_{\text{reg}} = 10^{-4}$) keeps log-variance parameters bounded.
