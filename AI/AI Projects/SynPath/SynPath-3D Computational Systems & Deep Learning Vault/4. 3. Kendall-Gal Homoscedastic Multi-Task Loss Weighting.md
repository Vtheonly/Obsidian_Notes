# 4.3. Kendall-Gal Homoscedastic Multi-Task Loss Weighting

Kendall-Gal weighting is used to balance Stage-1 tasks with different numerical scales.

The canonical Stage-1 task set is:

\[
\{\mathcal L_{\mathrm{CPDF}},
\mathcal L_{\mathrm{rxn}},
\mathcal L_{\mathrm{InfoNCE}},
\mathcal L_{\mathrm{flow}},
\mathcal L_{\mathrm{elastic}}\}.
\]

A representative weighted objective is:

\[
\mathcal L
=
\sum_k w_k(s_k)\mathcal L_k
+
\mathcal R(s),
\]

where \(s_k=\log\sigma_k^2\) and the exact coefficients follow the Stage-1 objective note.

The labels TIF and flat 75k synthon classification are historical names and are not current Stage-1 task definitions.

Monitor learned variances for collapse, saturation and task starvation.
