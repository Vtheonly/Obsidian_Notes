# 12.3. End-to-End Gradient Propagation in the Revised Architecture

Stage 0 gradients train the pocket encoder through structural self-supervision.

Stage 1 gradients flow through backbone → HENF/CPDF/planner → reaction/retrieval/flow heads → multi-task objective.

The ANN retrieval operation is discrete and therefore does not receive gradient through index selection. Metric learning supervises the query space and the contextual re-ranker learns over the retrieved support.

Stage 2 gradients optimize the GFlowNet objective over legal retrieved actions.

Physical guidance is differentiable through:

\[
J^\top\nabla_xV_{\mathrm{rep}}.
\]

There is no production gradient path through a DLS correction or MMFF94s optimizer.
