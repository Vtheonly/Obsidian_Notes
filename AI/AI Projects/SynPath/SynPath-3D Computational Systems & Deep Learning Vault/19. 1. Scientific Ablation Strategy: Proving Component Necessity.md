# 19.1. Scientific Ablation Strategy: Proving Component Necessity

Ablations test whether an architectural component contributes measurable value under matched conditions.

## Core suite

| ID | Ablation | Primary measurements |
|---|---|---|
| ABL-01 | CPDF vs fixed-anchor/blind-growth baseline | target recall, pocket span, geometric validity |
| ABL-02 | HENF vs no hydration field | hydration calibration, downstream quality |
| ABL-03 | compliant PoE vs rigid-angle baseline | clash rate, strain, geometric validity |
| ABL-04 | hierarchical retrieval vs flat catalog baseline | recall@128, catalog coverage, diversity |
| ABL-05 | pruned SubTB + gates vs unpruned/soft-reward baseline | convergence, invalid trajectories, entropy |

## Required controls

Also compare:

- ensemble vs single-state pocket conditioning;
- pretrained vs randomly initialized backbone;
- guided vs unguided torus flow;
- four ODE steps vs higher-step reference;
- external MMFF/DLS relaxation as an explicit baseline only.

Use identical data splits, training budgets and evaluation code. Prefer multiple seeds and confidence intervals where compute permits.

No predefined percentage gain is considered a scientific fact before measurement.
