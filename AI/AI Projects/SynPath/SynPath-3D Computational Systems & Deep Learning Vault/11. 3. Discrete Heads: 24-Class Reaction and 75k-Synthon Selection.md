# 11.3. Discrete Heads: Reaction Selection and Hierarchical Synthon Retrieval

The discrete policy is:

\[
z_t
\rightarrow
24\text{-class legal reaction}
\rightarrow
q_{\mathrm{target}}\in\mathbb R^{263}
\rightarrow
\operatorname{ANN}_{128}
\rightarrow
\text{contextual re-ranking}.
\]

The 263 dimensions are:

\[
256\text{-D chemical embedding}
+
3\text{-D exit vector}
+
1\text{-D volume}
+
3\text{-D electronic descriptor}.
\]

Catalog filtering occurs before approximate-nearest-neighbor search.

The production system must not require GPU HNSW specifically. HNSW is a CPU index in common FAISS deployments; GPU-supported FAISS index families are alternatives. Benchmark the chosen implementation rather than assuming a fixed backend.

The flat 75k-way softmax is a historical ablation baseline only.
