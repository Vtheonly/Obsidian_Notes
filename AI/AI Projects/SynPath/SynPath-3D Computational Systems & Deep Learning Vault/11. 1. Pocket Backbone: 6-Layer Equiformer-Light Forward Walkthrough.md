### 1. Structural Walkthrough
The backbone processes the pocket point cloud and continuous physical chemistry fields into node representations.

```text
Equiformer-Light Execution Pipeline:
1. Input Extraction:
   Pocket Coordinates:       X_P ∈ ℝ^(N_p x 3)
   Atomic Numbers:           Z_P ∈ ℕ^(N_p)
   Physiological Charges:    q_P ∈ {-1, -0.5, 0, +0.5, +1}^(N_p)
   Atomic SASA:              SASA_P ∈ ℝ^(N_p)
   ENSF Solvation Potential: Δμ_P ∈ ℝ^(N_p)

2. Node Feature Initialization:
   s_i^(0) = LayerNorm( W_z E(Z_i) + W_q q_i + W_sasa RBF(SASA_i) + W_solv Δμ_i ) ∈ ℝ^256
   v_i^(0) = 0 ∈ ℝ^(3 x 64)

3. Spatial Graph Construction:
   Radius Graph Construction: Edges (i, j) where ||x_i - x_j|| ≤ r_cut (6.0 Å)
   Radial Expansion:          e_ij = BesselRBF(||x_i - x_j||) ∈ ℝ^32
   Directional Vectors:       u_ij = (x_j - x_i) / ||x_j - x_i|| ∈ 𝕊^2

4. Six Layer Message Passing:
   For layer l = 1 to 6:
     s_i^(l), v_i^(l) = EquiLayer( s_i^(l-1), v_i^(l-1), e_ij, u_ij )
   
5. Output Representations:
   Pocket Invariant Node Features: h_p = s^(6) ∈ ℝ^(N_p x 256)
   Pocket Equivariant Field:       v_p = v^(6) ∈ ℝ^(N_p x 3 x 64)
```
