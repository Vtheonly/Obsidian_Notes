# 20.1. Lab 1: Ensemble Pocket Embedding and Radial Features

Implement the per-conformer atom embedding and smooth radial basis features used by the Equiformer-Light backbone.

The lab must preserve an explicit conformer dimension \(K\in[3,5]\) and test permutation-invariant ensemble pooling.

Inputs include atom identity, charge/context descriptors, SASA and local geometry. HENF is queried dynamically rather than treated as an obsolete static ENSF feature.
