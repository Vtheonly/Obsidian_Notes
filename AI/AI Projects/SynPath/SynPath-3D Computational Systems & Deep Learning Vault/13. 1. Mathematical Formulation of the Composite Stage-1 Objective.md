# 13.1. Mathematical Formulation of the Revised Stage-1 Objective

\[
\mathcal L_1=
\lambda_c\mathcal L_{\mathrm{CPDF}}+
\lambda_r\mathcal L_{\mathrm{rxn}}+
\lambda_t\mathcal L_{\mathrm{InfoNCE}}+
\lambda_f\mathcal L_{\mathrm{flow}}+
\lambda_e\mathcal L_{\mathrm{elastic}}.
\]

CPDF uses a class-imbalanced spatial objective. Reaction selection uses focal cross-entropy. Retrieval target learning uses InfoNCE over synthon descriptors. Flow matching uses wrapped torus velocity error plus compliant-angle regularization.

Kendall-Gal homoscedastic weighting is an optional balancing mechanism.

Every component is monitored independently.
