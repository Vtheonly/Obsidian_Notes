### 1. Detailed Loss Formulations
During Stage 1 behavioral cloning on verified crystal trajectories, the network optimizes four loss terms balanced via Kendall-Gal homoscedastic uncertainty:
$$\mathcal{L}_{\text{Stage1}} = \frac{1}{2} e^{-s_{\text{TIF}}} \mathcal{L}_{\text{TIF}} + e^{-s_{\text{rxn}}} \mathcal{L}_{\text{rxn}} + e^{-s_{\text{syn}}} \mathcal{L}_{\text{syn}} + \frac{1}{2} e^{-s_{\text{flow}}} \mathcal{L}_{\text{flow}} + \frac{1}{2}(s_{\text{TIF}} + s_{\text{rxn}} + s_{\text{syn}} + s_{\text{flow}}) + 10^{-4}\sum_k s_k^2$$

#### 1. Target-Interaction Field Loss ($\mathcal{L}_{\text{TIF}}$)
Evaluated between $M=5$ predicted anchors and ground-truth ligand pharmacophores using Hungarian bipartite matching:
$$\mathcal{L}_{\text{TIF}} = \min_{\sigma \in \mathcal{S}_M} \sum_{m=1}^M \left[ \|\vec{x}_m - \vec{x}_{\sigma(m)}^*\|_2^2 + (1 - \cos(\mathbf{R}_m, \mathbf{R}_{\sigma(m)}^*)) + \text{CE}(\vec{\tau}_m, \vec{\tau}_{\sigma(m)}^*) + |\Delta G_m - \Delta G_{\sigma(m)}^*| \right]$$

#### 2. Reaction Class Focal Loss ($\mathcal{L}_{\text{rxn}}$)
$$\mathcal{L}_{\text{rxn}} = -\alpha_{r^*} (1 - P(r^*))^\gamma \log P(r^*), \quad \gamma = 2.0$$

#### 3. Synthon Selection Cross-Entropy ($\mathcal{L}_{\text{syn}}$)
$$\mathcal{L}_{\text{syn}} = -\log P(B^* \mid r^*, u, \mathbf{z}_t) = -\log \left( \frac{\exp\left( \frac{(\mathbf{W}_q \mathbf{z}_t) \mathbf{E}_{B^*}^T}{\sqrt{d}} \right)}{\sum_{k \in \text{Legal}} \exp\left( \frac{(\mathbf{W}_q \mathbf{z}_t) \mathbf{E}_{B_k}^T}{\sqrt{d}} \right)} \right)$$

#### 4. Riemannian Torus Flow Matching Loss ($\mathcal{L}_{\text{flow}}$)
$$\mathcal{L}_{\text{flow}} = \mathbb{E}_{s \sim \mathcal{U}(0,1), \, \vec{\phi}_0 \sim \mathcal{U}(\mathbb{T}^K)} \left[ \sum_{k=1}^K \min\left( |v_{\theta, k}(\vec{\phi}_s, s) - u_k^*|, \, 2\pi - |v_{\theta, k}(\vec{\phi}_s, s) - u_k^*| \right)^2 \right]$$
where $u_k^* = \text{wrap}(\phi_{1, k}^* - \phi_{0, k})$.
