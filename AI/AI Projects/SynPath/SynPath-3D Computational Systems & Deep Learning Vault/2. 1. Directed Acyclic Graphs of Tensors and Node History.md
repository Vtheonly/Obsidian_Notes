# 2.1. Directed Acyclic Graphs of Tensors and Node History

PyTorch constructs a dynamic computational graph during the forward pass. Each differentiable operation contributes a backward node, allowing reverse-mode differentiation of a scalar loss.

For SynPath-3D examples, the canonical reference batch is B=32, but the mathematical principles are batch-size independent.

\[
\frac{\partial\mathcal L}{\partial x_i}
=
\sum_j
\frac{\partial\mathcal L}{\partial y_j}
\frac{\partial y_j}{\partial x_i}.
\]

The project-specific tensors and shapes are defined by the canonical tensor manifest, not by this educational example.

Use the current architecture's planning state, retrieval target and torus-flow tensors when illustrating real model traces.
