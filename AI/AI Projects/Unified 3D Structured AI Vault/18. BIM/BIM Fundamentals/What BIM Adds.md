# What BIM Adds (Over Pure 3D Geometry)

> BIM = Geometry + Semantics + Properties + Relationships + Hierarchy + Spatial Containment + Domain Information.

## The Seven Pillars

```mermaid
mindmap
  root((BIM))
    Geometry
      Extrusions
      Sweeps
      CSG
      Parametric Surfaces
    Semantics
      Element Types
      Classifications
      Names
    Properties
      Property Sets
      Quantity Sets
      Attributes
    Relationships
      Containment
      Connectivity
      Type Assignment
      Material Association
    Hierarchy
      Site
      Building
      Storey
      Space
      Element
    Spatial Containment
      Each Element in a Space
      Each Space in a Storey
      Each Storey in a Building
    Domain Information
      Structural
      Thermal
      Acoustic
      Cost
      Schedule
      Code Compliance
```

## Implication for AI

A BIM-aware AI must handle all seven aspects, not just geometry. A model that only generates geometry is **not** a BIM generator.

See [[BIM Fundamentals]], [[BIM Generation]], [[BIM Validation]].
