# Type Assignment

> Each element is assigned a **type** that defines shared properties among all instances of that type.

See [[Type vs Occurrence]] for the full content.

## Quick Recap

- `IfcRelDefinesByType`: element → type.
- A type holds shared properties (fire rating, material, default dimensions).
- An occurrence holds instance-specific data (placement, override properties).
