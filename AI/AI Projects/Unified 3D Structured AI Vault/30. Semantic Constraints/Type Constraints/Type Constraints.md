# Type Constraints

> **Definition.** Constraints on the type of an element: a "door" must have door-like geometry, behavior, and properties.

## Examples

- A door has a width in [0.7, 1.2] m, height in [1.9, 2.4] m.
- A door has a swing direction.
- A door connects two spaces.
- A window has a transparent part (glass).
- A wall has thickness > 0.

## Enforcement

- Type-specific validators.
- Geometry classification (does the geometry look like a door?).

See [[Semantic Constraints]], [[Semantic Validation]].
