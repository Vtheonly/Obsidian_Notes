# Glossary — Awareness Terms

| Term                  | Definition                                                                  |
| --------------------- | --------------------------------------------------------------------------- |
| Structure-aware       | Model uses information about how output is organized.                       |
| Tree-aware            | Model uses hierarchical parent-child relationships.                         |
| 3D-aware              | Model uses 3D geometric / spatial information.                              |
| Hierarchy-aware       | Model uses multiple levels of abstraction.                                  |
| Graph-aware           | Model uses arbitrary pairwise relations (graph).                            |
| Spatially-aware      | Model uses positions, extents, orientations.                                |
| Geometry-aware        | Model uses lengths, angles, areas, volumes, geometric relations.           |
| Semantic-aware        | Model uses types, attributes, semantic relations.                          |
| Topology-aware        | Model uses connectivity, adjacency, containment (independent of metric).    |
| Syntax-aware          | Model uses grammatical/syntactic relationships.                             |
| Layout-aware          | Model uses spatial/layout relationships.                                    |
| AST-aware             | Model uses the abstract syntax tree of code.                                |
| Hard guarantee        | Property cannot be violated.                                                |
| Statistical preference| Property is preferred but not guaranteed.                                   |
| Explicit structure    | Structure is a data structure (edges, masks, parent pointers).             |
| Implicit structure    | Structure is only in the data distribution or model behavior.               |
