# Glossary — BIM Terms

| Term              | Definition                                                          |
| ----------------- | ------------------------------------------------------------------- |
| BIM               | Building Information Modeling.                                      |
| IFC               | Industry Foundation Classes; open BIM standard.                     |
| IfcSite           | Top-level spatial element (a plot of land).                         |
| IfcBuilding       | A single building.                                                  |
| IfcBuildingStorey | A floor / level.                                                    |
| IfcSpace          | A volume bounded by elements (a room).                              |
| IfcElement        | A physical building element (wall, slab, door, etc.).               |
| IfcWall           | Vertical barrier.                                                   |
| IfcSlab           | Horizontal plane (floor, roof).                                     |
| IfcColumn         | Vertical load-bearing element.                                      |
| IfcBeam           | Horizontal load-bearing element.                                    |
| IfcDoor           | Opening that allows passage.                                        |
| IfcWindow         | Opening that allows light.                                          |
| IfcRelAggregates  | Whole → parts relationship.                                         |
| IfcRelContainedInSpatialStructure | Element → space containment.                          |
| IfcRelConnectsElements | Generic connection between elements.                            |
| IfcRelDefinesByType | Element → type assignment.                                        |
| IfcRelDefinesByProperties | Element → property set.                                    |
| IfcRelAssociatesMaterial | Element → material.                                         |
| IfcRelSpaceBoundary | Space bounded by element.                                         |
| IfcRelVoidsElement | Element has opening.                                               |
| IfcRelFillsElement | Opening filled by element.                                         |
| PropertySet       | Key-value property collection.                                      |
| ElementQuantity   | Measurable quantities (area, volume).                               |
| MaterialLayerSet  | Material composition (e.g. wall layers).                            |
| Type vs Occurrence | Type = shared definition; occurrence = instance.                   |

See [[04. BIM MOC]].
