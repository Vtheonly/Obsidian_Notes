# Glossary — 3D Terms

| Term               | Definition                                                          |
| ------------------ | ------------------------------------------------------------------- |
| Point cloud        | Set of 3D points with optional attributes.                          |
| Voxel              | 3D pixel; cell in a regular 3D grid.                                |
| Occupancy grid     | Voxel grid with binary (or probabilistic) occupancy.                |
| TSDF               | Truncated Signed Distance Function.                                 |
| SDF                | Signed Distance Function.                                           |
| Mesh               | Vertices, edges, faces.                                             |
| Manifold           | Locally homeomorphic to a disk.                                     |
| Watertight         | Closed surface (every edge has 2 faces).                            |
| B-rep              | Boundary representation.                                            |
| CSG                | Constructive Solid Geometry.                                        |
| Implicit surface   | Surface defined by $f(p) = 0$.                                      |
| Neural field       | Neural network representing a continuous field over 3D space.       |
| NeRF               | Neural Radiance Field.                                              |
| Camera intrinsics  | Focal length, principal point.                                      |
| Camera extrinsics  | Rotation + translation (camera-to-world).                           |
| Back-projection    | Convert (pixel, depth) to 3D point.                                 |
| Multi-view stereo  | Reconstruct 3D from multiple images.                                |
| SfM                | Structure from Motion.                                              |
| ICP                | Iterative Closest Point (registration).                            |
| Marching Cubes     | Extract mesh from SDF / TSDF.                                       |
| Chamfer distance   | Distance between two point sets.                                    |
| Epipolar geometry  | Geometry of two-camera views.                                       |
| Fundamental matrix | Relates corresponding points in two views.                          |
