# Glossary — Clustering Terms

| Term                  | Definition                                                       |
| --------------------- | ---------------------------------------------------------------- |
| K-Means               | Partition n points into k clusters minimizing variance.          |
| DBSCAN                | Density-based clustering; finds arbitrary shapes.                |
| HDBSCAN               | Hierarchical DBSCAN; handles varying density.                    |
| OPTICS                | Produces cluster ordering.                                       |
| Hierarchical clustering | Builds a tree of clusters (dendrogram).                       |
| Spectral clustering   | Clusters via eigenvectors of graph Laplacian.                    |
| Graph community detection | Finds densely connected groups in a graph.                 |
| Embedding-based clustering | Cluster in learned embedding space.                       |
| Deep clustering       | Joint learning of embeddings and assignments.                    |
| Motif                 | Recurring structural pattern.                                    |
| Subtree discovery     | Find recurring subtrees.                                         |
| Subgraph discovery    | Find recurring subgraphs.                                        |
| MDL                   | Minimum Description Length; model selection principle.           |
| Grammar induction     | Learn grammar rules from examples.                               |
| Program induction     | Infer a program from examples / structure.                       |
| Recursive discovery   | Discover components at multiple scales, recursively.             |
| Component abstraction | Replace instances with type references.                          |
| Hierarchical concept discovery | Discover concepts at multiple levels of abstraction.   |
