# Glossary — Tree Terms

| Term          | Definition                                                       |
| ------------- | ---------------------------------------------------------------- |
| Node          | An element of a tree.                                            |
| Edge          | A link between two nodes.                                        |
| Root          | The unique node with no parent.                                  |
| Leaf          | A node with no children.                                         |
| Parent        | The node directly above a given node.                            |
| Child         | A node directly below a given node.                              |
| Sibling       | A node sharing the same parent.                                  |
| Ancestor      | Any node on the path from root to a given node.                  |
| Descendant    | Any node reachable by descending from a given node.              |
| Depth         | Distance (edge count) from root.                                 |
| Height        | Distance from node to deepest descendant.                        |
| Subtree       | A node and all its descendants.                                  |
| Degree        | Number of children.                                              |
| Ordered tree  | Children order matters.                                          |
| N-ary tree    | Each node has at most n children.                                |
| Binary tree   | N-ary with n = 2.                                                |
| Parse tree    | Tree from a formal grammar parse.                                |
| AST           | Abstract Syntax Tree; abstracts away syntactic sugar.            |
| Expression tree | Tree of math operators and operands.                          |
| Feature tree  | Construction history of a CAD model.                             |
| Tree edit distance | Minimum edits to transform one tree into another.          |
