# COMPAS Framework

> **COMPAS** is an open-source Python framework for computation and research in architecture and engineering.

## Features

- Geometric primitives (points, vectors, lines, planes, meshes).
- Data structures (networks, meshes, volmeshes).
- Algorithms (mesh processing, graph algorithms, optimization).
- Interoperability (IFC, Rhino, Blender).
- Visualization (matplotlib, three.js).

## Use in AI

- Build geometric features for ML.
- Convert between representations (mesh ↔ graph ↔ tree).
- Implement validation checks.
- Build synthetic data generators.

## Installation

```bash
pip install compas
pip install compas_view2  # for visualization
```
