# Building Topology

> The topology of a building: connectivity, adjacency, containment, incidence — independent of metric positions.

See [[Why Buildings Are Not Purely Trees]], [[Topological Relations]], [[Adjacency and Containment]] for the canonical treatments.

## Quick Map

```mermaid
mindmap
  root((Building Topology))
    Containment
      Site contains Building
      Building contains Storey
      Storey contains Space
      Space contains Element
    Adjacency
      Room to Room
      Wall to Wall
      Wall to Slab
    Connectivity
      Door connects Spaces
      Stair connects Storeys
      Beam connects Columns
    Support
      Column supports Beam
      Wall supports Slab
      Foundation supports Wall
```
