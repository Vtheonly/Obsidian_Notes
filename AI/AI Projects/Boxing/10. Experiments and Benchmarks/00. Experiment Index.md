# Experiment and Benchmark Index

This area stores measured evidence. It must not contain invented benchmark results.

## Required Benchmark Families

### Pose Benchmark

Measure:

- latency per inference
- effective FPS
- keypoint stability
- confidence
- wrist/ankle accuracy
- occlusion behavior
- memory

### Temporal Model Benchmark

Compare:

- rules only
- lightweight temporal baseline
- ST-GCN
- ST-GCN + Tiny Transformer

Measure:

- movement classification
- phase classification
- false positives
- false negatives
- latency
- memory

### DTW Benchmark

Measure:

- unconstrained DTW
- Sakoe-Chiba DTW

Measure:

- latency
- memory
- alignment quality
- sensitivity to speed differences

### Quantization Benchmark

Compare:

- FP32
- FP16
- INT8 PTQ
- INT8 QAT where justified

Measure:

- model size
- latency
- RAM
- accuracy
- thermal behavior

### Runtime Benchmark

Compare:

- ONNX Runtime Mobile
- LiteRT when required

Measure:

- median
- P95
- P99
- sustained performance
- battery and temperature

## Acceptance Rule

Performance claims in the project report should be labeled as either:

- design target
- external published reference
- measured device result

These categories must never be conflated.
