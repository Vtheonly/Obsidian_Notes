# Technical Decisions and Open Questions

## Current Decisions

| Area | Current baseline | Status |
|---|---|---|
| Camera | CameraX | Chosen baseline |
| Pose | RTMPose-S | Chosen baseline |
| Filtering | One Euro + confidence handling | Chosen baseline |
| Normalization | Body-relative coordinates | Chosen baseline |
| Local motion model | ST-GCN-style encoder | Chosen baseline |
| Temporal model | Tiny causal transformer | Chosen baseline |
| Offline teacher | MotionBERT/DSTformer-style candidate | Research choice |
| Temporal alignment | DTW | Chosen baseline |
| Reference model | Multi-athlete distribution | Chosen baseline |
| Mobile runtime | ONNX Runtime Mobile first | First deployment candidate |
| Compression | FP32 → FP16/INT8 evaluation | Benchmark decision |
| Target | Galaxy A30s / Exynos 7904 | Fixed test target |

## Open Questions

### Pose Topology

Is the generic 17-keypoint skeleton sufficient, or does the system need:

- glove endpoints
- heel points
- metatarsal points
- dedicated chin
- additional torso landmarks

### 2D vs 3D

How much of the desired boxing analysis can be performed robustly from monocular 2D pose?

Which techniques genuinely benefit from an estimated 3D representation?

### Boxing Pose Model

How much does boxing-specific fine-tuning improve wrist, elbow, ankle, and occlusion stability over the generic model?

### Motion Model

Does ST-GCN + Tiny Transformer materially outperform simpler temporal baselines on the actual dataset?

### Reference Distribution

Is a Gaussian model adequate, or are mixtures, normalizing flows, prototypes, or learned reference embeddings required?

### Scoring

Which scoring components correlate with expert judgments strongly enough to expose them to users?

### Feedback

How should feedback timing be tuned so it is immediate enough to help but does not interrupt execution?

### Mobile Runtime

Which runtime/backend provides the lowest P95/P99 latency on the physical A30s?

### Thermal Behavior

How quickly does sustained inference throttle, and how much does adaptive frame reduction improve session stability?

### Camera Constraints

What camera distance, room lighting, clothing, and background conditions produce unacceptable keypoint confidence?

## Rule

No architecture parameter should become a permanent specification merely because it appears in an early design document. Device benchmarks and labeled data determine final values.
