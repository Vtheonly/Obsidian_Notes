# Dataset and Annotation Specification

## Training Sample

A training repetition should preserve:

- source video
- timestamp range
- pose keypoints
- keypoint confidence
- movement label
- stance
- side
- phase labels
- timing
- technique annotations

Example logical record:

| Field | Example |
|---|---|
| movement | jab |
| stance | orthodox |
| side | lead |
| phase | preparation → initiation → acceleration → peak → recovery |
| rear_hand_low | false |
| excessive_lean | false |
| elbow_flare | true |
| recovery_slow | false |

## Movement Classes

Initial labels:

- stance
- guard
- jab
- cross
- lead hook
- rear hook
- lead uppercut
- rear uppercut
- slip left
- slip right
- roll
- pull back
- step back
- lateral step
- pivot

## Phase Labels

Each punch can use:

1. preparation
2. initiation
3. acceleration
4. peak extension
5. retraction/recovery

Exact boundaries should be annotated consistently and later validated against model segmentation.

## Technique Error Labels

Useful labels:

- rear hand dropped
- lead hand dropped
- elbow flare
- excessive torso lean
- poor recovery
- foot crossing
- unstable base
- excessive stance narrowing
- excessive stance widening
- trajectory deviation
- poor timing

## Expert Annotation

Expert labels define what the model should consider technically meaningful.

A statistical reference distribution alone is not enough. An expert annotation layer is needed to distinguish harmless individual variation from meaningful technical errors.

## Dataset Splits

Do not randomly split repetitions from the same athlete across train and validation without checking leakage.

Preferred principle:

athletes used for validation/test should remain unseen during training when measuring generalization to new people.

## Augmentation

Potential augmentation dimensions:

- camera distance
- image scale
- translation
- mild rotation
- controlled noise
- motion blur
- temporary keypoint dropout
- confidence degradation

Augmentation must preserve the semantic label.

## Quality Assurance

Every dataset revision should check:

- missing frames
- invalid keypoints
- confidence anomalies
- label consistency
- phase ordering
- impossible timestamps
- duplicate samples
- athlete leakage
- annotation disagreement

## Licensing

Every external dataset, video source, model, and third-party asset must be reviewed individually for training and redistribution permissions before commercial use.
