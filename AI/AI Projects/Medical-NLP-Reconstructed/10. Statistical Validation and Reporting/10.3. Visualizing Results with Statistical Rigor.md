# 10.3. Visualizing Results with Statistical Rigor

The original vault's Chapter 10.3 focused on **aesthetics** (Seaborn themes, rotated labels, color palettes) but did not require **confidence intervals (CIs)** or **error bars** on performance plots. The audit identified this as a **high-severity** gap: presenting a bar chart comparing Top-1 Accuracy across models without 95% confidence intervals is a **scientific validation error**. Without CIs, a reviewer cannot determine whether the performance difference between BioBERT and PubMedBERT is statistically significant or merely due to random variance.

This note covers: (1) why confidence intervals are mandatory, (2) the bootstrap method for computing CIs, (3) the standard error bar, (4) Seaborn standards for clinical NLP plots, (5) the three plot types used in the project (bar, violin, heatmap), and (6) the full plotting code.

---

## 1. Why Confidence Intervals Are Mandatory

Consider this comparison:

| Model | Top-1 Accuracy |
| :--- | :--- |
| BioBERT | 0.91 |
| PubMedBERT | 0.93 |

PubMedBERT appears to outperform BioBERT by 2 percentage points. But without confidence intervals, we cannot tell whether:

- **PubMedBERT is genuinely better** (the 2-point gap is real and would replicate on a new test set).
- **The gap is noise** (the 2-point difference is within the random variance of the 200-note test set, and a different test set might show BioBERT ahead).

A 95% confidence interval answers this question. If the CIs are:

| Model | Top-1 Accuracy | 95% CI |
| :--- | :--- | :--- |
| BioBERT | 0.91 | [0.87, 0.94] |
| PubMedBERT | 0.93 | [0.89, 0.96] |

The CIs overlap substantially, so the 2-point gap is **not statistically significant** — it could be noise. If the CIs were:

| Model | Top-1 Accuracy | 95% CI |
| :--- | :--- | :--- |
| BioBERT | 0.91 | [0.89, 0.93] |
| PubMedBERT | 0.93 | [0.91, 0.95] |

The CIs still overlap, but the gap is more likely to be real. A formal hypothesis test (Mann-Whitney, Chapter 10.1) would resolve the question.

### 1.1. The Rule

**Every performance plot must include confidence intervals or error bars.** A plot without them is incomplete and would be rejected by any clinical journal or technical review.

## 2. The Bootstrap Method for Confidence Intervals

The **bootstrap** (Efron, 1979) is a non-parametric method for computing confidence intervals that does not assume a normal distribution. It works by **resampling with replacement** from the observed data.

### 2.1. The Algorithm

For a metric $M$ (e.g., Top-1 Accuracy) computed on a test set of $N$ notes:

1. **Resample**: Draw $N$ notes from the test set **with replacement** to form a bootstrap sample.
2. **Compute**: Compute $M$ on the bootstrap sample.
3. **Repeat**: Steps 1–2 $B = 10{,}000$ times to get $B$ bootstrap estimates $M_1^*, M_2^*, \dots, M_B^*$.
4. **Percentile CI**: The 95% CI is the 2.5th and 97.5th percentiles of the bootstrap distribution.

### 2.2. Why Bootstrap?

- **No distributional assumption**: Works for any metric (accuracy, MRR, NDCG) regardless of its distribution.
- **Works for small samples**: Even with $N = 30$, the bootstrap produces reasonable CIs.
- **Easy to implement**: A few lines of Python.

### 2.3. The Code

```python
import numpy as np

def bootstrap_ci(metric_fn, data, n_bootstrap=10000, ci=0.95):
    """
    Compute bootstrap confidence interval for a metric.
    
    Args:
        metric_fn: function that takes a list of data and returns a scalar metric
        data: list of data points (e.g., per-note accuracy)
        n_bootstrap: number of bootstrap samples
        ci: confidence level (0.95 for 95% CI)
    Returns:
        (metric_value, ci_lower, ci_upper)
    """
    data = np.asarray(data)
    n = len(data)
    
    # Original metric value
    metric_value = metric_fn(data)
    
    # Bootstrap samples
    bootstrap_metrics = []
    for _ in range(n_bootstrap):
        sample = np.random.choice(data, size=n, replace=True)
        bootstrap_metrics.append(metric_fn(sample))
    
    # Percentile CI
    alpha = (1 - ci) / 2
    ci_lower = np.percentile(bootstrap_metrics, 100 * alpha)
    ci_upper = np.percentile(bootstrap_metrics, 100 * (1 - alpha))
    
    return metric_value, ci_lower, ci_upper

# Example: Top-1 Accuracy with CI
per_note_correct = [1, 0, 1, 1, 0, ...]  # 1 if correct at rank 1, else 0
acc, ci_lo, ci_hi = bootstrap_ci(np.mean, per_note_correct)
print(f"Top-1 Accuracy: {acc:.3f} [{ci_lo:.3f}, {ci_hi:.3f}]")
```

## 3. The Standard Error Bar

For normally-distributed metrics, the **standard error** (SE) is an alternative to the bootstrap CI:

$$\text{SE} = \frac{\sigma}{\sqrt{N}}$$

where $\sigma$ is the sample standard deviation and $N$ is the sample size. The 95% CI is approximately $\text{mean} \pm 1.96 \cdot \text{SE}$.

### 3.1. When to Use SE vs. Bootstrap

- **SE**: When the metric is approximately normal (e.g., mean of a large sample).
- **Bootstrap**: When the metric is non-normal or is a complex function (e.g., NDCG, MRR).

For the project, the bootstrap is preferred because NDCG and MRR are non-normal.

## 5. The Three Plot Types

### 5.1. Bar Chart with Confidence Intervals

Used to compare Top-1 Accuracy across the five embedding models.

```python
def plot_accuracy_with_ci(model_results):
    """
    model_results: dict {model_name: (accuracy, ci_lower, ci_upper)}
    """
    models = list(model_results.keys())
    accs = [model_results[m][0] for m in models]
    ci_los = [model_results[m][0] - model_results[m][1] for m in models]
    ci_his = [model_results[m][2] - model_results[m][0] for m in models]
    
    fig, ax = plt.subplots()
    bars = ax.bar(models, accs, yerr=[ci_los, ci_his],
                  capsize=5, color=sns.color_palette('colorblind')[:len(models)],
                  edgecolor='black', linewidth=0.5)
    
    ax.set_ylabel('Top-1 Accuracy')
    ax.set_title('Top-1 Accuracy by Embedding Model (with 95% CI)')
    ax.set_ylim(0, 1)
    plt.xticks(rotation=25, ha='right')
    
    # Add value labels on bars
    for bar, acc in zip(bars, accs):
        ax.text(bar.get_x() + bar.get_width()/2, bar.get_height() + 0.02,
                f'{acc:.3f}', ha='center', va='bottom', fontsize=10)
    
    plt.tight_layout()
    return fig
```

def plot_similarity_heatmap(similarity_matrix, patient_ids, disease_ids):

    similarity_matrix: (N_patients, N_diseases) matrix

    ax.set_title('Patient-Disease Lin Similarity Matrix')
    plt.xticks(rotation=45, ha='right')
    plt.yticks(rotation=0)
    
    plt.tight_layout()
    return fig

## 6. Statistical Annotation on Plots

For comparisons between models, add **statistical annotations** indicating whether the difference is significant:

```python
def add_significance_bracket(ax, x1, x2, y, p_value):
    """Add a significance bracket between two bars."""
    if p_value < 0.001:
        sig_text = '***'
    elif p_value < 0.01:
        sig_text = '**'
    elif p_value < 0.05:
        sig_text = '*'
    else:
        sig_text = 'n.s.'
    
    # Draw bracket
    ax.plot([x1, x1, x2, x2], [y, y + 0.02, y + 0.02, y], 'k-', lw=1)
    ax.text((x1 + x2) / 2, y + 0.03, sig_text, ha='center', va='bottom', fontsize=12)
```

This adds the standard `*`/`**`/`***`/`n.s.` annotations that clinical journals require.

## 7. The Project's Plotting Standards

Every performance plot in the project's final report must:

1. **Include 95% confidence intervals** (via bootstrap, $B = 10{,}000$).
2. **Use the colorblind-friendly palette**.
3. **Have a descriptive title** and axis labels with units.
4. **Rotate x-axis labels** if they would overlap.
5. **Include statistical annotations** (`*`/`**`/`***`/`n.s.`) for model comparisons.
6. **Be saved at 300 DPI** for print quality.
7. **Be reproducible** — the plotting script takes the random seed as input so the same data produces the same plot.

### 7.1. The Plotting Script

```python
def generate_all_plots(results, output_dir, seed=42):
    """Generate all performance plots with statistical rigor."""
    np.random.seed(seed)
    
    # Bar chart: Top-1 Accuracy with CI
    fig1 = plot_accuracy_with_ci(results['top1_accuracy'])
    fig1.savefig(f'{output_dir}/top1_accuracy.png', dpi=300, bbox_inches='tight')
    
    # Violin plot: Score distribution
    fig2 = plot_score_distribution(results['all_scores'], results['all_labels'])
    fig2.savefig(f'{output_dir}/score_distribution.png', dpi=300, bbox_inches='tight')
    
    # Heatmap: Similarity matrix
    fig3 = plot_similarity_heatmap(
        results['similarity_matrix'],
        results['patient_ids'],
        results['disease_ids']
    )
    fig3.savefig(f'{output_dir}/similarity_heatmap.png', dpi=300, bbox_inches='tight')
    
    plt.close('all')
```
