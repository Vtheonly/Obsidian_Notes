# 10.2. Ranking Metrics — MRR, Top-K, and NDCG

The original vault's Chapter 10.2 evaluated ranking performance using only **Top-K Accuracy** and **Mean Reciprocal Rank (MRR)**. The audit identified this as a **high-severity** gap: **NDCG (Normalized Discounted Cumulative Gain)** is the gold standard for evaluating multi-stage ranking systems, and its omission means the project cannot measure graded relevance or compare fairly against listwise rankers (Chapter 9.1). NDCG rewards the system for clustering highly relevant diseases near the top of the list, which MRR (a binary metric) cannot do.

This note covers: (1) Top-K Accuracy, (2) Mean Reciprocal Rank (MRR), (3) Discounted Cumulative Gain (DCG), (4) Normalized DCG (NDCG), (5) when each metric is appropriate, and (6) the project's evaluation protocol.

---

## 1. Top-K Accuracy (Hit Rate)

**Top-K Accuracy** asks: *"Was the correct diagnosis in the top K positions of the ranked list?"*

### 1.1. Formula

For a single query with ground-truth rank $r$ (the position of the correct disease in the ranked list):

$$\text{Top-K Accuracy} = \begin{cases} 1 & \text{if } r \leq K \\ 0 & \text{otherwise} \end{cases}$$

Averaged over $N$ queries:

$$\text{Top-K Accuracy} = \frac{1}{N}\sum_{i=1}^N \mathbb{1}[r_i \leq K]$$

### 1.2. Project Use

- **Top-1**: The correct disease is at position 1. This is the ultimate goal — the doctor sees the correct diagnosis first.
- **Top-5**: The correct disease is in the first 5 positions. Useful for "differential diagnosis" use cases where the doctor reviews the top 5.
- **Top-20**: The correct disease is in the Top-20 (the Stage 1 retrieval's output). This measures Stage 1's recall.

### 1.3. Limitations

Top-K is a **binary** metric: it tells you whether the correct disease is in the top K, but not whether it is at position 1 or position K. A system that puts the correct disease at position 1 gets the same Top-5 score as a system that puts it at position 5.

## 2. Mean Reciprocal Rank (MRR)

**MRR** rewards the model for putting the correct disease as close to position 1 as possible.

### 2.1. Formula

For a single query with ground-truth rank $r$:

$$\text{RR} = \frac{1}{r}$$

Averaged over $N$ queries:

$$\text{MRR} = \frac{1}{N}\sum_{i=1}^N \frac{1}{r_i}$$

### 2.2. Example

| Query | Rank of correct disease | Reciprocal Rank |
| :--- | :--- | :--- |
| 1 | 1 | 1.0 |
| 2 | 3 | 0.33 |
| 3 | 5 | 0.20 |
| 4 | 2 | 0.50 |
| 5 | not in top-20 | 0.0 |

$$\text{MRR} = (1.0 + 0.33 + 0.20 + 0.50 + 0.0) / 5 = 0.406$$

### 2.3. Interpretation

- **MRR = 1.0**: The correct disease is always at position 1.
- **MRR = 0.5**: On average, the correct disease is at position 2.
- **MRR = 0.0**: The correct disease is never in the ranked list.

### 2.4. Why MRR Is Better Than Top-K

MRR is a **graded** metric: it distinguishes position 1 (RR=1.0) from position 5 (RR=0.2). A system that consistently puts the correct disease at position 1 has a higher MRR than one that puts it at position 5, even if both have the same Top-5 accuracy.

### 2.5. Limitations

MRR is still a **single-target** metric: it only rewards the position of the **one** correct disease. If the ranked list contains other relevant diseases (e.g., diseases in the same family that are also valid differential diagnoses), MRR does not reward placing them near the top. This is where NDCG excels.

---

## 3. Discounted Cumulative Gain (DCG)

**DCG** is a graded-relevance metric that rewards relevant items at the top of the list and discounts relevant items lower down.

### 3.1. The Formula

For a ranked list of $K$ items with relevance scores $\text{rel}_1, \text{rel}_2, \dots, \text{rel}_K$ (where $\text{rel}_i$ is the relevance of the item at position $i$):

$$\text{DCG}_K = \sum_{i=1}^K \frac{\text{rel}_i}{\log_2(i + 1)}$$

### 3.2. The Discount

The $\log_2(i + 1)$ denominator is the **discount**: relevant items at position 1 contribute fully, but relevant items at position 10 contribute only $1/\log_2(11) \approx 0.29$ as much. This encodes the intuition that the user cares more about the top of the list than the bottom.

### 3.3. Relevance Scores

DCG supports **graded relevance** — each item has a relevance score, not just binary relevant/not-relevant. For the project:

| Relevance | Score | Meaning |
| :--- | :--- | :--- |
| 3 | Highly relevant | The correct disease |
| 2 | Moderately relevant | A disease in the same family (e.g., Albinism Type 2 when the patient has Type 1) |
| 1 | Marginally relevant | A disease with overlapping phenotypes |
| 0 | Irrelevant | All other diseases |

### 3.4. Example

For a ranked list of 5 items with relevances $[3, 0, 2, 0, 1]$:

$$\text{DCG}_5 = \frac{3}{\log_2 2} + \frac{0}{\log_2 3} + \frac{2}{\log_2 4} + \frac{0}{\log_2 5} + \frac{1}{\log_2 6}$$

$$= 3/1 + 0/1.585 + 2/2 + 0/2.322 + 1/2.585 = 3 + 0 + 1 + 0 + 0.387 = 4.387$$

### 3.5. Why DCG Is Better Than MRR for Multi-Relevant Queries

DCG rewards the system for placing **all** relevant items near the top, not just the single most relevant one. If the ranked list is $[3, 2, 0, 1, 0]$, DCG rewards both the highly relevant item at position 1 and the moderately relevant item at position 2. MRR would only count the position-1 item and ignore the rest.

---

## 4. Normalized DCG (NDCG)

**NDCG** normalises DCG by the **ideal DCG (IDCG)** — the DCG of the best possible ranking (relevances sorted descending):

$$\text{NDCG}_K = \frac{\text{DCG}_K}{\text{IDCG}_K}$$

### 4.1. The Ideal DCG

$$\text{IDCG}_K = \sum_{i=1}^K \frac{\text{rel}_i^*}{\log_2(i + 1)}$$

where $\text{rel}_i^*$ is the $i$-th largest relevance score (i.e., the relevances sorted in descending order).

### 4.2. Properties

- **Range**: $[0, 1]$. NDCG = 1.0 means the ranking is ideal; NDCG = 0.0 means no relevant items in the top K.
- **Comparable across queries**: Because NDCG is normalised by IDCG, it is comparable across queries with different numbers of relevant items. (DCG is not — a query with 5 relevant items has a higher DCG than one with 1 relevant item, even if both rankings are ideal.)
- **Graded**: NDCG uses graded relevance, capturing the nuance that "same-family disease" is better than "unrelated disease" even if neither is the exact correct disease.

### 4.3. Example

For the ranked list $[3, 0, 2, 0, 1]$ (DCG = 4.387 from §3.4):

- Ideal ranking: $[3, 2, 1, 0, 0]$ (relevances sorted descending).
- $\text{IDCG}_5 = 3/\log_2 2 + 2/\log_2 3 + 1/\log_2 4 + 0/\log_2 5 + 0/\log_2 6$
- $= 3/1 + 2/1.585 + 1/2 + 0 + 0 = 3 + 1.261 + 0.5 = 4.761$
- $\text{NDCG}_5 = 4.387 / 4.761 = 0.921$

The ranking is 92.1% of ideal — quite good, but not perfect (the moderately relevant item at position 3 should have been at position 2).

### 4.4. The Code

```python
import numpy as np

def dcg_at_k(relevances, k):
    """Compute DCG@K for a list of relevance scores."""
    relevances = np.asarray(relevances)[:k]
    if relevances.size == 0:
        return 0.0
    discounts = np.log2(np.arange(2, relevances.size + 2))
    return np.sum(relevances / discounts)

def ndcg_at_k(ranked_relevances, k):
    """
    Compute NDCG@K.
    
    Args:
        ranked_relevances: list of relevance scores in ranked order
        k: cutoff
    Returns:
        NDCG@K in [0, 1]
    """
    dcg = dcg_at_k(ranked_relevances, k)
    ideal_relevances = sorted(ranked_relevances, reverse=True)
    idcg = dcg_at_k(ideal_relevances, k)
    if idcg == 0:
        return 0.0
    return dcg / idcg

# Example
ranked_relevances = [3, 0, 2, 0, 1]
print(f"NDCG@5 = {ndcg_at_k(ranked_relevances, 5):.3f}")  # 0.921
```

## 5. When Each Metric Is Appropriate

| Metric | Best For | Limitation |
| :--- | :--- | :--- |
| Top-K Accuracy | Binary "was it in the list?" | No graded signal |
| MRR | Single-target ranking | Ignores non-target relevance |
| **NDCG** | **Graded-relevance ranking** | Requires relevance labels |
| MAP | Binary multi-relevant ranking | No discount for position |

### 5.1. The Project's Use

The project reports **all three** metrics, with NDCG as the primary metric for ranking quality:

- **Top-1 Accuracy**: The headline number for jury presentations ("91% Top-1 accuracy").
- **MRR**: The graded single-target metric, reported alongside Top-1.
- **NDCG@10**: The graded multi-target metric, reported for scientific completeness.

### 5.2. Why NDCG Matters for the Project

Rare-disease diagnosis often has **overlapping syndromes**: a patient with Albinism Type 1 may also have features of Hermansky-Pudlak Syndrome, and both diagnoses are partially correct. MRR only rewards the position of Type 1; NDCG also rewards placing Hermansky-Pudlak near the top. This is clinically more meaningful — the doctor benefits from seeing both related diseases early, not just the single "correct" one.

## 6. The Project's Evaluation Protocol

### 6.1. The Test Set

The test set contains 200 patient notes, each with:

- A **ground-truth diagnosis** (the correct Orpha ID).
- A list of **related diseases** (diseases in the same family, with relevance 2).
- A list of **phenotype-overlap diseases** (diseases with overlapping HPO terms, relevance 1).

### 6.2. The Pipeline

For each test note:

1. Run Stage 1 retrieval → Top-20 candidates.
2. Run Stage 3 KG verification → verified Top-20.
3. Run Stage 4 tournament → final ranked Top-20.
4. Compute relevances: the ground-truth disease gets relevance 3; same-family diseases get 2; phenotype-overlap diseases get 1; all others get 0.
5. Compute Top-1, Top-5, Top-20, MRR, NDCG@10.

### 6.3. Aggregation

Aggregate over the 200 test notes:

- **Top-1 Accuracy** = (number of notes with correct disease at rank 1) / 200.
- **MRR** = mean of $1/r_i$ over the 200 notes.
- **NDCG@10** = mean of NDCG@10 over the 200 notes.

### 6.4. Confidence Intervals (Chapter 10.3)

Each metric is reported with a 95% confidence interval, computed via bootstrap. This tells the jury not just "NDCG = 0.91" but "NDCG = 0.91 ± 0.03," which is necessary for statistical comparison between models.

## 7. Summary

| Metric | Formula | Range | Graded? | Project Use |
| :--- | :--- | :--- | :--- | :--- |
| Top-K Accuracy | $\mathbb{1}[r \leq K]$ | $\{0, 1\}$ | No | Headline |
| MRR | $1/r$ | $[0, 1]$ | No (single-target) | Reported |
| DCG | $\sum \text{rel}_i / \log_2(i+1)$ | $[0, \infty)$ | Yes | Intermediate |
| **NDCG** | DCG / IDCG | $[0, 1]$ | **Yes** | **Primary** |

The project's evaluation protocol reports Top-1, Top-5, Top-20, MRR, and NDCG@10, with 95% confidence intervals. NDCG is the primary metric because it captures graded relevance — the clinically important property that related diseases should also be ranked highly.
