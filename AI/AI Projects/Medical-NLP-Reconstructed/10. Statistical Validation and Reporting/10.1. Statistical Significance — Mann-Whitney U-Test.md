# 10.1. Statistical Significance — Mann-Whitney U-Test

To prove that the project's architecture actually works and is not just "lucky," the project uses the **Mann-Whitney U-Test** (also called the Wilcoxon rank-sum test). The original vault explained *why* the test is used (non-parametric, rank-based) but omitted the **mathematical formula** for the $U$ statistic, the **rank-sum computation**, the **$z$-score conversion** for large samples, and the **ties adjustment**. Without these, the reader cannot verify the calculation or implement it from scratch.

This note covers: (1) why a non-parametric test is needed, (2) the Mann-Whitney $U$ formula, (3) the rank-sum computation with ties, (4) the $z$-score normal approximation, (5) effect size (Cohen's $r$), and (6) the project's specific application (BioBERT vs. MiniLM baseline).

---

## 1. Why a Non-Parametric Test Is Needed

The standard parametric test for comparing two groups is the **t-test**, which assumes:

- The data in each group follows a **normal distribution**.
- The two groups have **equal variances**.

For the project's similarity scores, neither assumption holds:

- The similarity scores for the correct disease cluster near 0.9 (a sharp peak), not a bell curve.
- The similarity scores for wrong diseases cluster near 0.6–0.7 (a different peak).
- The two distributions have substantially different variances.

Applying a t-test to non-normal data produces unreliable $p$-values. The **Mann-Whitney U-Test** is the standard non-parametric alternative: it does not assume normality, and it tests whether one group's values tend to be higher than the other's, based solely on the **ranks** of the values rather than their magnitudes.

### 1.1. The Hypothesis

- **Null hypothesis ($H_0$)**: The two groups have the same distribution. Specifically, $P(X > Y) = 0.5$ for randomly sampled $X$ from group 1 and $Y$ from group 2.
- **Alternative hypothesis ($H_1$)**: One group tends to have higher values than the other. For the project: BioBERT's similarity scores for the correct disease tend to be higher than MiniLM's.

The test is **one-sided** for the project (we expect BioBERT to be better, not just different).

---

## 2. The Mann-Whitney $U$ Formula

Given two independent samples:

- Group 1: $X_1, X_2, \dots, X_{n_1}$ (e.g., BioBERT similarity scores, $n_1$ values)
- Group 2: $Y_1, Y_2, \dots, Y_{n_2}$ (e.g., MiniLM similarity scores, $n_2$ values)

### 2.1. Combine and Rank

Combine all $n_1 + n_2$ values into a single list, sort them, and assign ranks (1 for the smallest, $n_1 + n_2$ for the largest). Track which group each value came from.

### 2.2. Compute Rank Sums

Let $R_1$ be the sum of ranks for Group 1, and $R_2$ be the sum of ranks for Group 2. Note that $R_1 + R_2 = (n_1 + n_2)(n_1 + n_2 + 1) / 2$ (the sum of all ranks).

### 2.3. The $U$ Statistic

The Mann-Whitney $U$ statistic is:

$$U_1 = n_1 n_2 + \frac{n_1(n_1 + 1)}{2} - R_1$$

$$U_2 = n_1 n_2 + \frac{n_2(n_2 + 1)}{2} - R_2$$

Note that $U_1 + U_2 = n_1 n_2$ (a useful sanity check). The test statistic is $U = \min(U_1, U_2)$.

### 2.4. Intuition

$U_1$ counts the number of "wins" for Group 1 over Group 2: the number of pairs $(X_i, Y_j)$ where $X_i > Y_j$, plus half the number of ties. A small $U_1$ (relative to $n_1 n_2 / 2$) means Group 1 tends to have **lower** values; a large $U_1$ means Group 1 tends to have **higher** values.

For the project, a large $U_1$ (BioBERT wins more often) supports the alternative hypothesis that BioBERT outperforms MiniLM.

---

## 3. The Rank-Sum Computation with Ties

When two or more values are equal (a **tie**), each tied value receives the **average rank** of the positions it occupies.

### 3.1. Example

Combined sorted values: $[0.7, 0.8, 0.8, 0.8, 0.9]$

- Position 1: rank 1 (value 0.7)
- Positions 2, 3, 4: three-way tie (value 0.8). Average rank = $(2+3+4)/3 = 3$. Each tied value gets rank 3.
- Position 5: rank 5 (value 0.9)

Final ranks: $[1, 3, 3, 3, 5]$. Sum = 15.

### 3.2. Why Ties Matter

Ties reduce the test's discriminative power. The standard $U$ formula assumes no ties; with ties, a correction is applied (§4.2).

In the project's similarity scores, ties are rare (cosine similarities are continuous), but they can occur when multiple patient notes have identical embeddings (e.g., boilerplate text).

---

## 4. The $z$-Score Normal Approximation

For small samples ($n_1, n_2 < 20$), the $U$ statistic's distribution is tabulated. For larger samples, the distribution of $U$ under the null hypothesis is approximately normal, and a $z$-score can be computed:

### 4.1. Mean and Standard Deviation Under $H_0$

Under the null hypothesis:

$$\mu_U = \frac{n_1 n_2}{2}$$

$$\sigma_U = \sqrt{\frac{n_1 n_2 (n_1 + n_2 + 1)}{12}}$$

### 4.2. Ties Adjustment

If there are ties, the standard deviation is reduced:

$$\sigma_U = \sqrt{\frac{n_1 n_2}{12}\left[(n_1 + n_2 + 1) - \frac{\sum_{g} (t_g^3 - t_g)}{(n_1 + n_2)(n_1 + n_2 - 1)}\right]}$$

where $t_g$ is the number of values in tie group $g$, and the sum is over all tie groups.

### 4.3. The $z$-Score

$$z = \frac{U - \mu_U}{\sigma_U}$$

For a one-sided test (Group 1 > Group 2), the $p$-value is:

$$p = 1 - \Phi(z)$$

where $\Phi$ is the standard normal CDF.

### 4.4. Decision Rule

- If $p < 0.05$: reject $H_0$. The difference is statistically significant.
- If $p \geq 0.05$: fail to reject $H_0$. The difference is not statistically significant.

For the project, $p < 0.05$ means BioBERT significantly outperforms MiniLM.

---

## 5. Effect Size — Cohen's $r$

The $p$-value tells you whether the difference is **real**; the **effect size** tells you **how big** the difference is. For the Mann-Whitney test, the standard effect size is:

$$r = \frac{z}{\sqrt{n_1 + n_2}}$$

### 5.1. Interpretation

| $r$ | Effect Size |
| :--- | :--- |
| 0.1 | Small |
| 0.3 | Medium |
| 0.5 | Large |

For the project, a large effect size means BioBERT does not just *statistically* outperform MiniLM — it outperforms by a substantial margin.

### 5.2. Why Effect Size Matters

A $p$-value can be small (significant) even when the effect is tiny, if the sample size is large enough. Reporting the effect size alongside the $p$-value gives a complete picture: "BioBERT significantly outperforms MiniLM ($p < 0.001$, $r = 0.42$, medium-to-large effect)."

## 6. The Project's Application — BioBERT vs. MiniLM

The project uses the Mann-Whitney U-test to verify that BioBERT (the domain-adapted model) significantly outperforms MiniLM (the general-purpose control) on rare-disease retrieval.

### 6.1. The Two Groups

- **Group 1 (BioBERT)**: For each patient note in the test set, the BioBERT cosine similarity score for the **correct** disease. $n_1 = 200$ (the test set size).
- **Group 2 (MiniLM)**: For the same patient notes, the MiniLM cosine similarity score for the correct disease. $n_2 = 200$.

### 6.2. The Hypothesis

- $H_0$: BioBERT and MiniLM produce the same distribution of similarity scores for the correct disease.
- $H_1$: BioBERT produces higher similarity scores than MiniLM.

### 6.3. The Result (Illustrative)

```
BioBERT scores: mean = 0.91, std = 0.04, n = 200
MiniLM scores:  mean = 0.72, std = 0.08, n = 200

U = 3500  (out of max 40000)
z = 14.2
p < 0.0001
r = 0.71  (large effect)
```

The result: BioBERT significantly outperforms MiniLM ($p < 0.0001$, large effect). This justifies the domain adaptation: the 18 billion PubMed words that went into BioBERT produce a real, large, statistically significant improvement over the general-purpose MiniLM.

### 6.4. The Code

```python
from scipy.stats import mannwhitneyu
import numpy as np

def run_mann_whitney(biobert_scores, minimlm_scores):
    """
    Run one-sided Mann-Whitney U-test.
    H1: BioBERT scores > MiniLM scores.
    """
    result = mannwhitneyu(
        biobert_scores,
        minimlm_scores,
        alternative='greater',  # one-sided
        method='asymptotic'     # use normal approximation
    )
    
    U = result.statistic
    p = result.pvalue
    
    # Effect size (Cohen's r)
    z = (U - len(biobert_scores) * len(minimlm_scores) / 2) / \
        np.sqrt(len(biobert_scores) * len(minimlm_scores) * 
                (len(biobert_scores) + len(minimlm_scores) + 1) / 12)
    r = abs(z) / np.sqrt(len(biobert_scores) + len(minimlm_scores))
    
    return {
        'U': U,
        'p_value': p,
        'z_score': z,
        'effect_size_r': r,
        'significant': p < 0.05
    }
```

## 7. The "UTF" Correction

The original vault mentioned a "UTF correction," which is a mishearing of "U-Test." This is a distracting student error that should not appear in a technical reference. The correct term is **Mann-Whitney U-Test** or **Wilcoxon rank-sum test** (the two names refer to the same test, with slightly different historical derivations).

## 8. Assumptions and Limitations

### 8.1. Assumptions

- **Independence**: The two samples must be independent. For the project, BioBERT and MiniLM scores are computed on the same patient notes but using different models, so they are independent (the models do not share parameters or training data).
- **Ordinal scale**: The data must be at least ordinal (cosine similarity is continuous, so this is satisfied).
- **Identical distribution shape** (optional): The test is most powerful when the two distributions have the same shape (differing only in location). If the shapes differ substantially, the test still works but the interpretation shifts to "stochastic dominance" rather than "median difference."

### 8.2. Limitations

- **Less powerful than t-test** when the normality assumption holds. If the data were truly normal, the t-test would be more powerful. The Mann-Whitney test is the right choice when normality cannot be assumed (which is the project's case).
- **Does not estimate the magnitude** of the difference. The test tells you *whether* one group is higher, not *by how much*. The effect size (Cohen's $r$) partially addresses this, but for a magnitude estimate, a separate statistic (e.g., median difference) is needed.

## 9. Summary

| Element | Formula / Value |
| :--- | :--- |
| $U$ statistic | $U_1 = n_1 n_2 + n_1(n_1+1)/2 - R_1$ |
| Mean under $H_0$ | $\mu_U = n_1 n_2 / 2$ |
| Std dev under $H_0$ | $\sigma_U = \sqrt{n_1 n_2 (n_1 + n_2 + 1) / 12}$ |
| $z$-score | $z = (U - \mu_U) / \sigma_U$ |
| $p$-value (one-sided) | $p = 1 - \Phi(z)$ |
| Effect size | $r = \|z\| / \sqrt{n_1 + n_2}$ |
| Significance threshold | $p < 0.05$ |
