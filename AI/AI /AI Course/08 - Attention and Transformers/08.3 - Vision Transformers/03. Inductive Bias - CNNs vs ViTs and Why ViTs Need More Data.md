# 03. Inductive Bias — CNNs vs ViTs and Why ViTs Need More Data

> **Prerequisites:** [[01. From Words to Patches - How ViT Tokenizes an Image]], [[01. Introduction and Foundations of CNNs]] (the CNN design philosophy)
> **Connections:** [[04. ViT Architecture and Design Decisions]] (next)

This is the most important note in the ViT section. If you understand why ViTs need more data than CNNs, you understand the fundamental tradeoff between inductive bias and data-driven learning — a tradeoff that runs through all of modern deep learning.

---

## What is inductive bias?

**Inductive bias** is the set of assumptions built into a model's architecture that constrain what it can learn, independent of the data. It is the "prior knowledge" the designer bakes in.

A CNN has strong inductive biases:

1. **Locality:** each convolutional neuron sees only a small local neighborhood (the kernel), not the whole image. The assumption: nearby pixels are more related than distant ones.
2. **Translation equivariance:** the same kernel is applied at every spatial position. The assumption: a pattern that appears in the top-left is the same pattern if it appears in the bottom-right.
3. **Hierarchical composition:** stacking layers expands the receptive field, so early layers detect edges, middle layers detect textures/parts, late layers detect objects. The assumption: visual concepts are built hierarchically from simpler components.

These assumptions are **correct for natural images** — locality holds (pixels correlate with neighbors), translation equivariance holds (a cat is a cat regardless of position), and hierarchical composition holds (edges → textures → parts → objects is how visual cortex works). By baking these correct assumptions into the architecture, CNNs can learn from relatively small datasets: the architecture already "knows" what kind of patterns to look for, so it only needs the data to fill in the details.

A ViT has almost **no** inductive biases about images:

1. **No locality:** every patch can attend to every other patch from the first layer. There is no built-in assumption that nearby patches are more related.
2. **No translation equivariance:** the patches are at fixed positions with learned positional embeddings. There is no weight sharing across spatial translations.
3. **No hierarchical composition:** the "receptive field" is global from layer 1; there is no built-in progression from local to global features.

The ViT's only image-specific prior is the patch extraction step, which is a single convolution. Everything else — the spatial relationships, the locality, the hierarchy — must be **learned from data**.

---

## The tradeoff: inductive bias vs data

This sets up a fundamental tradeoff:

| | Strong inductive bias (CNN) | Weak inductive bias (ViT) |
| :--- | :--- | :--- |
| Sample efficiency | High — needs less data to learn | Low — needs more data to learn the priors |
| Ceiling on performance | Limited by the bias (if the bias is wrong, the model cannot escape it) | Higher — can learn any pattern the data supports |
| Best regime | Small-to-medium datasets | Large-to-massive datasets |

The CNN's inductive bias is a **constraint**. If the bias is correct (and for natural images, it largely is), the constraint helps — it focuses learning on the right kinds of patterns and prevents the model from wasting capacity exploring irrelevant ones. But if the bias is wrong or too rigid, the constraint hurts — the model cannot learn patterns that violate the bias.

The ViT's lack of inductive bias is **freedom**. The model can learn any pattern the data supports, including patterns that violate CNN priors (e.g., long-range spatial dependencies that CNNs handle poorly). But this freedom comes at a cost: the model must learn the priors from data, which requires a lot of data.

---

## The empirical evidence: the JFT-300M result

The original ViT paper (Dosovitskiy et al. 2020) demonstrated this tradeoff cleanly. They trained ViTs and ResNets on datasets of increasing size:

- **ImageNet-1K** (1.3M images): ResNet **dominates**. ViT underperforms — it does not have enough data to learn the spatial priors that ResNet gets for free.
- **ImageNet-21K** (14M images): ResNet still wins, but the gap narrows.
- **JFT-300M** (300M images): ViT **overtakes** ResNet. With enough data, the ViT's freedom to learn any pattern beats the ResNet's constrained-but-correct priors.

The crossover happens around 14–100M images. Below that, CNNs win; above that, ViTs win. This is why the original ViT paper's headline result was "ViT beats SOTA on ImageNet" — but only after pretraining on JFT-300M. Without the massive pretraining, ViT loses to ResNet.

---

## Why the crossover happens

At small data sizes, the CNN's inductive bias is doing real work. The model does not need to learn that "nearby pixels are related" — the architecture already encodes this. The model only needs to learn *what* the local patterns are (edges, textures, parts), which is a much smaller learning problem. The ViT, by contrast, must learn both the spatial priors *and* the patterns from the data, which is a harder problem that requires more data.

At large data sizes, the CNN's inductive bias becomes a **ceiling**. The model is constrained to express only patterns that respect locality, translation equivariance, and hierarchical composition. If the task requires patterns that violate these (e.g., "this pixel in the top-left is related to that pixel in the bottom-right because they are the same color in a globally-coordinated pattern"), the CNN cannot represent them well. The ViT, with its global attention from layer 1, can represent any pattern — and with enough data, it learns the relevant ones.

This is the same phenomenon as in NLP: RNNs (which encode the prior "the past influences the future, in order") dominated NLP until Transformers (which encode almost no prior) were trained on enough data to learn the order-related patterns themselves. The trajectory is: **architectural priors → data-driven learning**, and the crossover happens when data becomes abundant enough.

---

## The modern resolution: hybrid approaches

The ViT's data hunger was a real limitation in 2020, when JFT-300M was a proprietary dataset most researchers could not access. The field has since developed several approaches to get ViT-like performance on smaller datasets:

### 1. Hybrid CNN+ViT

Use a CNN for the early layers (to provide the locality and translation equivariance priors cheaply) and a ViT for the later layers (to provide the global attention and flexibility). The CNN "前置" the patches with good low-level features, so the ViT does not need to learn them from scratch. Examples: CoaT, BoTNet, "Early Convolutions Help Transformers See Further."

### 2. Strong augmentation and self-supervised pretraining

Train the ViT on ImageNet-1K with heavy data augmentation (RandAugment, Mixup, CutMix — see [[07. Data Augmentation]]) and self-supervised objectives (MAE, DINO, MoCo). The augmentation effectively multiplies the dataset; the self-supervised objective provides a richer learning signal than supervised classification. With these tricks, ViTs can match ResNets on ImageNet-1K without massive pretraining.

### 3. Hierarchical architectures (Swin, PVT)

Modify the ViT to have a hierarchical structure (small patches early, merged into larger patches later), reintroducing some of the CNN's multi-scale prior. Swin Transformer (Liu et al. 2021) uses shifted-window attention to make this efficient. These architectures combine the flexibility of attention with the data efficiency of hierarchical priors, and they match or beat both CNNs and plain ViTs on a wide range of dataset sizes.

### 4. Knowledge distillation from CNNs

Train a CNN teacher on the dataset, then distill its knowledge into a ViT student. The CNN teacher's inductive bias is "transferred" to the ViT through the distillation loss, effectively giving the ViT access to the CNN's priors without baking them into the architecture. DeiT (Touvron et al. 2021) uses this to train competitive ViTs on ImageNet-1K alone.

## The deeper lesson: priors vs data

The CNN-vs-ViT tradeoff is one instance of a recurring pattern in deep learning:

- **RNNs vs Transformers:** RNNs encode the prior "the past influences the future, in order." Transformers encode almost no prior and need more data to learn order-related patterns. Transformers won when data scaled.
- **Hand-crafted features vs learned features:** pre-deep-learning CV used SIFT, HOG, SURF — features designed by humans based on assumptions about what visual patterns matter. Deep learning replaced them with learned features, which need more data but scale better. Deep learning won when data and compute scaled.
- **Symbolic AI vs neural networks:** symbolic AI encodes human knowledge as rules. Neural networks learn from data. Neural networks won when data and compute scaled.

The pattern: **as data and compute scale, models with less inductive bias and more flexibility win, because they can learn the priors from data rather than being constrained by designer-specified ones.** The ViT is the vision instance of this pattern; the Transformer is the NLP instance. Both won when data scaled.

This does not mean inductive bias is always bad — for small-data regimes (medical imaging, scientific domains), CNNs or even hand-crafted features may still be the right choice. But for the data-rich regimes that dominate modern AI, the trend is clear: **less prior, more data, more flexibility.**

---

## What you should walk away with

1. Inductive bias is the set of architectural assumptions that constrain what a model can learn, independent of data.
2. CNNs have strong inductive biases: locality, translation equivariance, hierarchical composition. ViTs have almost none (only the patch extraction).
3. Strong inductive bias → sample-efficient but limited ceiling. Weak inductive bias → data-hungry but higher ceiling.
4. The crossover happens around 14–100M images: below, CNNs win; above, ViTs win.
5. Modern hybrids (CNN+ViT, Swin, DeiT, MAE) narrow the gap, making ViTs competitive on smaller datasets.
6. The deeper lesson: as data scales, models with less inductive bias and more flexibility win. This is the same trajectory as RNN→Transformer and hand-crafted→learned features.
