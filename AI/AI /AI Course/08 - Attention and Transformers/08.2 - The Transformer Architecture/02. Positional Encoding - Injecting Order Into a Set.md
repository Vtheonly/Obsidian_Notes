# 02. Positional Encoding — Injecting Order Into a Set

> **Prerequisites:** [[01. Self-Attention - When the Sequence Attends to Itself]]
> **Connections:** [[01. The Convolution Operation Deep Dive]] (CNNs encode position via the kernel; Transformers cannot)

---

## The problem: self-attention is permutation-equivariant

Self-attention computes $Q K^\top$ — a set of pairwise interactions. If you permute the input tokens, the output is the same permutation. The operation has no notion of order. It treats the sequence as a **set**, not a sequence.

This is catastrophic for language. "The cat sat on the mat" and "Mat the on sat cat the" would produce identical self-attention outputs (up to permutation), because the operation cannot distinguish them. But they mean completely different things. The model needs to know which token is in which position.

The RNN did not have this problem because its sequential processing *was* the order — token $t$ was computed after token $t-1$, and the hidden state at step $t$ implicitly encoded "this is step $t$." Self-attention, by being parallel and permutation-equivariant, throws away this information.

**Positional encoding** is the fix: explicitly inject position information into each token's representation before self-attention, so the model can use position as part of its attention computation.

---

## The two main approaches

### 1. Sinusoidal positional encoding (Vaswani et al. 2017)

The original Transformer adds a fixed, non-learned positional encoding to each token's embedding. For position $pos$ and dimension $i$:

$$PE(pos, 2i) = \sin\left(\frac{pos}{10000^{2i/d}}\right)$$
$$PE(pos, 2i+1) = \cos\left(\frac{pos}{10000^{2i/d}}\right)$$

The encoding is a $d$-dimensional vector for each position, where even dimensions are sines and odd dimensions are cosines of varying frequencies. The lowest frequencies cycle slowly (encoding coarse position), the highest frequencies cycle quickly (encoding fine position).

**Why sinusoids?** Three reasons:

1. **Bounded:** sines and cosines are in $[-1, 1]$, so adding them to embeddings does not blow up magnitudes.
2. **Extrapolatable:** for any fixed offset $k$, $PE(pos + k)$ is a linear function of $PE(pos)$. This means the model can learn to attend to "the token $k$ positions ahead" by learning a linear projection — the relative position is encoded in a learnable way.
3. **Unique:** each position has a unique encoding (the combined sine/cosine pattern at different frequencies disambiguates positions).

The encoding is added (not concatenated) to the token embedding:

$$X = [\text{embed}(w_1) + PE(1), \ldots, \text{embed}(w_T) + PE(T)]$$

Adding rather than concatenating preserves the model dimension $d$ and lets the positional information flow through all subsequent operations (Q, K, V projections) naturally.

### 2. Learned positional embeddings (BERT, GPT, ViT)

Instead of fixed sinusoids, learn a position embedding matrix $E_{pos} \in \mathbb{R}^{T_{max} \times d}$, where $T_{max}$ is the maximum sequence length. The embedding for position $pos$ is simply the $pos$-th row of this matrix, added to the token embedding:

$$X = [\text{embed}(w_1) + E_{pos}(1), \ldots, \text{embed}(w_T) + E_{pos}(T)]$$

This is simpler and empirically performs as well or better than sinusoids. The downside: it cannot extrapolate beyond $T_{max}$ — the model has no notion of positions beyond the maximum it was trained on. Sinusoidal encodings, in principle, extrapolate to any length.

In practice, most modern Transformers (BERT, GPT, ViT) use learned positional embeddings, accepting the fixed maximum length. Models that need to handle very long sequences (Longformer, BigBird) use specialized encodings (rotary, ALiBi) that combine the benefits of both.

---

## Rotary positional embeddings (RoPE) — the modern default

The most widely used positional encoding in 2023+ LLMs (LLaMA, Mistral, Qwen, etc.) is **Rotary Positional Embedding (RoPE)** (Su et al. 2021). RoPE does not add position information to the embedding; instead, it **rotates** the query and key vectors at attention time based on their positions.

The idea: instead of encoding absolute position, encode **relative position** directly into the dot product. The rotation is designed so that $q_m^\top k_n$ depends only on the relative offset $m - n$, not on the absolute positions $m$ and $n$.

RoPE's advantages:
- **Relative position** is what actually matters for attention ("look 3 tokens back" is more useful than "look at position 47").
- **Extrapolatable** to longer sequences (with some fine-tuning).
- **No extra parameters** — the rotations are fixed functions of position.

RoPE is more mathematically involved than sinusoidal or learned encodings, and the details are beyond this introductory treatment. The key takeaway: positional encoding is an active research area, and the field has converged on relative-position encodings (RoPE, ALiBi) for modern long-context models.

---

## Why position matters for attention — a concrete example

Consider "the cat chased the dog" vs "the dog chased the cat." The token sets are identical; only the order differs. Without positional encoding, the self-attention outputs would be identical (up to permutation). With positional encoding:

- In sentence 1, "chased" attends to "cat" (subject, position 2) and "dog" (object, position 5). The attention pattern encodes "subject before verb, object after."
- In sentence 2, "chased" attends to "dog" (subject, position 2) and "cat" (object, position 5). The attention pattern is the same shape but with different tokens filling the subject and object roles.

Without position, "chased" could not distinguish "cat is the subject" from "cat is the object" — both are just "the token 'cat' is in the sentence." Positional encoding lets the attention mechanism learn position-dependent patterns like "the token immediately before the verb is usually the subject."

---

## What you should walk away with

1. Self-attention is permutation-equivariant — it has no notion of order. Positional encoding is the fix.
2. The original Transformer uses fixed sinusoidal encodings (sines and cosines of varying frequencies), which are bounded, unique, and extrapolatable.
3. BERT, GPT, and ViT use learned positional embeddings — simpler, equally effective, but with a fixed maximum length.
4. Modern LLMs (LLaMA, etc.) use Rotary Positional Embeddings (RoPE), which encode relative position directly into the dot product.
5. Positional encoding is what lets attention learn position-dependent patterns (subject-verb order, coreference distance, etc.).
