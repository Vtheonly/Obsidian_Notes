# 3.9 Image Pyramids and Multi-Scale Representation

> **Prerequisites:** [[3.2 Linear Smoothing Filters]] (Gaussian), [[3.7 Geometric Transformations and Interpolation]]
> **Connections:** [[3.8 Feature Descriptors - SIFT, SURF, ORB, HOG]] (SIFT uses scale-space pyramids), [[03. Architecture and Connectivity/05. Evolution of CNN Architectures]] (FPN uses pyramids)

An **image pyramid** is a multi-scale representation of an image — a stack of progressively smaller, smoother versions. Pyramids are essential for scale-invariant detection (objects appear at different sizes in different images) and for efficient multi-scale algorithms. This note covers the two main types: Gaussian pyramids (for smoothing + downsampling) and Laplacian pyramids (for detail extraction and reconstruction).

---

## Why multi-scale?

An object can appear at any size in an image. A face might be 1000 pixels wide in a close-up portrait or 50 pixels wide in a wide group photo. A detector that works at one scale will miss objects at other scales. The naive solution — run the detector at every scale by resizing the image — is expensive. **Image pyramids** make this efficient by pre-computing the multi-scale representation.

A pyramid is also the natural data structure for algorithms that need to combine local detail (high resolution) with global context (low resolution). SIFT's scale space, CNN Feature Pyramid Networks, and Laplacian pyramid blending all use this structure.

---

## The Gaussian Pyramid

A Gaussian pyramid is built by repeatedly **blurring with a Gaussian and downsampling by 2**:

1. Start with the original image $G_0$ (level 0).
2. Apply a Gaussian blur to $G_0$.
3. Downsample by 2 (drop every other pixel) → $G_1$ (level 1, half the resolution).
4. Repeat: blur $G_1$, downsample → $G_2$, etc.

```
Level 0: G_0 (original, e.g., 512×512)
Level 1: G_1 (256×256, blurred + downsampled)
Level 2: G_2 (128×128)
Level 3: G_3 (64×64)
...
```

Each level is $\frac{1}{4}$ the size of the previous (half the width, half the height). The pyramid has $\log_2(\min(H, W))$ levels.

**Why blur before downsampling?** Downsampling without blurring causes **aliasing** — high frequencies that the smaller image cannot represent fold back as spurious low frequencies. The Gaussian blur is a low-pass filter that removes the high frequencies before they can alias. This is the Nyquist-Shannon sampling theorem in action.

### EXPAND operation

The inverse of the pyramid construction: upsample $G_{i+1}$ by 2 (insert zeros) and blur with the same Gaussian → a blurred approximation of $G_i$, denoted $\text{EXPAND}(G_{i+1})$. This is used in Laplacian pyramids (below) and in multi-scale blending.

---

## The Laplacian Pyramid

A Laplacian pyramid captures the **detail** at each scale — the information lost when going from level $i$ to level $i+1$. It is derived from the Gaussian pyramid:

$$L_i = G_i - \text{EXPAND}(G_{i+1})$$

$L_i$ is the difference between level $i$ of the Gaussian pyramid and the upsampled version of level $i+1$. It contains the **high-frequency detail** that was smoothed away when building the Gaussian pyramid.

### Why "Laplacian"?

Each $L_i$ approximates the **Laplacian of the Gaussian** (LoG — see [[3.6 Canny and LoG - Advanced Edge Detection]]) at a different scale. The difference of two Gaussians at different scales is an approximation of the Laplacian. So the Laplacian pyramid is a **multi-scale edge/detail detector**.

### Reconstruction

The original image can be perfectly reconstructed from the Laplacian pyramid:

$$G_i = L_i + \text{EXPAND}(G_{i+1})$$

Starting from the top (the smallest Gaussian level, which is also the smallest Laplacian's "base"), expand and add the corresponding Laplacian level, repeat down to level 0. This gives lossless reconstruction — the Laplacian pyramid is a complete representation, not an approximation.

### Applications of Laplacian pyramids

1. **Image blending:** to blend two images seamlessly (e.g., the apple+orange classic example), blend each Laplacian level separately with a smooth mask, then reconstruct. This produces blends without visible seams, because each scale is blended independently.
2. **Image compression:** the Laplacian levels are sparser than the original (mostly zeros in smooth regions), so they can be compressed more efficiently. This is the basis of some early wavelet compression schemes.
3. **Texture synthesis:** generate textures by sampling from the Laplacian statistics of an example texture.
4. **Multi-scale detail enhancement:** amplify or suppress specific scales by scaling the Laplacian levels before reconstruction.

---

## The DoG pyramid (SIFT's scale space)

SIFT (see [[3.8 Feature Descriptors - SIFT, SURF, ORB, HOG]]) uses a variant: the **Difference of Gaussians (DoG) pyramid**. Instead of subtracting the expanded version (Laplacian), SIFT subtracts **adjacent Gaussian levels**:

$$\text{DoG}_i = G_i(\sigma) - G_i(k\sigma)$$

where $k$ is a scale ratio (e.g., $k = 2^{1/3}$). The DoG approximates the LoG and is used to find scale-space extrema — keypoints that are stable across scales.

---

## Pyramids in deep learning: Feature Pyramid Networks (FPN)

Modern object detectors (see [[01. Modern Computer Vision Tasks - Detection and Segmentation]]) face the same multi-scale problem. **Feature Pyramid Networks (FPN)** (Lin et al., 2017) build a pyramid from a CNN's feature maps: the CNN naturally produces features at decreasing resolutions (after each pooling/strided-conv layer), and FPN adds a top-down path with lateral connections to produce a pyramid of rich features at each scale. The detector then runs on all pyramid levels, detecting large objects at coarse levels and small objects at fine levels.

FPN is the deep-learning successor to the Gaussian pyramid — it serves the same purpose (multi-scale detection) but uses learned features instead of Gaussian blur.

## Practical use in OpenCV

```python
import cv2

# Gaussian pyramid
level0 = image
level1 = cv2.pyrDown(level0)  # blur + downsample by 2
level2 = cv2.pyrDown(level1)
level3 = cv2.pyrDown(level2)

# Expand back
expanded = cv2.pyrUp(level1)  # upsample + blur

# Laplacian pyramid
laplacian0 = level0.astype(float) - cv2.pyrUp(level1).astype(float)
# (must match sizes; pyrUp doubles the dimensions)
```

---

## What you should walk away with

1. An **image pyramid** is a multi-scale stack: each level is smaller and smoother than the one below.
2. **Gaussian pyramid:** built by blur + downsample. Must blur before downsampling to avoid aliasing.
3. **Laplacian pyramid:** the detail at each scale = $L_i = G_i - \text{EXPAND}(G_{i+1})$. Captures multi-scale edges/details.
4. The Laplacian pyramid is a **complete representation** — the image can be perfectly reconstructed.
5. Applications: multi-scale blending (seamless), compression, texture synthesis, detail enhancement.
6. **SIFT's DoG** and **deep learning's FPN** are modern successors that use the pyramid structure with learned features.
7. Pyramids are the data structure for any algorithm that needs to handle objects at multiple scales.
