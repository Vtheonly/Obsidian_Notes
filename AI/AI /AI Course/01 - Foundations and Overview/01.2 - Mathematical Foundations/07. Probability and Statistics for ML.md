## Random variables and distributions

A **random variable** $X$ is a variable whose value is uncertain, described by a probability distribution. We distinguish:

- **Discrete** $X$ (e.g., a class label): described by a probability mass function $P(X = x)$.
- **Continuous** $X$ (e.g., a regression target): described by a probability density function $p(x)$.

The **expectation** (mean) is $\mathbb{E}[X] = \sum_x x P(x)$ (discrete) or $\int x p(x) dx$ (continuous). The **variance** is $\text{Var}(X) = \mathbb{E}[(X - \mathbb{E}[X])^2]$.

---

## The key distributions for ML

### Bernoulli distribution

For a binary random variable $X \in \{0, 1\}$ with $P(X = 1) = p$:

$$P(X = x) = p^x (1 - p)^{1 - x}$$

- Mean: $p$. Variance: $p(1-p)$.

**ML use:** binary classification. A model outputting a probability $p$ for "class 1" is modeling a Bernoulli distribution.

### Categorical / Multinomial distribution

For a $K$-class random variable $X \in \{1, \ldots, K\}$ with $P(X = k) = p_k$:

$$P(X = k) = p_k, \quad \sum_{k=1}^K p_k = 1$$

**ML use:** multi-class classification. A model outputting a softmax distribution is modeling a categorical distribution.

### Gaussian (Normal) distribution

For a continuous random variable $X \in \mathbb{R}$ with mean $\mu$ and variance $\sigma^2$:

$$p(x) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left(-\frac{(x - \mu)^2}{2\sigma^2}\right)$$

- Mean: $\mu$. Variance: $\sigma^2$.

The multivariate Gaussian (for $\mathbf{x} \in \mathbb{R}^d$) uses a mean vector $\boldsymbol{\mu}$ and covariance matrix $\Sigma$:

$$p(\mathbf{x}) = \frac{1}{(2\pi)^{d/2} |\Sigma|^{1/2}} \exp\left(-\frac{1}{2} (\mathbf{x} - \boldsymbol{\mu})^\top \Sigma^{-1} (\mathbf{x} - \boldsymbol{\mu})\right)$$

**ML use:** regression (noise model), VAEs (latent distribution), Gaussian initialization (weight init), GMMs (clustering).

## Maximum Likelihood Estimation (MLE)

MLE is the principle that connects probability theory to ML loss functions. The idea: **choose the parameters that make the observed data most probable.**

Given data $\{x_1, \ldots, x_n\}$ assumed to be i.i.d. from a distribution $p(x; \theta)$, the **likelihood** is:

$$L(\theta) = \prod_{i=1}^n p(x_i; \theta)$$

The MLE estimate is $\hat{\theta}_{MLE} = \arg\max_\theta L(\theta)$. In practice, we maximize the **log-likelihood** (which turns the product into a sum and is numerically stabler):

$$\ell(\theta) = \sum_{i=1}^n \log p(x_i; \theta)$$

### MLE for regression → MSE

Assume the target $y$ is a linear function of features $x$ plus Gaussian noise:

$$y = \mathbf{w}^\top \mathbf{x} + \epsilon, \quad \epsilon \sim \mathcal{N}(0, \sigma^2)$$

Then $y | \mathbf{x} \sim \mathcal{N}(\mathbf{w}^\top \mathbf{x}, \sigma^2)$, and the log-likelihood is:

$$\ell(\mathbf{w}) = -\frac{1}{2\sigma^2} \sum_i (y_i - \mathbf{w}^\top \mathbf{x}_i)^2 + \text{const}$$

Maximizing $\ell$ is equivalent to **minimizing MSE**. So MSE is not an arbitrary choice — it is the maximum-likelihood loss under a Gaussian noise assumption.

### MLE for classification → Cross-Entropy

Assume the label $y \in \{0, 1\}$ is Bernoulli with probability $p = \sigma(\mathbf{w}^\top \mathbf{x})$ (sigmoid). The log-likelihood is:

$$\ell(\mathbf{w}) = \sum_i \left[ y_i \log p_i + (1 - y_i) \log(1 - p_i) \right]$$

Maximizing $\ell$ is equivalent to **minimizing binary cross-entropy**. So BCE is not arbitrary — it is the maximum-likelihood loss under a Bernoulli assumption.

For multi-class (categorical with softmax), the same derivation gives **categorical cross-entropy**.

### The deep lesson

**Every standard ML loss function is an MLE under some noise assumption:**

| Loss | Noise assumption | Distribution |
| :--- | :--- | :--- |
| MSE (regression) | Gaussian noise | $\mathcal{N}(\mathbf{w}^\top \mathbf{x}, \sigma^2)$ |
| BCE (binary classification) | Bernoulli | $\text{Bernoulli}(\sigma(\mathbf{w}^\top \mathbf{x}))$ |
| CCE (multi-class) | Categorical | $\text{Categorical}(\text{softmax}(\mathbf{w}^\top \mathbf{x}))$ |

This is why these losses are "natural" — they are not arbitrary; they fall out of the probabilistic model. If you change the noise assumption (e.g., Laplace noise instead of Gaussian), you get a different loss (MAE instead of MSE).

## Maximum A Posteriori (MAP) and regularization

MLE can overfit — it finds the parameters that best fit the training data, with no preference for "simple" parameters. **MAP estimation** adds a **prior** $p(\theta)$ over the parameters, encoding a preference:

$$\hat{\theta}_{MAP} = \arg\max_\theta p(\theta | \text{data}) = \arg\max_\theta \left[ \ell(\theta) + \log p(\theta) \right]$$

(by Bayes' rule, dropping the evidence term which does not depend on $\theta$).

### Gaussian prior → L2 regularization

If the prior is $p(\mathbf{w}) = \mathcal{N}(0, \tau^2 I)$ (Gaussian with mean 0, variance $\tau^2$):

$$\log p(\mathbf{w}) = -\frac{1}{2\tau^2} \|\mathbf{w}\|^2 + \text{const}$$

So MAP with a Gaussian prior is MLE plus **L2 regularization** (weight decay):

$$\hat{\mathbf{w}}_{MAP} = \arg\min_\mathbf{w} \left[ \text{MSE}(\mathbf{w}) + \lambda \|\mathbf{w}\|^2 \right]$$

where $\lambda = 1/(2\tau^2)$. **L2 regularization is MAP with a Gaussian prior.**

### Laplace prior → L1 regularization

If the prior is Laplace (double-exponential), $p(\mathbf{w}) \propto \exp(-\lambda \|\mathbf{w}\|_1)$, MAP gives **L1 regularization** (Lasso). This is why L1 promotes sparsity — the Laplace prior concentrates mass at zero.

### The deep lesson

**Regularization is a prior.** L2 = Gaussian prior; L1 = Laplace prior; ElasticNet = a mixture. The regularization strength $\lambda$ is the inverse prior variance. This is not a metaphor — it is a mathematical equivalence. Understanding this connects the two halves of ML: the loss function (from MLE) and the regularizer (from the prior).

## Bayes' theorem and Bayesian inference

Bayes' theorem relates the posterior to the likelihood and prior:

$$p(\theta | \text{data}) = \frac{p(\text{data} | \theta) \cdot p(\theta)}{p(\text{data})}$$

- $p(\theta | \text{data})$: **posterior** — what we believe about $\theta$ after seeing the data.
- $p(\text{data} | \theta)$: **likelihood** — how probable the data is given $\theta$.
- $p(\theta)$: **prior** — what we believed before seeing data.
- $p(\text{data})$: **evidence** — a normalizing constant.

MLE uses only the likelihood. MAP uses likelihood + prior. **Full Bayesian inference** uses the entire posterior — not just its mode (which is what MAP gives) but the full distribution. This lets you quantify uncertainty in your predictions, which is critical for scientific applications, medicine, and autonomous systems.

Full Bayesian inference is typically intractable (the evidence integral is hard), so it is approximated via:
- **Variational inference** (VAEs — see [[10.2 - Variational Autoencoders]]).
- **Markov Chain Monte Carlo** (MCMC).
- **Bayesian neural networks** (maintain distributions over weights).

## KL divergence

The **Kullback-Leibler divergence** measures how much one distribution differs from another:

$$D_{KL}(p \| q) = \sum_x p(x) \log \frac{p(x)}{q(x)} \quad \text{(discrete)}$$

or $\int p(x) \log \frac{p(x)}{q(x)} dx$ for continuous.

Key properties:
- $D_{KL} \geq 0$, with equality iff $p = q$.
- Not symmetric ($D_{KL}(p \| q) \neq D_{KL}(q \| p)$).
- Not a true distance (no triangle inequality).

**ML uses:**
- **VAEs:** the KL term in the VAE loss is $D_{KL}(q_\phi(z|x) \| p(z))$ — pushing the encoder's distribution toward the prior.
- **Knowledge distillation:** train a student to match a teacher's output distribution, minimizing $D_{KL}(\text{teacher} \| \text{student})$.
- **Variational inference:** the ELBO is $\log p(x) - D_{KL}(q(z|x) \| p(z|x))$ — minimizing the KL between approximate and true posterior.
- **Information theory:** $D_{KL}$ measures the information lost when $q$ approximates $p$.

---

## What you should walk away with

1. **Probability distributions** model uncertainty. Bernoulli (binary), Categorical (multi-class), Gaussian (continuous) are the workhorses of ML.
2. **MLE** chooses parameters that maximize the data likelihood. MSE = MLE under Gaussian noise; BCE = MLE under Bernoulli; CCE = MLE under Categorical.
3. **MAP** adds a prior. L2 regularization = MAP with Gaussian prior; L1 = MAP with Laplace prior. Regularization is a prior.
4. **Bayes' theorem** relates posterior, likelihood, and prior. Full Bayesian inference uses the entire posterior (not just its mode) to quantify uncertainty.
5. **KL divergence** measures distributional difference. It is the VAE's regularizer, the distillation loss, and the variational inference objective.

The key takeaway: **ML loss functions are not arbitrary — they are MLE under specific noise assumptions. Regularization is not arbitrary — it is a prior. Understanding this transforms your mental model of why we use what we use.**
