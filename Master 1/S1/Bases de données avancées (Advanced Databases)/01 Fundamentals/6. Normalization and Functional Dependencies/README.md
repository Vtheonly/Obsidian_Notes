# 6. Normalization and Functional Dependencies

This chapter develops the foundations of relational schema normalization: data anomalies, functional dependencies, attribute closure, candidate keys, normal forms, decomposition, and practical normalization exercises.

## Learning Objectives

By the end of this chapter, you should be able to:

1. Identify insertion, update, and deletion anomalies.
2. Formalize functional dependencies.
3. Compute attribute closures.
4. Find candidate keys and distinguish them from superkeys.
5. Determine whether a relation satisfies 1NF, 2NF, 3NF, or BCNF.
6. Decompose relations while preserving important dependency and lossless-join properties.
7. Apply normalization systematically to exam-style problems.
