# 9. Complex ER to Relational Translations

This chapter focuses on translating complex E/R structures into relational schemas, especially N:M associations, 1:1 and 1:N dependencies, association attributes, and cases where relationships carry important constraints.

## Learning Objectives

- translate entity types into relations;
- translate N:M associations correctly;
- identify when a foreign key can represent a relationship;
- preserve association attributes;
- reason from cardinalities and functional dependencies instead of memorizing isolated patterns.
