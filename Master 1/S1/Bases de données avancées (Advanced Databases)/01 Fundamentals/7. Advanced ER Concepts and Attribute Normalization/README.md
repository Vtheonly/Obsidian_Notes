# 7. Advanced ER Concepts and Attribute Normalization

This chapter develops the E/R modeling cases that become difficult in exams: ternary associations, association attributes, composite and multivalued attributes, derived attributes, and controlled vocabularies.

## Learning Objectives

By the end of this chapter, you should be able to:

- recognize when a binary relationship is insufficient;
- model repeated events without losing uniqueness;
- distinguish entity attributes from association attributes;
- identify attributes that should be decomposed or derived;
- decide when a controlled list is better represented by a reference entity;
- translate these modeling decisions into a relational design.
