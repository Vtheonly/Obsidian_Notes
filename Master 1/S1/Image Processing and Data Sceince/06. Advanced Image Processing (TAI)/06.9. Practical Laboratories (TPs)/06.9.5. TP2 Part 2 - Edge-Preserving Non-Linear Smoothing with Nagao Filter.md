# 06.9.5. TP2 Part 2 - Edge-Preserving Non-Linear Smoothing with Nagao Filter

## 1. Overview
The Nagao filter is an edge-preserving smoothing operator that avoids blurring sharp boundaries by evaluating multiple directional sub-regions around each pixel, covering Exercise 3 of TP2.

## 2. Algorithm Mechanics
For each pixel in a $5 \times 5$ window:
1. Divide the neighborhood into 9 overlapping sub-regions (central cross, 4 cardinal bars, 4 diagonal corner quadrants).
2. Calculate the local sample variance $\sigma_k^2$ for each sub-region.
3. Identify the sub-region with the lowest variance: $k^* = \arg\min \sigma_k^2$.
4. Replace the center pixel with the mean intensity $\mu_{k^*}$ of that sub-region.

```python
import numpy as np
import cv2

def filtre_nagao(im: np.ndarray) -> np.ndarray:
    """Applies the 5x5 edge-preserving Nagao filter to a grayscale image."""
    h, w = im.shape
    padded = np.pad(im.astype(np.float64), 2, mode='reflect')
    out = np.zeros((h, w), dtype=np.uint8)

    sub_regions = [
        [(0,0), (-1,0), (1,0), (0,-1), (0,1)],
        [(0,0), (-1,0), (-2,0), (-1,-1), (-2,-1), (-1,1), (-2,1)],
        [(0,0), (1,0), (2,0), (1,-1), (2,-1), (1,1), (2,1)],
        [(0,0), (0,1), (0,2), (-1,1), (-1,2), (1,1), (1,2)],
        [(0,0), (0,-1), (0,-2), (-1,-1), (-1,-2), (1,-1), (1,-2)],
        [(0,0), (-1,0), (-1,1), (-1,2), (-2,1), (-2,2), (0,1)],
        [(0,0), (-1,0), (-1,-1), (-1,-2), (-2,-1), (-2,-2), (0,-1)],
        [(0,0), (1,0), (1,1), (1,2), (2,1), (2,2), (0,1)],
        [(0,0), (1,0), (1,-1), (1,-2), (2,-1), (2,-2), (0,-1)]
    ]

    for y in range(h):
        for x in range(w):
            py, px = y + 2, x + 2
            lowest_var = float('inf')
            best_mean = padded[py, px]

            for mask in sub_regions:
                vals = [padded[py + dy, px + dx] for dy, dx in mask]
                var = np.var(vals)
                if var < lowest_var:
                    lowest_var = var
                    best_mean = np.mean(vals)

            out[y, x] = int(round(best_mean))

    return out
```

## 3. Benchmark Comparisons (PSNR)
- **Mean Filter ($5 \times 5$)**: Significantly blurs edge transitions.
- **Nagao Filter ($5 \times 5$)**: Produces sharp, clean edge boundaries by selecting homogeneous sub-regions that avoid crossing high-variance edges.
