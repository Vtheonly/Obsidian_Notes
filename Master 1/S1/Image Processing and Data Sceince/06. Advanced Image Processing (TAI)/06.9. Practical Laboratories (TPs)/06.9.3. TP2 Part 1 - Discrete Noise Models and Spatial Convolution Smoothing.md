## 1. Overview
This note covers digital noise modeling (additive Gaussian vs. salt-and-pepper impulse noise), spatial domain filtering, and objective quality evaluation using MSE and PSNR metrics, covering Exercises 1 and 2 of TP2.

## 2. Noise Generation & Characterization (Exercise 1)

```python
import cv2
import numpy as np

# Ingest base grayscale image
im1 = cv2.imread("Images/cameraman.bmp", cv2.IMREAD_GRAYSCALE)
if im1 is None:
    raise FileNotFoundError("Image 'Images/cameraman.bmp' not found.")

# 1. Additive White Gaussian Noise (AWGN): mean=0, variance=100 (sigma=10)
def generate_gaussian_noise(image: np.ndarray, mean: float = 0.0, var: float = 100.0) -> np.ndarray:
    sigma = np.sqrt(var)
    gaussian_noise = np.random.normal(mean, sigma, image.shape)
    noisy = image.astype(np.float64) + gaussian_noise
    return np.clip(noisy, 0, 255).astype(np.uint8)

im2 = generate_gaussian_noise(im1, mean=0.0, var=100.0)
cv2.imwrite("Images/cameraman_bruit_gauss_sig0_001.bmp", im2)

# 2. Impulse Noise (Salt-and-Pepper): 10% corrupted pixels (p=0.10)
def sp_noise(image: np.ndarray, prob: float = 0.10) -> np.ndarray:
    noisy = image.copy()
    rnd = np.random.rand(*image.shape)
    # Set half of corrupted pixels to white (salt)
    noisy[rnd < (prob / 2.0)] = 255
    # Set remaining corrupted pixels to black (pepper)
    noisy[(rnd >= (prob / 2.0)) & (rnd < prob)] = 0
    return noisy

im3 = sp_noise(im1, prob=0.10)
cv2.imwrite("Images/cameraman_bruit_sel_poivre_p_10.bmp", im3)
```

## 3. Spatial Filtering and PSNR Benchmarks (Exercise 2)

```python
# Mean and Median Filter Implementations
def filtre_moyenne(im: np.ndarray, ksize: int) -> np.ndarray:
    pad = ksize // 2
    padded = np.pad(im.astype(np.float64), pad, mode='reflect')
    h, w = im.shape
    out = np.zeros_like(im, dtype=np.float64)
    for y in range(h):
        for x in range(w):
            out[y, x] = np.mean(padded[y:y+ksize, x:x+ksize])
    return np.clip(out, 0, 255).astype(np.uint8)

def filtre_median(im: np.ndarray, ksize: int) -> np.ndarray:
    pad = ksize // 2
    padded = np.pad(im, pad, mode='reflect')
    h, w = im.shape
    out = np.zeros_like(im)
    for y in range(h):
        for x in range(w):
            out[y, x] = np.median(padded[y:y+ksize, x:x+ksize])
    return out

def calculate_psnr(orig: np.ndarray, proc: np.ndarray) -> float:
    mse = np.mean((orig.astype(np.float64) - proc.astype(np.float64)) ** 2)
    if mse == 0:
        return float('inf')
    return 10.0 * np.log10((255.0 ** 2) / mse)

# Evaluate Filters on Gaussian Noise (im2) and Salt-and-Pepper Noise (im3)
imf2 = filtre_moyenne(im2, ksize=3)
imf3 = filtre_median(im3, ksize=3)
imfm2 = filtre_median(im2, ksize=3)

print("--- PSNR Quality Benchmarks ---")
print(f"Gaussian Noisy Base PSNR:          {calculate_psnr(im1, im2):.2f} dB")
print(f"Mean Filter (3x3) on Gaussian:     {calculate_psnr(im1, imf2):.2f} dB")
print(f"Median Filter (3x3) on Gaussian:   {calculate_psnr(im1, imfm2):.2f} dB")
print(f"Salt & Pepper Base PSNR:           {calculate_psnr(im1, im3):.2f} dB")
print(f"Median Filter (3x3) on Salt&Pepper:{calculate_psnr(im1, imf3):.2f} dB")
```

## 4. Key Takeaways
- **Gaussian Noise**: Best mitigated by linear Mean, Gaussian, or Bilateral filters. Median filters leave residual variance.
- **Salt-and-Pepper Noise**: Completely eliminated by the Median filter. Linear filters blur impulse pixels across neighbors, causing visible dark and bright smudges.

## Library Quick Reference
* `np.random.normal(mean, sigma, shape)` — draws the additive white Gaussian noise field injected into `im1` (note [[19. Spatial Image Restoration - Noise Models, Linear Convolution, and Fast Integral Filters|19]]).
* `np.random.rand(*shape)` — uniform draws whose `p/2` / `p` thresholding select salt and pepper pixels (note [[19. Spatial Image Restoration - Noise Models, Linear Convolution, and Fast Integral Filters|19]]).
* `np.clip(x, 0, 255)` — clamps float arithmetic back into the 8-bit dynamic range before the `.astype(np.uint8)` cast (note [[02. NumPy Array Manipulation - Slicing, Strides, Shapes, and Vectorized Indexing|02]]).
* `np.pad(img, k, mode='reflect')` — mirror-pads the border so every filter window overlaps real pixels (note [[19. Spatial Image Restoration - Noise Models, Linear Convolution, and Fast Integral Filters|19]]).
* `np.mean` / `np.median` — the window statistics implementing the mean and median filter responses (note [[04. NumPy Mathematical Engine - Vectorization, ufuncs, and Broadcasting Rules|04]]).
