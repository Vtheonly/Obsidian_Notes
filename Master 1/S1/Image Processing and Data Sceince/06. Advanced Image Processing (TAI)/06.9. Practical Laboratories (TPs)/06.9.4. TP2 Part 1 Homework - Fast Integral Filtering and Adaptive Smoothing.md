## 2. Accelerating Large Kernel Smoothing via Integral Images
Traditional box filtering scales at $O(M^2)$ per pixel. An integral image computes local window sums in **$O(1)$ constant time** using four array lookups:

```python
import numpy as np
import time

def fast_box_filter_integral(image: np.ndarray, ksize: int) -> np.ndarray:
    """Computes a box filter in O(1) time per pixel using an integral image."""
    h, w = image.shape
    pad = ksize // 2
    padded = np.pad(image.astype(np.float64), pad, mode='reflect')
    
    # Construct Integral Image
    integral = np.zeros((padded.shape[0] + 1, padded.shape[1] + 1), dtype=np.float64)
    integral[1:, 1:] = np.cumsum(np.cumsum(padded, axis=0), axis=1)
    
    output = np.zeros((h, w), dtype=np.uint8)
    area = ksize * ksize
    
    for y in range(h):
        for x in range(w):
            y1, x1 = y, x
            y2, x2 = y + ksize, x + ksize
            win_sum = integral[y2, x2] + integral[y1, x1] - integral[y1, x2] - integral[y2, x1]
            output[y, x] = int(round(win_sum / area))
            
    return output
```

## 3. Adaptive Local Mean Filtering
The adaptive mean filter adjusts smoothing dynamically according to local variance $\sigma_L^2$ relative to the overall noise variance $\sigma_\eta^2$:

$$I_{\text{adaptive}}(y, x) = I(y, x) - \frac{\sigma_\eta^2}{\sigma_L^2} \cdot \Big( I(y, x) - \mu_L \Big)$$

- **Flat/Homogeneous Regions ($\sigma_L^2 \approx \sigma_\eta^2$)**: The ratio $\frac{\sigma_\eta^2}{\sigma_L^2} \to 1$, reducing the formula to the local mean $\mu_L$ and removing noise.
- **Edge Regions ($\sigma_L^2 \gg \sigma_\eta^2$)**: The ratio $\frac{\sigma_\eta^2}{\sigma_L^2} \to 0$, keeping the original pixel $I(y, x)$ unchanged and preserving edge sharpness.

```python
def adaptive_mean_filter(image: np.ndarray, noise_variance: float, ksize: int = 5) -> np.ndarray:
    """Applies an adaptive mean filter based on local and global variance."""
    h, w = image.shape
    pad = ksize // 2
    padded = np.pad(image.astype(np.float64), pad, mode='reflect')
    output = np.zeros((h, w), dtype=np.uint8)
    
    for y in range(h):
        for x in range(w):
            patch = padded[y:y+ksize, x:x+ksize]
            local_mean = np.mean(patch)
            local_var = np.var(patch)
            
            if local_var <= noise_variance:
                val = local_mean
            else:
                val = padded[y+pad, x+pad] - (noise_variance / local_var) * (padded[y+pad, x+pad] - local_mean)
                
            output[y, x] = int(round(np.clip(val, 0, 255)))
            
    return output
```
