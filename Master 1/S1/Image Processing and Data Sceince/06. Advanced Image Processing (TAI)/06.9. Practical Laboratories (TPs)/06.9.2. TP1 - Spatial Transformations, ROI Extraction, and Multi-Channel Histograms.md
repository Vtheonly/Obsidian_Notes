# 06.9.2. TP1 - Spatial Transformations, ROI Extraction, and Multi-Channel Histograms

## 1. Overview
This note covers spatial cropping, resizing, rotations, text annotations, and computing multi-channel color histograms using Matplotlib, completing Exercises 4 and 5 of TP1.

## 2. Geometric Transformations & Annotation (Exercise 4)

```python
import cv2
import numpy as np

img = cv2.imread("Images/pepper.bmp")
if img is None:
    raise FileNotFoundError("Image file 'Images/pepper.bmp' not found.")

h, w = img.shape[:2]

# 1. Downscale by factor of 2
im2 = cv2.resize(img, (w // 2, h // 2), interpolation=cv2.INTER_LINEAR)

# 2. Crop Region of Interest (ROI)
# Defined boundary: y from 30 to 150, x from 200 to 400
im3 = img[30:150, 200:400].copy()

# 3. Draw blue rectangle and render green text
im4 = img.copy()
cv2.rectangle(im4, (200, 30), (400, 150), (255, 0, 0), thickness=2)
cv2.putText(im4, "My rectangle", (200, 20), cv2.FONT_HERSHEY_SIMPLEX, 0.6, (0, 255, 0), 2)

# 4. Rotate 90 degrees clockwise
im5 = cv2.rotate(img, cv2.ROTATE_90_CLOCKWISE)

# 5. Apply Gaussian blur
im6 = cv2.GaussianBlur(img, ksize=(5, 5), sigmaX=1.5)
```

## 3. Histogram Analysis: Grayscale vs. Multi-Channel Color (Exercise 5)

```python
import cv2
import numpy as np
import matplotlib.pyplot as plt

# 1. Grayscale Histogram on cameraman.bmp
cameraman_gray = cv2.imread("Images/cameraman.bmp", cv2.IMREAD_GRAYSCALE)
hist_gray = cv2.calcHist([cameraman_gray], [0], None, [256], [0, 256]).ravel()

# Custom verification using np.bincount
custom_hist_gray = np.bincount(cameraman_gray.ravel(), minlength=256)
assert np.array_equal(hist_gray.astype(int), custom_hist_gray), "Histogram mismatch."

# 2. Multi-Channel Color Histogram on pepper.bmp
pepper_bgr = cv2.imread("Images/pepper.bmp")
colors = ('blue', 'green', 'red')
channel_histograms = []

plt.figure(figsize=(10, 4))
for i, col_name in enumerate(colors):
    hist_chan = cv2.calcHist([pepper_bgr], [i], None, [256], [0, 256]).ravel()
    channel_histograms.append(hist_chan)
    plt.plot(hist_chan, color=col_name, label=f"Channel: {col_name.capitalize()}")

plt.title("Multi-Channel Color Histogram - pepper.bmp")
plt.xlabel("Intensity Bin [0, 255]")
plt.ylabel("Pixel Count")
plt.legend()
plt.grid(True, linestyle=":", alpha=0.6)
plt.show()
```

## Library Quick Reference
* `cv2.resize(img, (w, h), interpolation=...)` — spatial rescaling; the interpolation flag selects nearest/bilinear/bicubic reconstruction (note [[16. Image Spatial Transformations - Interpolation, Scaling, Cropping, and Affine Warping|16]]).
* `cv2.rotate(img, code)` — fast 90/180/270-degree rotations (note [[16. Image Spatial Transformations - Interpolation, Scaling, Cropping, and Affine Warping|16]]).
* `cv2.rectangle` / `cv2.putText` — draw bounding boxes and labels onto the image in Cartesian (x, y) coordinates (note [[16. Image Spatial Transformations - Interpolation, Scaling, Cropping, and Affine Warping|16]]).
* `cv2.GaussianBlur(img, ksize, sigmaX)` — isotropic low-pass smoothing applied here before resampling to suppress aliasing (note [[19. Spatial Image Restoration - Noise Models, Linear Convolution, and Fast Integral Filters|19]]).
* `cv2.calcHist([img], [ch], mask, [256], [0, 256])` — computes the per-channel 256-bin intensity histogram plotted below (note [[18. Visual Frequency and Radiometry - Histograms, Equalization, AHE, and CLAHE|18]]).
* `np.bincount(img.ravel(), minlength=256)` — fast integer histogram used to build the PMF directly (note [[04. NumPy Mathematical Engine - Vectorization, ufuncs, and Broadcasting Rules|04]]).
* `plt.figure / plt.plot / plt.title / plt.xlabel / plt.ylabel / plt.grid / plt.legend / plt.show` — the pyplot functional interface used for the PMF line chart (note [[03. Matplotlib Core Architecture - Figure, Axes, and Canvas Visualization Mechanics|03]]).
* `np.array_equal(a, b)` — verifies custom and library resampling produce identical buffers (note [[02. NumPy Array Manipulation - Slicing, Strides, Shapes, and Vectorized Indexing|02]]).
