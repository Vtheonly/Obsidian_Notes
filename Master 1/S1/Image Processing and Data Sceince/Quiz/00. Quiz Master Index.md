# 00. Quiz Master Index

The centralized assessment system of this repository. Every chapter, laboratory sequence, and library topic of the curriculum has a dedicated interactive question bank under this `Quiz/` directory. All banks are generated in the puzzle callout format (`[!question]`, `[!success]`, `[!example]` Obsidian callouts) with three question types per bank: True/False, Multiple Choice (one correct answer), and Matching.

## 2. Format and Validation

Each bank declares its source notes in the `sources` frontmatter, so every question is traceable to the exact lesson it assesses. Math uses single-dollar inline LaTeX and code uses single-backtick inline spans, so every file renders correctly in Obsidian.

The entire question bank system is machine-verified by the bundled parser `quiz_validator.py` (run it from the repository root):

```bash
python3 Quiz/quiz_validator.py Quiz/
```

It enforces the exact callout structure, option and answer lettering, bijective matching mappings, inline-only LaTeX, and cross-bank duplicate detection. All 20 banks (492 questions) pass with zero errors.
