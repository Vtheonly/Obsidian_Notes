# 03.2. Tutorial 04 - Multi-City Temperature Array Analysis with NumPy

## 1. Overview
This tutorial analyzes a 7-day temperature dataset across three Algerian cities (Alger, Annaba, Oran) using NumPy arrays, multi-axis aggregations, coordinate extractions, and boolean masks.

## 2. Input Temperature Matrix
The dataset contains daily temperature readings (°C) across 7 days:

| Day | Alger (Col 0) | Annaba (Col 1) | Oran (Col 2) |
| :--- | :--- | :--- | :--- |
| **Day 1** | 22 | 25 | 20 |
| **Day 2** | 24 | 27 | 21 |
| **Day 3** | 19 | 20 | 22 |
| **Day 4** | 25 | 29 | 28 |
| **Day 5** | 26 | 30 | 27 |
| **Day 6** | 21 | 21 | 23 |
| **Day 7** | 20 | 26 | 25 |

## 3. Code Implementation and Explanations

```python
import numpy as np

# 1. Create the 2D temperature matrix T
T = np.array([
    [22, 25, 20],
    [24, 27, 21],
    [19, 20, 22],
    [25, 29, 28],
    [26, 30, 27],
    [21, 21, 23],
    [20, 26, 25]
])

cities = ["Alger", "Annaba", "Oran"]
days = [f"Day {i}" for i in range(1, 8)]

# 2. Maximum temperature calculations
# Max across rows for each column (city)
max_per_city = T.max(axis=0)  
# Max across columns for each row (day)
max_per_day = T.max(axis=1)   
# Overall maximum scalar value
overall_max = T.max()         

print("--- City Maxima ---")
for city, val in zip(cities, max_per_city):
    print(f"  {city}: {val} °C")

print("\n--- Daily Maxima ---")
for day, val in zip(days, max_per_day):
    print(f"  {day}: {val} °C")

print(f"\nOverall Maximum: {overall_max} °C")

# 3. Locate exact day and city coordinates for overall maximum
flat_max_index = T.argmax()
row_idx, col_idx = np.unravel_index(flat_max_index, T.shape)
print(f"\nPeak recorded on {days[row_idx]} in {cities[col_idx]} at {overall_max} °C")

# 4. Compare daily maximum temperatures between Alger (col 0) and Oran (col 2)
alger_vs_oran = np.maximum(T[:, 0], T[:, 2])
print("\nHigher Temperature (Alger vs. Oran):")
for day, val in zip(days, alger_vs_oran):
    print(f"  {day}: {val} °C")

# 5. Append city averages as a new row vector
city_averages = T.mean(axis=0).reshape(1, 3)
T_with_averages = np.vstack([T, city_averages])
print("\nMatrix with Appended City Averages (Row 8):")
print(np.round(T_with_averages, 2))

# 6. Find days where Annaba was strictly hotter than both Alger and Oran
# Annaba is Col 1, Alger is Col 0, Oran is Col 2
annaba_hottest_mask = (T[:, 1] > T[:, 0]) & (T[:, 1] > T[:, 2])
print("\nDays when Annaba was the hottest city:")
for day_idx, is_hottest in enumerate(annaba_hottest_mask):
    if is_hottest:
        print(f"  {days[day_idx]} (Annaba: {T[day_idx, 1]} °C)")
```

## 4. Interpretation of Results
- Annaba recorded the overall peak temperature (30 °C on Day 5) and maintained the highest weekly average.
- Annaba was the hottest city on Days 1, 2, 4, 5, and 7.
- Oran recorded higher temperatures than Alger during mid-to-late week periods (Days 3, 4, 6, and 7).

## Library Quick Reference
* `np.array(list)` — instantiates the 7x3 temperature matrix as a contiguous `ndarray` (note [[01. NumPy Foundations - Memory Layout, ndarray Anatomy, and Array Instantiation|01]]).
* `T.max(axis=...)` / `T.mean(axis=...)` — multi-axis reductions: `axis=0` collapses rows per city, `axis=1` collapses columns per day (note [[04. NumPy Mathematical Engine - Vectorization, ufuncs, and Broadcasting Rules|04]]).
* `T.argmax()` + `np.unravel_index(idx, shape)` — flat maximum index converted to (day, city) coordinates (note [[02. NumPy Array Manipulation - Slicing, Strides, Shapes, and Vectorized Indexing|02]]).
* `np.maximum(a, b)` — element-wise ufunc computing the higher of two city vectors (note [[04. NumPy Mathematical Engine - Vectorization, ufuncs, and Broadcasting Rules|04]]).
* `.reshape(1, 3)` + `np.vstack` — broadcast-safe row vector appended to the matrix (note [[04. NumPy Mathematical Engine - Vectorization, ufuncs, and Broadcasting Rules|04]]).
* `(T[:, 1] > T[:, 0]) & (...)` — boolean mask with bitwise `&` selecting the days Annaba is hottest (note [[02. NumPy Array Manipulation - Slicing, Strides, Shapes, and Vectorized Indexing|02]]).
