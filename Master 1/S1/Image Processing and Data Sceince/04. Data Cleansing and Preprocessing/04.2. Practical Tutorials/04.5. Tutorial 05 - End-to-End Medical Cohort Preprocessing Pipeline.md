# 04.5. Tutorial 05 - End-to-End Medical Cohort Preprocessing Pipeline

## 1. Overview
This tutorial builds an end-to-end data cleaning and preprocessing pipeline on a messy 10-patient clinical dataset containing missing values, inconsistent text formats, outliers, and unscaled columns.

## 2. Input Dataset
```python
import pandas as pd
import numpy as np

raw_data = {
    'PatientID': ['P001', 'P002', 'P003', 'P004', 'P005', 'P006', 'P007', 'P008', 'P009', 'P010'],
    'Age': [25, np.nan, 65, 50, 80, 120, 45, 38, np.nan, 55],
    'BloodPressure': [120, 130, np.nan, 110, 200, 95, 125, 118, 122, 210],
    'Cholesterol': [200, 180, 250, 190, 300, 180, np.nan, 210, 220, 350],
    'Gender': ['Female', 'male', 'Male', 'female', 'MALE', None, 'female', 'female', 'FEMALE', 'Male'],
    'Diagnosis': ['Diabetes', 'Healthy', 'Diabetes', 'Healthy', 'Hypertension', 'Healthy', 'Diabetes', 'Healthy', None, 'Hypertension']
}
df = pd.DataFrame(raw_data)
```

## 3. Step-by-Step Pipeline Implementation

```python
from sklearn.preprocessing import StandardScaler

# Step 1: Text Standardization
for col in ['Gender', 'Diagnosis']:
    df[col] = df[col].astype(str).str.lower().str.strip().replace({'none': np.nan, 'nan': np.nan})

# Step 2: Categorical Imputation (Mode)
for col in ['Gender', 'Diagnosis']:
    mode_val = df[col].mode()[0]
    df[col] = df[col].fillna(mode_val)

# Step 3: Numerical Imputation (Median)
num_cols = ['Age', 'BloodPressure', 'Cholesterol']
for col in num_cols:
    median_val = df[col].median()
    df[col] = df[col].fillna(median_val)

# Step 4: Outlier Capping via IQR
for col in num_cols:
    Q1 = df[col].quantile(0.25)
    Q3 = df[col].quantile(0.75)
    IQR = Q3 - Q1
    lower = Q1 - 1.5 * IQR
    upper = Q3 + 1.5 * IQR
    df[col] = df[col].clip(lower=lower, upper=upper)

# Step 5: One-Hot Encoding (Dropping first category to prevent dummy variable trap)
df_encoded = pd.get_dummies(df, columns=['Gender', 'Diagnosis'], drop_first=True, dtype=int)

# Step 6: Feature Standardization
scaler = StandardScaler()
df_encoded[num_cols] = scaler.fit_transform(df_encoded[num_cols])

print("--- Preprocessed Medical Dataset ---")
display(df_encoded)
```
