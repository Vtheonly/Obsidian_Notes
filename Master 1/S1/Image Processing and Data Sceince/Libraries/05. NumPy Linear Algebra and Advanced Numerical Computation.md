# 05. NumPy Linear Algebra and Advanced Numerical Computation

## 1. Overview
Linear algebra is fundamental to data transformations and machine learning modeling. This note covers matrix multiplication, transpositions, determinants, matrix inversions, linear system solving, and eigenvalue decompositions using `np.linalg`.

## 2. Matrix Multiplication and Transposition
- Matrix multiplication requires inner dimensions to match: $(M \times K) \times (K \times N) \rightarrow (M \times N)$.
- In modern Python, matrix multiplication is performed using the `@` operator or `np.dot()`.
- Transposition switches row and column indices using `.T`.

```python
import numpy as np

A = np.array([[1, 2], 
              [3, 4]])
B = np.array([[5, 6], 
              [7, 8]])

# Matrix Dot Product:
C = A @ B  # [[1*5 + 2*7, 1*6 + 2*8], [3*5 + 4*7, 3*6 + 4*8]] -> [[19, 22], [43, 50]]

# Matrix Transpose:
A_T = A.T  # [[1, 3], [2, 4]]
```

## 3. The `np.linalg` Module Functions

| Function | Mathematical Operation | Description |
| :--- | :--- | :--- |
| `np.linalg.det(A)` | $\det(A)$ | Computes the scalar determinant of a square matrix. |
| `np.linalg.inv(A)` | $A^{-1}$ | Computes the multiplicative inverse of a non-singular matrix ($A A^{-1} = I$). |
| `np.linalg.solve(A, b)`| $A x = b \rightarrow x = A^{-1} b$ | Solves a system of linear equations using LU decomposition. |
| `np.linalg.norm(x)` | $\|x\|_2 = \sqrt{\sum x_i^2}$ | Computes the Euclidean norm (magnitude) of a vector or matrix. |
| `np.trace(A)` | $\sum A_{ii}$ | Computes the sum of elements along the main diagonal. |
| `np.linalg.matrix_rank(A)`| $\text{rank}(A)$ | Computes the number of linearly independent row or column vectors. |
| `np.linalg.eig(A)` | $A v = \lambda v$ | Computes scalar eigenvalues $\lambda$ and corresponding eigenvectors $v$. |

### Solving Systems of Linear Equations
Solve the system:
$$2x + y = 8$$
$$x + 3y = 14$$

```python
# System matrix A and right-hand side vector b
A = np.array([[2.0, 1.0],
              [1.0, 3.0]])
b = np.array([8.0, 14.0])

# Solve Ax = b
solution = np.linalg.solve(A, b)
print(f"Solution: x = {solution[0]:.1f}, y = {solution[1]:.1f}") # x=2.0, y=4.0
```
