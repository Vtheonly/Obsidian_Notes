# 10. Matplotlib and Seaborn Statistical Plotting for Tabular Data

## 1. Overview
This note covers statistical data visualization using Matplotlib and Seaborn, including histograms (empirical PDFs), box plots, violin plots, correlation heatmaps, and 3D surface meshes. Advanced visualization helps diagnose processing issues: plotting intensity distributions, displaying 3D intensity terrains, and comparing multi-channel grids side by side.

## 2. Seaborn Integration with Pandas
Seaborn is built on top of Matplotlib and integrates directly with Pandas DataFrames, handling aggregations and statistical representations automatically. The bundled `sns.load_dataset(name)` helper fetches standard example datasets (e.g., `"titanic"`, `"tips"`) as DataFrames for practicing:

```python
import seaborn as sns
import matplotlib.pyplot as plt

# Load a standard practice dataset as a DataFrame
tips = sns.load_dataset("tips")

# Set consistent plotting theme
sns.set_theme(style="whitegrid")
```

## 3. Primary Statistical Plot Types

### Histograms and Kernel Density Estimation (KDE)
Histograms display the distribution of continuous features by grouping values into bins. Adding a KDE line overlays an estimated probability density curve:

```python
fig, ax = plt.subplots(figsize=(7, 4))
sns.histplot(data=df, x="Salary", kde=True, bins=20, color="teal", ax=ax)
ax.set_title("Salary Distribution with KDE Overlay", fontweight="bold")
plt.show()
```

### Box Plots and Violin Plots
- **Box Plot**: Shows data distributions using quartiles (Q1, median, Q3) and highlights outliers beyond $1.5 \times \text{IQR}$.
- **Violin Plot**: Combines a box plot with a rotated kernel density curve, showing where data points are concentrated:

```python
fig, axs = plt.subplots(1, 2, figsize=(12, 5))

# Box Plot
sns.boxplot(data=df, x="Department", y="Salary", palette="Set2", ax=axs[0])
axs[0].set_title("Salary Spread Across Departments")

# Violin Plot
sns.violinplot(data=df, x="Department", y="Salary", palette="Set2", ax=axs[1])
axs[1].set_title("Salary Density Distributions")

plt.tight_layout()
plt.show()
```

### Correlation Heatmaps
Heatmaps visualize relationships across multi-dimensional correlation matrices using color scales:

```python
fig, ax = plt.subplots(figsize=(6, 5))
correlation_matrix = df[["Age", "Salary", "BloodPressure"]].corr()

sns.heatmap(
    correlation_matrix, 
    annot=True, 
    fmt=".2f", 
    cmap="Blues", 
    square=True, 
    linewidths=0.5, 
    ax=ax
)
ax.set_title("Feature Correlation Matrix", fontweight="bold")
plt.show()
```

## 4. Tonal Histograms: `Axes.hist(x, bins=None, range=None, density=False)`
The raw Matplotlib histogram underlies every Seaborn plotting routine and is the tool of choice for image tonal analysis (empirical PDF of pixel intensities):

- `bins`: Number (or explicit edges) of the histogram bars. For 8-bit images use `bins=256, range=(0, 256)` so each gray level gets its own bar.
- `range`: The lower and upper bin edges; values outside are ignored.
- `density=True`: Normalizes bar heights so the total area equals $1$, yielding an empirical probability density function.

```python
import numpy as np

# Image tonal histogram: empirical PDF of gray levels
img = np.random.randint(0, 256, size=(64, 64), dtype=np.uint8)

fig, ax = plt.subplots(figsize=(6, 4))
ax.hist(img.ravel(), bins=256, range=(0, 256), density=True, color="steelblue")
ax.set_title("Empirical Intensity PDF")
ax.set_xlabel("Gray Level")
ax.set_ylabel("Probability Density")
plt.show()
```

## 5. 3D Intensity Topography: `plot_surface`
Treating pixel values as elevation ($z$-axis) helps visualize why spatial gradients and morphological probes behave like physical surfaces:

```python
from mpl_toolkits.mplot3d import Axes3D  # noqa: F401 (registers the 3d projection)

# Generate a synthetic 2D Gaussian bell curve
x = np.linspace(-2, 2, 50)
y = np.linspace(-2, 2, 50)
X, Y = np.meshgrid(x, y)
Z = np.exp(-(X**2 + Y**2))

fig = plt.figure(figsize=(8, 6))
ax = fig.add_subplot(111, projection='3d')

# Render the continuous topographical mesh
surf = ax.plot_surface(X, Y, Z, cmap='viridis', edgecolor='none')
ax.set_title("3D Intensity Topography")
fig.colorbar(surf, ax=ax, shrink=0.5)
plt.show()
```
