# 09. Pandas Data Cleansing - Handling Nulls, Deduplication, and String Normalization

## 1. Overview
Data cleaning prepares raw, inconsistent datasets for analysis. This note covers detecting and imputing missing values (`NaN`), identifying and removing duplicate rows, and standardizing text features.

## 2. Missing Value Treatment
Missing data in Pandas is represented by `np.nan` (or `pd.NA`).

```python
import pandas as pd
import numpy as np

# 1. Detection: Count missing values per column
null_counts = df.isnull().sum()

# 2. Removal: Drop rows containing missing values
df_cleaned = df.dropna()                         # Drops rows with any null value
df_subset = df.dropna(subset=["Age"])            # Drops rows only if 'Age' is null

# 3. Imputation: Fill missing entries with summary metrics
df["Age"] = df["Age"].fillna(df["Age"].median()) # Impute with median
df["City"] = df["City"].fillna("Unknown")        # Impute with constant label
```

## 3. Deduplication
Duplicate records can skew summary metrics and bias predictive models:

```python
# Find duplicate rows: Returns a boolean Series
is_dup = df.duplicated()

# Remove duplicate rows, keeping the first occurrence
df_unique = df.drop_duplicates(keep="first")

# Remove duplicate rows based on specific primary keys
df_unique_patients = df.drop_duplicates(subset=["PatientID"], keep="last")
```

## 4. Vectorized String Manipulation (`.str` accessor)
String columns can be transformed cleanly using the vectorized `.str` accessor without writing manual loops:

```python
# Convert text to uppercase, strip leading/trailing whitespace, and replace patterns
df["Name"] = df["Name"].str.upper()
df["City"] = df["City"].str.strip().str.replace("Blida", "Blida City")
```

## 5. Adding, Renaming, and Dropping Columns
```python
# Add an engineered column
df["Bonus"] = df["Salary"] * 0.10

# Rename existing columns in-place
df.rename(columns={"Salary": "MonthlySalary"}, inplace=True)

# Drop redundant columns
df.drop(columns=["Bonus"], inplace=True)
```

## 6. Categorical Encoding: `pd.get_dummies()`
Converts categorical text columns into binary indicator (one-hot) columns so that numerical models can consume them. Each category level becomes its own 0/1 column:

```python
# DataFrame with a categorical 'Gender' column (M/F) and numeric features
encoded = pd.get_dummies(df, columns=["Gender"], drop_first=False)
# Adds 'Gender_F' and 'Gender_M' columns with 0/1 values.

# drop_first=True avoids the dummy-variable trap (perfect collinearity)
encoded = pd.get_dummies(df, columns=["Gender"], drop_first=True)
```

Boolean dummy columns are often cast to integers before model fitting: `encoded.astype({"Gender_M": int})`.
