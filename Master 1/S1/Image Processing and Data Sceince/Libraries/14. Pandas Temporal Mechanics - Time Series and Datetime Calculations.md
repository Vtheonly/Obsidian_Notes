# 14. Pandas Temporal Mechanics - Time Series and Datetime Calculations

## 1. Overview
Time-series datasets index data points sequentially over time. This note covers parsing dates using `pd.to_datetime()`, frequency resampling, shift operations, rolling window calculations, and the `.dt` accessor.

## 2. Parsing Datetime Formats
The `pd.to_datetime()` function converts string representations into high-precision `datetime64[ns]` objects:

```python
import pandas as pd

dates = ["2026-01-01", "2026-02-01", "2026-03-01"]
date_series = pd.to_datetime(dates)

# Access temporal components using the .dt accessor:
years = date_series.dt.year
months = date_series.dt.month_name()
days = date_series.dt.day
```

## 3. Resampling, Shifting, and Rolling Windows
When working with a `DatetimeIndex`, Pandas provides dedicated temporal methods:

```python
# Generate continuous monthly date ranges
df.index = pd.date_range(start="2026-01-01", periods=12, freq="MS")

# 1. Resample: Aggregate monthly metrics to quarterly totals
quarterly_totals = df["Sales"].resample("Q").sum()

# 2. Shift: Shift values to compute month-over-month percent change
df["PrevMonthSales"] = df["Sales"].shift(1)
df["GrowthPct"] = ((df["Sales"] - df["PrevMonthSales"]) / df["PrevMonthSales"]) * 100

# 3. Rolling Windows: Compute 3-month moving averages
df["3MonthSMA"] = df["Sales"].rolling(window=3).mean()
```
