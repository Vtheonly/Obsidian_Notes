# 07. Pandas Data Ingestion, Inspection, and Type Coercion

## 1. Overview
Data analysis begins with ingesting and inspecting raw data. This note covers importing and exporting tabular files, auditing missing values, inspecting DataFrame shapes and column data types, and type coercion.

## 2. Ingesting and Exporting Datasets

### Reading Data
```python
import pandas as pd

# CSV Ingestion:
df_csv = pd.read_csv("dataset.csv", sep=",", encoding="utf-8")

# Reading specific columns and setting index during load:
df_sub = pd.read_csv("dataset.csv", usecols=["PatientID", "Age"], index_col="PatientID")
```

### Exporting Data
```python
# Export to CSV without persisting the DataFrame index:
df_csv.to_csv("cleaned_data.csv", index=False)

# Exporting across various formats:
df_csv.to_excel("report.xlsx", index=False) # Requires openpyxl
df_csv.to_json("data.json", indent=4)
df_csv.to_pickle("data.pkl")                # High-speed binary format
```

## 4. Selecting Columns by Data Type and Type Coercion
- `df.select_dtypes(include=[...])`: Subsets columns based on their data types.
- `pd.to_numeric(series, errors='coerce')`: Converts string series into numbers, safely replacing invalid values with `NaN`.
- `series.astype(dtype)`: Explicitly casts an entire column to a target type.

```python
# Subsetting columns by type:
numeric_cols = df.select_dtypes(include="number").columns.tolist()
string_cols = df.select_dtypes(include=["object", "string"]).columns.tolist()

# Type coercion:
df["Age"] = pd.to_numeric(df["Age"], errors="coerce")
df["MonthlySalary"] = df["MonthlySalary"].fillna(0).astype(int)
```
