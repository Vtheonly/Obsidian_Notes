# 13. Pandas Data Reshaping - Pivoting, Unpivoting, Stacking, and Melting

## 1. Overview
Data often needs to be reshaped between wide and long formats for analysis and modeling. This note covers `pivot()`, `pivot_table()`, and `melt()`.

## 2. Reshaping Frameworks: Long vs. Wide Formats

```mermaid
graph LR
    Wide["Wide Format: Category A | Category B"] -->|melt: unpivot| Long["Long Format: Variable | Value"]
    Long -->|pivot_table: aggregate & reshape| Wide
```

- **Wide Format**: Data is spread across multiple columns (e.g., one column per year or category). Often preferred for executive tables.
- **Long Format**: Data is stacked into key-value pairs (`variable`, `value`), making it easier to filter, group, and visualize in Seaborn.

## 3. Reshaping DataFrames: `pivot()` vs. `pivot_table()`
- `df.pivot(index, columns, values)`: Reshapes unique index-column combinations into a wide table. If duplicate entries exist, it raises a `ValueError`.
- `df.pivot_table(index, columns, values, aggfunc='mean')`: Reshapes data like `pivot()`, but handles duplicate entries gracefully by applying an aggregation function (e.g., `mean`, `sum`, `count`):

```python
import pandas as pd

# Creating a summary table of average salaries across cities and departments:
pivoted = df.pivot_table(
    index="City", 
    columns="Department", 
    values="Salary", 
    aggfunc="mean"
)
display(pivoted)
```

## 4. Unpivoting Data with `melt()`
`melt()` converts wide DataFrames into a long format:

```python
# Unpivot wide salary and age metrics into a long-format key-value table:
melted = df.melt(
    id_vars=["Name", "City"],           # Identifier columns to keep fixed
    value_vars=["Age", "Salary"],       # Measurement columns to unpivot
    var_name="Metric",                  # New column name for measurement labels
    value_name="Value"                  # New column name for values
)
display(melted.head())
```
