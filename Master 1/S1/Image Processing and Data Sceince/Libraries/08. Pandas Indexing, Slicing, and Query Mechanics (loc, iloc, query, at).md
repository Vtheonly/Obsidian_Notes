# 08. Pandas Indexing, Slicing, and Query Mechanics (loc, iloc, query, at)

## 1. Overview
Pandas provides several indexing accessors to select rows and columns. This note covers label-based indexing (`.loc`), position-based indexing (`.iloc`), scalar accessors (`.at`, `.iat`), boolean filtering, and the `.query()` method.

## 2. The Four Primary Accessors

| Accessor | Indexing Paradigm | Inputs | Bounds Inclusion | Relative Speed |
| :--- | :--- | :--- | :--- | :--- |
| **`.loc[]`** | **Label-based** | Row/Col label strings | **Includes** stop index (`'a':'c'`) | Standard |
| **`.iloc[]`**| **Position-based**| Integer coordinates (`0..N-1`) | **Excludes** stop index (`0:2`) | Standard |
| **`.at[]`** | **Label scalar** | Exact row and column label | Returns single scalar | Fast |
| **`.iat[]`** | **Position scalar**| Exact integer coordinates | Returns single scalar | Fastest |

```python
import pandas as pd

df = pd.DataFrame(
    data=[["Amel", 25], ["Sami", 28], ["Rania", 22]],
    index=["row_a", "row_b", "row_c"],
    columns=["Name", "Age"]
)

# Label-based slicing with .loc (includes 'row_b')
subset_loc = df.loc["row_a":"row_b", ["Name", "Age"]]

# Position-based slicing with .iloc (excludes index 2)
subset_iloc = df.iloc[0:2, 0:2]

# Fast scalar retrieval
val_at = df.at["row_a", "Age"]   # 25
val_iat = df.iat[0, 1]            # 25
```

## 3. Boolean Filtering and Logical Operators
When filtering DataFrame rows with multiple conditions, use bitwise operators (`&` for AND, `|` for OR, `~` for NOT). Each individual condition must be enclosed in parentheses:

```python
# Select patients older than 25 living in Algiers
high_risk = df[(df["Age"] > 25) & (df["City"] == "Algiers")]
```

## 4. The `.query()` Method
The `.query()` method allows filtering using readable, string-based expressions:

```python
# Equivalent query expression:
filtered = df.query('Age > 25 and City == "Algiers"')
```

## 5. Non-Destructive Filtering with `.where()`
Unlike boolean filtering (which drops non-matching rows), the `.where()` method preserves the DataFrame's original dimensions, replacing values in non-matching rows with `NaN`:

```python
preserved_shape = df.where(df["Age"] > 25)
```
