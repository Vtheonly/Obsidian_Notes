# 02.10. Code Modularity, Packaging, and Standard Library Systems

## 1. Overview
Modular programming organizes code into reusable modules and packages. This note covers import semantics, the role of `__init__.py`, the `if __name__ == '__main__'` entry point, and key Python standard library modules (`math`, `random`, `datetime`, `statistics`, `os`).

## 2. Code Modularity: Modules and Packages
- **Module**: A single Python file (`.py`) containing executable code, functions, and classes.
- **Package**: A directory containing modules alongside an `__init__.py` file, which marks the folder as an importable Python package.

```text
my_analytics_package/
│
├── __init__.py           # Package initializer
├── data_cleaning.py      # Cleaning submodule
└── math_metrics.py       # Metrics submodule
```

```python
# Content of my_analytics_package/__init__.py
from .data_cleaning import clean_text
from .math_metrics import compute_mean

__all__ = ['clean_text', 'compute_mean']
```

### The Role of `__name__ == "__main__"`
When a file runs directly from the terminal (`python file.py`), CPython assigns the string `"__main__"` to the built-in variable `__name__`. If the file is imported by another module (`import file`), `__name__` is set to the file's module name instead.
This mechanism lets a module include standalone executable code (such as self-tests or CLI scripts) that won't run when the module is imported elsewhere:

```python
def calculate_bmi(weight: float, height: float) -> float:
    return weight / (height ** 2)

if __name__ == "__main__":
    # Runs during standalone script execution, skipped on import
    print("Self-test:", calculate_bmi(75, 1.80))
```

## 3. Core Standard Library Modules for Data Science

### `math` Module
Provides basic mathematical functions implemented on C doubles:
```python
import math
sqrt_val = math.sqrt(16)        # 4.0
log_val = math.log10(100)       # 2.0
exp_val = math.exp(2)           # 7.389...
rounded = math.ceil(4.2)        # 5 (Round up)
floored = math.floor(4.8)       # 4 (Round down)
```

### `random` Module
Provides pseudo-random number generators using the Mersenne Twister algorithm:
```python
import random
random.seed(42)                 # Guarantees reproducibility
int_val = random.randint(1, 10) # Random integer in range [1, 10]
float_val = random.uniform(10, 20)
sampled = random.sample([1, 2, 3, 4, 5], 3) # Sampling without replacement
```

### `datetime` Module
Provides classes for manipulating dates, times, and intervals:
```python
import datetime
now = datetime.datetime.now()
current_date = datetime.date.today()
delta = datetime.date(2026, 10, 1) - datetime.date(2026, 9, 1)
print(f"Days between: {delta.days}")  # 30 days

# datetime.timedelta: a duration, built explicitly from days/seconds/microseconds
one_week = datetime.timedelta(weeks=1)
next_check = current_date + one_week            # date arithmetic -> date
elapsed = datetime.datetime.now() - start_time  # subtracting datetimes -> timedelta
print(f"Pipeline took {elapsed.total_seconds():.2f} s")   # duration as float seconds
```
`datetime.timedelta` is the currency of all date arithmetic: adding/subtracting a `timedelta` to a `date` or `datetime` shifts it in time, while subtracting two dates/times yields one — access `.days`, `.seconds`, or `.total_seconds()` (used for benchmark timing in the tutorials).

### `statistics` Module
Provides basic statistical calculations on Python iterables:
```python
import statistics
vals = [10, 12, 15, 15, 18, 20, 25]
mean_val = statistics.mean(vals)
median_val = statistics.median(vals)
stdev_val = statistics.stdev(vals)
```

### `os` Module
Provides portable operating system interfaces:
```python
import os
current_dir = os.getcwd()
os.makedirs("data/processed", exist_ok=True)
exists = os.path.exists("data/raw/data.txt")
```

The `os.path` submodule builds platform-independent file paths and inspects them:
```python
import os

# Join path components with the OS-native separator ('/' on Linux, '\\' on Windows)
data_file = os.path.join("data", "raw", "students.csv")   # 'data/raw/students.csv'

# Decompose and normalize paths
folder  = os.path.dirname(data_file)          # 'data/raw'
name    = os.path.basename(data_file)         # 'students.csv'
absolute = os.path.abspath(data_file)         # full path from CWD -> reproducible I/O
```
`os.path.join` is the correct way to build paths in every tutorial script — string concatenation with `+` breaks the moment code moves between operating systems.

### `sys` Module
Interpreter state and control flow:
```python
import sys

# Make a sibling 'utils' package importable when running a script directly
sys.path.append(os.path.join(os.path.dirname(__file__), ".."))
import utils.transform          # now resolves against the appended directory

# Abort with an explicit exit status (non-zero signals failure to the shell / CI)
if not os.path.exists(data_file):
    sys.exit("ERROR: dataset not found — aborting before analysis")
```
`sys.path` is the list of directories the importer searches; appending a project root to it is the lightweight alternative to installing a package, used by the modular tutorials. `sys.exit` terminates immediately with an exit code — `0` means success, anything else signals an error.

### `csv` Module
Streaming row-based file I/O without loading the whole file into memory:
```python
import csv

# DictReader maps each row to a dict keyed by the header line — self-documenting
with open("students.csv", newline="") as fh:
    for row in csv.DictReader(fh):
        grade = float(row["grade"])      # access columns BY NAME, not by index

# writer emits RFC-4180-compliant CSV (handles quoting of commas in values)
with open("out.csv", "w", newline="") as fh:
    writer = csv.writer(fh)
    writer.writerow(["city", "mean_temp"])
    writer.writerows(results)
```
