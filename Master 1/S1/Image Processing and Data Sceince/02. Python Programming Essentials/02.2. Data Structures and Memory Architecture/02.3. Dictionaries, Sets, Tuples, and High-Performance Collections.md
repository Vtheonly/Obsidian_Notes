# 02.3. Dictionaries, Sets, Tuples, and High-Performance Collections

## 1. Overview
This note covers Python's core collection types: immutable tuples, hash-table-backed dictionaries and sets, and the double-ended queue (`deque`).

## 2. Structural Comparison

| Collection | Syntax | Mutability | Ordering | Hash Table Backed | Lookup Complexity | Primary Use Case |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **Tuple** | `(1, 2, 3)` | Immutable | Ordered | No | $O(n)$ search, $O(1)$ index | Fixed records, database row tuples, hashable dictionary keys |
| **Dictionary**| `{"k": "v"}` | Mutable | Ordered (3.7+) | Yes | $O(1)$ average | Key-value mapping, metadata storage |
| **Set** | `{1, 2, 3}` | Mutable | Unordered | Yes | $O(1)$ average | Deduplication, membership testing, set mathematics |
| **Deque** | `deque([1, 2])`| Mutable | Ordered | No (Doubly Linked) | $O(1)$ ends, $O(n)$ middle | Stacks (LIFO) and Queues (FIFO) |

## 3. Hash Table Mechanics: Dictionaries and Sets
CPython dictionaries and sets rely on open addressing hash tables.
1. When inserting key $k$, Python computes its hash: $h = \text{hash}(k)$.
2. $h$ is mapped to an index within the hash table bucket array.
3. If an index collision occurs, Python resolves it using a perturbation probing sequence:

$$i = (5 \times i + 1 + \text{perturb}) \pmod{\text{size}}$$

*Requirement*: Any object used as a dictionary key or set member must be **hashable** (implementing an immutable `__hash__()` and `__eq__()`). Mutable objects like lists cannot be used as dictionary keys.

### Dictionary Safe Access and Mutation
```python
person = {"name": "Ali", "age": 30, "city": "Alger"}

# Safe retrieval avoiding KeyError exceptions
email = person.get("email", "Not Registered")

# Mutation and element removal
person["age"] = 31             # In-place update
del person["city"]             # In-place deletion

# Extracting view objects
keys = person.keys()
values = person.values()
items = person.items()
```

### Set Mathematics
```python
set_a = {1, 2, 3}
set_b = {3, 4, 5}

union_set = set_a | set_b         # {1, 2, 3, 4, 5}
intersection = set_a & set_b     # {3}
difference = set_a - set_b       # {1, 2}
symmetric_diff = set_a ^ set_b   # {1, 2, 4, 5}
```

## 4. Stacks (LIFO) and Queues (FIFO) with `collections.deque`
While a standard Python list can function as a stack (using `append()` and `pop()` in $O(1)$ time), using it as a FIFO queue (using `list.pop(0)`) requires shifting every remaining element left, running in $O(n)$ time.
`collections.deque` uses a doubly linked list of fixed-size memory blocks, providing $O(1)$ time complexity for insertions and deletions at both ends.

```python
from collections import deque

queue = deque()
queue.append("Patient A")      # Enqueue
queue.append("Patient B")
first_served = queue.popleft() # Dequeue in O(1) time
print(f"Served: {first_served}, Remaining: {list(queue)}")
```
