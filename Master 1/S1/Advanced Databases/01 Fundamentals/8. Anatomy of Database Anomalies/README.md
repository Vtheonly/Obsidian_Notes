# 8. Anatomy of Database Anomalies

This chapter explains how a flat, un-normalized relation creates redundancy and insertion, update, and deletion anomalies, then connects those problems to decomposition and normalization.

- propose a decomposition that separates independent facts;
- connect anomaly analysis to normalization.
