#  Chapter 09 — NAT & Perimeter Security

> [!abstract] Chapter Goal
> Understand how the network boundary — the place where private meets public — is engineered. Cover the three NAT types (static, dynamic, PAT), inbound access techniques (port forwarding, triggering), and the architectural patterns (DMZ, proxy, VPN) that secure the edge.

##  Learning Outcomes

After this chapter you should be able to:

- Explain why NAT exists and why it's both essential and controversial.
- Distinguish static NAT, dynamic NAT, and PAT by mapping type, use case, and pool demand.
- Trace a packet through a PAT translation, identifying what changes at L3 and L4.
- Configure port forwarding to expose an internal service.
- Draw a DMZ with appropriate firewall placement.
- Compare a forward proxy and a reverse proxy.
- Explain the difference between a site-to-site VPN and a remote-access VPN.
