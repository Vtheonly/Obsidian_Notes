#  Chapter 12 — Tunnels & Remote Access

> [!abstract> Chapter Goal
> Expose local services to the public internet without deploying infrastructure. Tools like **Ngrok** and **Cloudflare Tunnels** create outbound-only tunnels from your machine to a public endpoint, sidestepping NAT and firewall restrictions. This chapter covers the tunneling primitives, the major tools, and the trade-offs.

##  Learning Outcomes

After this chapter you should be able to:

- Explain what a tunnel is and how encapsulation enables it.
- Distinguish an overlay network from an underlay network.
- Expose a local HTTP service to the public internet with Ngrok.
- Set up a Cloudflare Tunnel for permanent access to a home lab service.
- Choose the right tunneling tool for a given scenario.
- Identify the security implications of exposing local services.
