# 04.05 — FLSM (Fixed-Length Subnet Masking)

> [!abstract] Equal-Sized Subnets
> **FLSM** divides a network block into **equal-sized subnets** by borrowing a fixed number of bits from the host portion. Every subnet ends up with the same prefix length and the same number of usable hosts. FLSM is the simplest subnetting technique and the foundation for understanding VLSM.

---

##  The Math

Three formulas govern FLSM:

1. **Number of subnets created** (borrow $n$ bits):
$$\text{Subnets} = 2^n$$

2. **Number of usable hosts per subnet** (with $h$ host bits remaining):
$$\text{Usable hosts} = 2^h - 2$$

3. **Host bits remaining** (after borrowing $n$ bits from a network with default prefix $P$):
$$h = 32 - (P + n)$$

> [!warning] Why "$-2$"?
> The first address in a subnet (all host bits = 0) is the **network address** — identifies the network. The last address (all host bits = 1) is the **broadcast address** — sends to all hosts. Neither can be assigned to a host. Hence $2^h - 2$.

---

##  Why Subnet?

You subnet a network block for four reasons:

1. **Reduce broadcast traffic** — a /16 with 65K hosts generates enormous broadcast load. Splitting into /24s caps each broadcast domain at 254 hosts.
2. **Improve security** — subnets create natural boundaries for ACLs and firewalls.
3. **Isolate networks** — separate finance from engineering, guest Wi-Fi from corporate, etc.
4. **Simplify administration** — smaller subnets are easier to document and troubleshoot.

---

##  Worked Example

**Given:** Network block `184.65.94.20` with custom subnet mask `255.255.240.0`.

### Step 1: Identify the Class and Default Network

- First octet `184` → Class B (range 128–191).
- Class B default prefix: `/16`.
- Default classful network: `184.65.0.0/16`.

### Step 2: Parse the Custom Subnet Mask

Custom mask: `255.255.240.0`
- First octet `255` = `11111111` (8 bits)
- Second octet `255` = `11111111` (8 bits)
- Third octet `240` = `11110000` (4 bits)
- Fourth octet `0` = `00000000` (0 bits)
- Total bits set: 8 + 8 + 4 + 0 = **20** → prefix `/20`.

So the network + subnet portion is 20 bits; the host portion is 32 − 20 = 12 bits.

### Step 3: Calculate Subnetting Capacity

- Borrowed bits $n$: 4 (the 4 bits in the third octet beyond the default /16).
- Number of subnets: $2^4 = 16$ subnets.
- Host bits $h$: $32 - 20 = 12$.
- Usable hosts per subnet: $2^{12} - 2 = 4096 - 2 = 4094$.

### Step 4: Determine the Specific Subnet for a Host

Given a host `184.65.94.20/20`, compute its subnet address by bitwise ANDing the IP with the mask:

| | Third octet | Fourth octet |
| :--- | :--- | :--- |
| Host IP | `94` = `01011110` | `20` = `00010100` |
| Mask | `240` = `11110000` | `0` = `00000000` |
| **Subnet bits** | **`01010000` = `80`** | **`00000000` = `0`** |

Resulting subnet address: `184.65.80.0/20`.

### Step 5: Find the Full Range

- **Subnet address:** `184.65.80.0` (host bits all 0)
- **First usable IP:** `184.65.80.1`
- **Last usable IP:** `184.65.95.254`
- **Broadcast:** `184.65.95.255` (host bits all 1, i.e., third octet `80 + 15 = 95`, fourth octet `255`)

The block size is $2^{12} = 4096$ addresses. The next subnet starts at `184.65.96.0` (third octet `80 + 16 = 96`, since the 4 borrowed bits give a block size of 16 in the third octet).

---

##  Block Size Shortcut

For any prefix length, the **block size** in the octet where the mask changes is `256 - mask_value_in_that_octet`:

| Mask octet | Block size | Subnets in a /24 |
| :-: | :-: | :-: |
| `128` | 128 | 2 (/25) |
| `192` | 64 | 4 (/26) |
| `224` | 32 | 8 (/27) |
| `240` | 16 | 16 (/28) |
| `248` | 8 | 32 (/29) |
| `252` | 4 | 64 (/30) |

For our example: mask octet is `240`, so block size is `256 - 240 = 16`. Subnets in the third octet are: `0, 16, 32, 48, 64, 80, 96, 112, 128, 144, 160, 176, 192, 208, 224, 240`. Our host's third octet `94` falls in the `80–95` block (since `80 ≤ 94 < 96`), so its subnet is `184.65.80.0/20`.

##  FLSM Cheat Sheet — Prefixes & Host Counts

| Prefix | Mask | Usable Hosts | Block Size (in last octet) |
| :-: | :--- | :-: | :-: |
| /24 | 255.255.255.0 | 254 | 256 |
| /25 | 255.255.255.128 | 126 | 128 |
| /26 | 255.255.255.192 | 62 | 64 |
| /27 | 255.255.255.224 | 30 | 32 |
| /28 | 255.255.255.240 | 14 | 16 |
| /29 | 255.255.255.248 | 6 | 8 |
| /30 | 255.255.255.252 | 2 | 4 |
| /31 | 255.255.255.254 | 0 (or 2 P2P, RFC 3021) | 2 |
| /32 | 255.255.255.255 | 1 (host route) | 1 |

> [!note] /31 for Point-to-Point
> RFC 3021 allows `/31` for point-to-point links (router-to-router), giving 2 usable addresses with no broadcast/network wasted. Saves addresses on large WAN fabrics. Cisco IOS supports this with `no ip directed-broadcast` and proper config.

---

##  FLSM Limitations

FLSM is wasteful when subnets have very different host requirements. Example:

| Subnet | Hosts needed | With /26 (62 hosts) | Wasted |
| :--- | :-: | :-: | :-: |
| Engineering | 50 | 62 | 12 |
| Sales | 30 | 62 | 32 |
| HR | 12 | 62 | 50 |
| WAN link | 2 | 62 | 60 |

If you use FLSM `/26` for all four subnets, you waste 154 addresses out of 248 allocated. **VLSM** ([[04 - IPv4 Network Layer/04.06 VLSM|04.06]]) fixes this by giving each subnet its own mask.

---

##  Memory Aids

- **"Borrow Bits → Create Subnets → Less Hosts"** — more subnet bits always means fewer host bits.
- Mask value `240` = `11110000` → count the 1s (4) → that's how many bits you borrowed.
- Subnet ID = `IP AND Mask`. Broadcast = `Subnet ID OR (NOT Mask)`.
- For subnet 0 in any /N: the subnet address equals the classful network address (e.g., `192.168.1.0/24` → subnet 0 is `192.168.1.0`).
