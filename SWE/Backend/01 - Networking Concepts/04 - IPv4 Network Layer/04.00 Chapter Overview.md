#  Chapter 04 — IPv4 Network Layer

> [!abstract] Chapter Goal
> Master **logical addressing** — the addressing scheme that lets any host find any other host across arbitrarily many L2 networks. This chapter covers the IPv4 address structure, classful addressing, RFC 1918 private ranges, and the three subnetting techniques (FLSM, VLSM, CIDR) that are the bread-and-butter of every network engineer's job.

Subnetting is the single most-tested topic in any networking cert (CCNA, Network+, etc.). It's also the most arithmetic-heavy. Spend extra time on [[04 - IPv4 Network Layer/04.05 FLSM|FLSM]] and [[04 - IPv4 Network Layer/04.06 VLSM|VLSM]] — and use the [[14 - Memory Aids & Mnemonics/14.01 IPv4 Subnetting Memory Tricks|subnetting mnemonics]] to lock the patterns in.

##  Learning Outcomes

After this chapter you should be able to:

- Decompose any IPv4 address into network and host portions given a mask.
- Identify the class of any IPv4 address from its first octet alone.
- List the RFC 1918 private ranges and explain why they exist.
- Given a network block and a list of subnet size requirements, allocate addresses optimally with VLSM.
- Summarize a list of contiguous subnets into a single CIDR route.
- Validate that a host IP and its configured gateway are in the same subnet.
- Calculate subnet ID, broadcast, and usable host range from any IP/prefix pair in under 60 seconds.
