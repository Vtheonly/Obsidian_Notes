#  Chapter 11 — Application Layer

> [!abstract> Chapter Goal
> The protocols users actually touch: DNS for name resolution, HTTP/HTTPS for the web, TLS for encryption, SNI for virtual hosting, WebSockets for real-time bidirectional communication, and XHR for in-browser AJAX. Plus the classic email and file-transfer protocols. This chapter merges the previously isolated application-layer notes into a coherent whole.

##  Learning Outcomes

After this chapter you should be able to:

- Explain the DNS resolution chain from browser cache to root server to authoritative server.
- Choose the right DNS record type for a given scenario (A, AAAA, CNAME, MX, TXT, SRV).
- Describe the HTTP request/response cycle and list common methods and status codes.
- Compare HTTP/1.1, HTTP/2, and HTTP/3 in terms of multiplexing, head-of-line blocking, and transport.
- Walk through the TLS 1.3 handshake (1-RTT and 0-RTT).
- Explain why SNI exists and how it enables virtual hosting.
- Implement a WebSocket upgrade from HTTP.
- Diagnose CORS errors and explain the same-origin policy.
