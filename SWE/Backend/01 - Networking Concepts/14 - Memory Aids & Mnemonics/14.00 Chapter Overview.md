##  Learning Outcomes

After this chapter you should be able to:

- Recall the IPv4 class boundaries, default masks, and reserved addresses from memory.
- Recite the subnetting flow ("Classy Friends Visit Small Gateways") and the VLSM "Big Fish Eat First" rule.
- Reproduce the fragmentation recipe ("Don't Make Networking Terrifying") and the per-fragment fields ("PLOM").
- List Cisco default Administrative Distances from memory.
- Recall the OSI 7 layers using "Please Do Not Throw Sausage Pizza Away."

##  How to Use This Chapter

1. **Read the mnemonic.** Understand what it represents.
2. **Close the note.** Try to recite the mnemonic and explain each element.
3. **Open the note.** Check your answer. Repeat until perfect.
4. **Apply it.** Solve a practice problem using the mnemonic.

The night before an exam, just re-read this chapter.
