# 14.03 — Routing Protocols Memory Tricks

> [!abstract> AD, Loops, OSPF Areas, BGP Attributes
> Routing protocols have lots of numbers and rules. These mnemonics lock in the Cisco Administrative Distance defaults, RIP's four loop-prevention mechanisms, OSPF's area/router roles, and BGP's message types.

---

##  Administrative Distance — Default Values

| Source | Default AD |
| :--- | :-: |
| Directly Connected | 0 |
| Static | 1 |
| EIGRP (internal) | 90 |
| IGRP | 100 |
| OSPF | 110 |
| IS-IS | 115 |
| RIP | 120 |
| EIGRP (external) | 170 |
| iBGP | 200 |
| Unreachable | 255 |

### Mnemonic
> "**Connect Direct, Static, EIGRP, IGRP, OSPF, IS-IS, RIP**"
>
> ADs in order: 0, 1, 90, 100, 110, 115, 120.

Or remember the three most common: **0, 1, 110, 120** (connected, static, OSPF, RIP).

### The Rule
> "**AD picks the source; metric picks the path within the source.**"
>
> Lower AD = more trusted.

##  RIP Loop Prevention — Four Mechanisms

```text
Split Horizon       — don't advertise route back where learned
Poison Reverse      — advertise failed route as metric 16
Hold-Down Timer     — 60s lock after unreachable (Cisco)
Max Hop = 16        — count-to-infinity cap
```

### Mnemonic
> "**Some People Hate Deadlocks**"
>
> → **S**plit Horizon, **P**oison Reverse, **H**old-Down, (max hop = 16)

### Timers
| Timer | Default | Purpose |
| :--- | :-: | :--- |
| Update | 30s | Send full table to neighbors |
| Invalid | 180s | Mark route as unreachable |
| Hold-Down | 60s (Cisco) / 180s (RFC) | Ignore worse-metric updates |
| Flush | 240s | Permanently remove the route |

> "30 / 180 / 60 / 240 — Update / Invalid / Hold-Down / Flush"

##  RIP Update Logic — The Four Rules

1. **New route** → install
2. **Better metric (different neighbor)** → replace
3. **Same neighbor** → always overwrite (even if worse)
4. **Worse metric (different neighbor)** → discard

### Mnemonic
> "**New Better Same Worse**"
>
> Install / Replace / Overwrite / Discard

### The Trap
Rule 3 trips everyone: if the **same neighbor** sends a worse metric, you must overwrite. The neighbor is the authoritative source for that route.

##  OSPF — Areas and Router Types

### OSPF Areas
> "**0 is the Backbone**" — all areas connect to Area 0.

Area types from most-restricted to least:
1. **Normal** — receives all LSAs
2. **Stub** — no type 5 (external); default route injected
3. **Totally Stubby** (Cisco) — no type 3, 4, 5; only intra-area + default
4. **NSSA** — like stub but can originate external (type 7)
5. **Totally NSSA** (Cisco) — combines Totally Stubby + NSSA

### Router Types
> "**IR, BR, ABR, ASBR**"

- **IR (Internal Router)** — all interfaces in one area
- **BR (Backbone Router)** — at least one interface in Area 0
- **ABR (Area Border Router)** — interfaces in multiple areas
- **ASBR (Autonomous System Boundary Router)** — imports external routes

### Mnemonic
> "**Internal routers stay home, Backbone routers touch Area 0, ABRs bridge areas, ASBRs bridge ASes.**"

> "**Hello DBD LSR LSU LSAck**"
>

| Type | Name | Purpose |
| :-: | :--- | :--- |
| 1 | Hello | Discover/maintain neighbors |
| 2 | DBD | Database Description — summarize LSDB |

##  BGP — Path Attributes and Decision Process

### The 10-Step Decision Process (Cisco)
1. Highest WEIGHT (local to router)
2. Highest LOCAL_PREF (AS-wide)
3. Locally originated
4. Shortest AS_PATH
5. Lowest ORIGIN code
6. Lowest MED
7. eBGP over iBGP
8. Oldest route
9. Lowest router ID

### Mnemonic
> "**W L O A O M E O R**"
>
> "**We Love Oranges Always, Oranges Make Everyone Outrun Rhinos**"

Or just remember: **WEIGHT → LOCAL_PREF → AS_PATH** — the three most commonly tuned.

### BGP Message Types
> "**O U N K**"
>
> "**Open, Update, Notification, Keepalive**"

| Type | Purpose |
| :-: | :--- |
| Open | Establish session |
| Update | Advertise or withdraw routes |
| Notification | Error + close session |
| Keepalive | Periodic "I'm alive" |

### BGP Ports and Timers
- TCP port **179**
- Hold time: **180s** (default)
- Keepalive: **60s** (default = hold/3)

##  Distance-Vector vs Link-State vs Path-Vector

| Family | Example | Algorithm | What's exchanged |
| :--- | :--- | :--- | :--- |
| Distance-Vector | RIP | Bellman-Ford | Routing tables (rumors) |
| Link-State | OSPF, IS-IS | Dijkstra (SPF) | Link states (topology) |
| Path-Vector | BGP | Best-path selection | Routes with AS_PATH |

### Mnemonic
> "**Distance = rumors, Link = map, Path = paper trail**"

##  OSPF Cost Formula

$$\text{Cost} = \frac{\text{Reference Bandwidth}}{\text{Interface Bandwidth}}$$

### Default Reference: 100 Mbps
| Interface | Cost |
| :--- | :-: |
| 10 Mbps | 10 |
| 100 Mbps | 1 |
| 1 Gbps | 1 (problem!) |
| 10 Gbps | 1 (problem!) |

### The Gigabit Bottleneck Fix
> "**auto-cost reference-bandwidth 10000**"
>
> Sets reference to 10 Gbps. Now 1 Gbps = cost 10, 10 Gbps = cost 1.

**Must be set on every router in the OSPF domain** — inconsistent reference bandwidths cause routing asymmetry.
