# 14.01 — IPv4 Subnetting Memory Tricks

> [!abstract> The Five Subnetting Topics
> The entire IPv4 subnetting chapter reduces to five topics: **Classes, FLSM, VLSM, Summarization, Gateway.** Remember them with: "**Classy Friends Visit Small Gateways**" → C → F → V → S → G.

```text
Country
 ├── Classes      ← Which neighborhood am I in?
 ├── FLSM         ← How do I split equally?
 ├── VLSM         ← How do I split efficiently?
 ├── Summarization ← How do I merge routes?
 └── Gateway      ← How do I leave my neighborhood?
```

---

##  Classful Addressing

### The Class Letters
- **A = Big** (16M hosts)
- **B = Medium** (65K hosts)
- **C = Small** (254 hosts)
- **D = Multicast**
- **E = Experimental

> "**ABC** = Networks; **DE** = Special."

### First-Octet Ranges — Memorize 4 Boundaries
The 5 classes are bounded by 4 numbers:
```
128, 192, 224, 240
```
- 1–126 → A (127 reserved for loopback)
- 128–191 → B
- 192–223 → C
- 224–239 → D
- 240–255 → E

Each boundary is half of what's left after the previous one. So: 128, then 128+64=192, then 192+32=224, then 224+16=240.

### Binary Staircase
The leading bits:
```
A: 0
B: 10
C: 110
D: 1110
E: 1111
```
Every new class adds one more `1`. Like a staircase.

### Default Masks
A = `/8`, B = `/16`, C = `/24`.
> "Add 8 every time. Like climbing stairs: 8, 16, 24."

##  Reserved Addresses — "The Celebrities"

| Address | Mnemonic |
| :--- | :--- |
| `127.x.x.x` (loopback) | "**127 = Me**" — the packet never leaves; talks to itself. |
| `255.255.255.255` (limited broadcast) | "**EVERYBODY!!!**" — every device hears it. |
| Host bits all 0 (network ID) | "**House Number = 0**" — the street itself, not a house. |
| Host bits all 1 (broadcast) | "**Everybody On This Street**" — broadcast for the subnet. |

##  FLSM Memory Trick

> "**Borrow Bits → Create Subnets → Less Hosts**"
>
> "More subnet bits = fewer host bits" — like stealing rooms from a house.

### The Formula
$$2^n \ge \text{required subnets}$$

Where $n$ = number of bits to borrow from the host portion.

### Fast FLSM Method
When you see a mask like `255.255.240.0`, immediately:
1. Write the third octet in binary: `240 = 11110000`.
2. Count the 1s: `4`.
3. Total prefix: `8 + 8 + 4 = /20`.

Done.

---

##  VLSM Memory Trick

> "**Big Fish Eat First**" — biggest subnet gets allocated first.
>
> Or: "Largest → Medium → Small → Tiny."

### Hosts → Prefix Quick Table (Memorize!)

| Hosts needed | h bits | Prefix | Block size |
| :-: | :-: | :-: | :-: |
| 2 | 2 | /30 | 4 |
| 6 | 3 | /29 | 8 |
| 14 | 4 | /28 | 16 |
| 30 | 5 | /27 | 32 |
| 62 | 6 | /26 | 64 |
| 126 | 7 | /25 | 128 |
| 254 | 8 | /24 | 256 |

Notice: hosts roughly halve each step. The pattern is $2^h - 2$.

### VLSM Allocation Trick
```
Largest Network → Next Available Address → Next Largest → ... → Smallest
```
Like filling boxes on a shelf. **No gaps, no overlap.**

### Golden Rule
$$\text{Usable hosts} = 2^h - 2 \ge \text{required hosts}$$

Find the smallest $h$ that satisfies this. Prefix = $32 - h$.

##  Summarization Memory Trick

> "**Subnetting Splits. Summarization Squashes.**"

### The Recipe
> "**B M C M**" → **B**inary, **M**atch, **C**ount, **M**ask.
>
> Pronounce: "Be My Classmate, Mate."

1. **B**inary — convert the changing octets to binary.
2. **M**atch — count the matching bits from left to right.
3. **C**ount — the matching bits = prefix length.
4. **M**ask — set the non-matching bits to 0 → summary address.

### Example Pattern
```
10 = 00001010
11 = 00001011
12 = 00001100
...
15 = 00001111
```
First 5 bits match (`00001`). So summary = `/21` (or whatever fits).

##  Gateway Memory Trick

> "**Gateway = Exit Door**"
>
> "A house cannot use an exit door located in another neighborhood."

### Same-Subnet Rule
$$\text{Host IP} \text{ AND } \text{Mask} = \text{Gateway IP} \text{ AND } \text{Mask}$$

If the two don't match, the gateway config is invalid.

### Exam Shortcut
When given a host IP and a gateway IP:
1. Compute both subnet IDs.
2. **Same subnet?** → Valid.
3. **Different subnets?** → Invalid.

That's the whole check.

##  The Story

If you reduce the entire subnetting chapter to a story:

> First identify the class, then split the network equally (FLSM) or efficiently (VLSM), merge routes when possible (summarization), and make sure every host's exit door (gateway) is inside its own neighborhood.
