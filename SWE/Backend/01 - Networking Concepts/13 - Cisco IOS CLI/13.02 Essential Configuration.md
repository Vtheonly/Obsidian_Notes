# 13.02 — Essential Configuration

> [!abstract> Day-One Setup
> The minimal configuration every Cisco router or switch needs: hostname, privileged-mode password, console security, remote access (SSH/VTY), interface IP addressing. Plus the universal "undo" rule: prefix any command with `no` to remove it.

---

##  Hostname and Basic Setup

```cisco
Router> enable
Router# configure terminal
Router(config)# hostname R1
R1(config)# enable secret MySecurePassword5678
R1(config)# no ip domain-lookup
R1(config)# banner motd # Authorized access only! #
```

- `hostname R1` — changes the device name (immediately reflected in the prompt).
- `enable secret` — sets the privileged EXEC password (encrypted in the config). **Use `secret`, not `password`** — the latter is stored in clear text.
- `no ip domain-lookup` — prevents the router from trying to DNS-resolve typos (otherwise, a typo like `ena` makes the router wait for a DNS timeout).
- `banner motd` — sets the "message of the day" shown at login.

---

##  Console Port Security

```cisco
R1(config)# line console 0
R1(config-line)# password ConsolePassword1234
R1(config-line)# login
R1(config-line)# logging synchronous
R1(config-line)# exec-timeout 5 0
R1(config-line)# exit
```

- `password` + `login` — require a password for console access.
- `logging synchronous` — keeps console messages from interrupting your typing (they appear after the prompt, not in the middle of your input).
- `exec-timeout 5 0` — auto-logout after 5 minutes 0 seconds of inactivity. Replace with `0 0` to disable (not recommended for production).

##  Remote Access (SSH)

Modern best practice: use SSH, not Telnet. Setting up SSH requires a hostname, a domain name, and an RSA key:

```cisco
R1(config)# ip domain-name example.com
R1(config)# crypto key generate rsa modulus 2048
! (when prompted, confirm key size)

R1(config)# username admin privilege 15 secret AdminPassword9012
R1(config)# aaa new-model
R1(config)# aaa authentication login default local

R1(config)# line vty 0 15
R1(config-line)# transport input ssh
R1(config-line)# login local
R1(config-line)# exec-timeout 5 0
R1(config-line)# exit
```

- `crypto key generate rsa` — generates the RSA keypair used by SSH. The modulus should be ≥ 2048 for modern security.
- `username ... privilege 15 secret ...` — creates a local user with full privileges.
- `aaa new-model` + `aaa authentication login default local` — use the local user database for login.
- `transport input ssh` — allow only SSH (not Telnet). Use `transport input ssh telnet` if you must allow both.
- `login local` — use the local user database (configured above).

### Legacy Telnet (don't use in production)
```cisco
R1(config)# line vty 0 4
R1(config-line)# password TelnetPassword
R1(config-line)# login
R1(config-line)# exit
```

Telnet is unencrypted — anyone sniffing the network sees the password. Use only for isolated lab networks.

##  Interface Configuration

```cisco
! Ethernet interface
R1(config)# interface fastethernet 0/0
R1(config-if)# description LAN link to access switch
R1(config-if)# ip address 192.168.1.254 255.255.255.0
R1(config-if)# no shutdown
R1(config-if)# exit

! Serial WAN interface (DCE side requires clock rate)
R1(config)# interface serial 0/0/0
R1(config-if)# description WAN to R2
R1(config-if)# ip address 10.0.0.1 255.255.255.252
R1(config-if)# clock rate 56000
R1(config-if)# no shutdown
R1(config-if)# exit
```

- `description` — free-text annotation. Always add descriptions; future-you will thank you.
- `ip address A B` — set IP and mask (use full mask, not CIDR).
- `no shutdown` — interfaces default to "shutdown" state; you must explicitly enable them.
- `clock rate 56000` — only on DCE side of a serial link (back-to-back serial in lab). DTE side doesn't need it.

### Layer 2 Switch Port (no IP)
```cisco
Switch(config)# interface fastethernet 0/1
Switch(config-if)# description Server port
Switch(config-if)# switchport mode access
Switch(config-if)# switchport access vlan 10
Switch(config-if)# spanning-tree portfast
Switch(config-if)# spanning-tree bpduguard enable
Switch(config-if)# no shutdown
Switch(config-if)# exit
```

- `switchport mode access` — make this an end-host port (not a trunk).
- `switchport access vlan 10` — assign to VLAN 10.
- `spanning-tree portfast` — skip STP listening/learning, go straight to forwarding (saves 30s).
- `spanning-tree bpduguard enable` — if a switch is plugged in (BPDU arrives), error-disable the port.

##  The Universal Undo Rule

To remove or negate any configuration command, prefix it with `no`:

```cisco
! Shutdown an interface
R1(config-if)# shutdown

! Bring it back up
R1(config-if)# no shutdown

! Remove an IP address
R1(config-if)# no ip address

! Remove a static route
R1(config)# no ip route 192.168.2.0 255.255.255.0 10.0.0.2

! Remove a hostname (revert to default)
R1(config)# no hostname R1
Router(config)#
```

This works for nearly every config command. If you can configure it, you can `no` it.

##  Saving the Configuration

```cisco
! Save running-config to startup-config (persist across reboot)
R1# copy running-config startup-config
! Or the shorter, classic shortcut:
R1# write memory
! Or just:
R1# wr

! Restore startup-config to running-config (overwrite current changes)
R1# copy startup-config running-config

! Erase the startup-config entirely (factory reset, step 1 of 2)
R1# write erase
! Then reload:
R1# reload
```

##  Other Common Configuration Tasks

### Set the clock
```cisco
R1# clock set 14:30:00 27 June 2026
R1(config)# ntp server pool.ntp.org
R1(config)# ntp update-calendar
```

### Configure DHCP server
```cisco
R1(config)# ip dhcp excluded-address 192.168.1.1 192.168.1.10
R1(config)# ip dhcp pool LAN_POOL
R1(dhcp-config)# network 192.168.1.0 255.255.255.0
R1(dhcp-config)# default-router 192.168.1.1
R1(dhcp-config)# dns-server 8.8.8.8 1.1.1.1
R1(dhcp-config)# lease 7
R1(dhcp-config)# exit
```

### Configure a static default route
```cisco
R1(config)# ip route 0.0.0.0 0.0.0.0 203.0.113.1
```
