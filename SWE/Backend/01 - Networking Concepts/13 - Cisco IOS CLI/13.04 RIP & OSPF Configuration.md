# 13.04 — RIP & OSPF Configuration

> [!abstract> Routing Protocol Snippets
> Copy-paste-ready configurations for RIPv2 and single-area OSPF on Cisco IOS. Plus the common options you'll need: passive interfaces, route summarization, default route propagation, and reference bandwidth tuning.

---

##  RIPv2 Configuration

```cisco
R1(config)# router rip
R1(config-router)# version 2
R1(config-router)# no auto-summary
R1(config-router)# network 192.168.1.0
R1(config-router)# network 10.0.0.0
R1(config-router)# passive-interface fastethernet 0/0
R1(config-router)# default-information originate
R1(config-router)# exit
```

### What each line does

| Command | Purpose |
| :--- | :--- |
| `router rip` | Enter RIP router config mode |
| `version 2` | Use RIPv2 (required for VLSM and classless routing) |
| `no auto-summary` | Disable automatic classful summarization at network boundaries (required for VLSM) |
| `network 192.168.1.0` | Enable RIP on interfaces whose IP is in `192.168.1.0/24` |
| `network 10.0.0.0` | Enable RIP on interfaces in `10.0.0.0/8` (note: classful spec!) |
| `passive-interface fa0/0` | Don't send RIP updates out fa0/0 (but still advertise its subnet to other RIP neighbors) |
| `default-information originate` | Advertise a default route to RIP neighbors |

> [!warning] `network` uses classful boundaries
> The `network` command in RIP uses classful boundaries — `network 10.10.10.0` is interpreted as `network 10.0.0.0`. This is historical. You can't enable RIP on a single /24 of a Class A network with one `network` command; you must enable it on the entire Class A and then use `passive-interface` on the interfaces where you don't want RIP.

##  OSPF Configuration

```cisco
R1(config)# router ospf 1
R1(config-router)# router-id 1.1.1.1
R1(config-router)# auto-cost reference-bandwidth 10000
R1(config-router)# network 192.168.1.0 0.0.0.255 area 0
R1(config-router)# network 10.0.0.0 0.0.0.3 area 0
R1(config-router)# passive-interface fastethernet 0/0
R1(config-router)# default-information originate
R1(config-router)# exit
```

### What each line does

| Command | Purpose |
| :--- | :--- |
| `router ospf 1` | Start OSPF process ID 1 (locally significant; doesn't need to match on neighbors) |
| `router-id 1.1.1.1` | Set the OSPF router ID manually (else: highest loopback IP, then highest interface IP) |
| `auto-cost reference-bandwidth 10000` | Set reference to 10 Gbps (so 1G = cost 10, 10G = cost 1) — **must match on all OSPF routers** |
| `network 192.168.1.0 0.0.0.255 area 0` | Run OSPF on interfaces matching `192.168.1.0/24` (wildcard mask!), put them in area 0 |
| `network 10.0.0.0 0.0.0.3 area 0` | Same for `10.0.0.0/30` (the WAN link) |
| `passive-interface fa0/0` | Don't send OSPF hellos out fa0/0 (still advertise its subnet) |
| `default-information originate` | Advertise a default route to OSPF neighbors |

> [!warning] Wildcard masks, not subnet masks
> OSPF `network` commands use **wildcard masks** (inverse of subnet masks). A `/24` subnet mask `255.255.255.0` becomes wildcard `0.0.0.255`. A `/30` mask `255.255.255.252` becomes wildcard `0.0.0.3`. Easy way to convert: subtract each octet from 255.

### Multi-Area OSPF Example

```cisco
R1(config)# interface loopback0
R1(config-if)# ip address 1.1.1.1 255.255.255.255
R1(config-if)# exit

R1(config)# router ospf 1
R1(config-router)# router-id 1.1.1.1
R1(config-router)# auto-cost reference-bandwidth 10000
! Backbone interfaces
R1(config-router)# network 10.0.0.0 0.0.0.3 area 0
! Area 1 interfaces
R1(config-router)# network 192.168.1.0 0.0.0.255 area 1
R1(config-router)# area 1 range 192.168.0.0 255.255.0.0
R1(config-router)# exit
```

The `area 1 range 192.168.0.0 255.255.0.0` command summarizes Area 1's routes before advertising them into Area 0 — shrinking the backbone's LSDB.

### OSPF on a Broadcast Network (DR/BDR election)

```cisco
! Influence DR election by setting priority
R1(config)# interface fastethernet 0/0
R1(config-if)# ip ospf priority 200    ! higher priority → preferred for DR
R1(config-if)# ip ospf cost 10         ! manual cost override
R1(config-if)# ip ospf hello-interval 5    ! non-default hello (must match on all neighbors)
R1(config-if)# ip ospf dead-interval 20    ! default = 4 × hello
R1(config-if)# exit
```

> [!warning] Hello/dead timers must match
> OSPF routers won't form an adjacency if their hello/dead timers don't match. Default is 10s/40s on broadcast and point-to-point, 30s/120s on NBMA. If you change one router, change all neighbors.

##  Common Options for Both Protocols

### Passive interface default (Cisco best practice)
Make every interface passive by default, then un-passive the ones with neighbors:
```cisco
R1(config-router)# passive-interface default
R1(config-router)# no passive-interface serial 0/0/0
```

This prevents accidentally sending routing updates out access ports where no router exists.

### Route redistribution (RIP  OSPF)
```cisco
R1(config)# router ospf 1
R1(config-router)# redistribute rip metric 100 subnets

R1(config)# router rip
R1(config-router)# redistribute ospf 1 metric 2
```

`metric 100` sets the seed metric for OSPF-learned routes injected into RIP. `subnets` is required to redistribute non-classful routes.

### Authentication
```cisco
! OSPF MD5 authentication
R1(config)# interface s0/0/0
R1(config-if)# ip ospf message-digest-key 1 md5 MySecretKey
R1(config-if)# ip ospf authentication message-digest
```
