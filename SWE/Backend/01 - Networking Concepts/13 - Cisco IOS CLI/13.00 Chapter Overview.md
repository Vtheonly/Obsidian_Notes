#  Chapter 13 — Cisco IOS CLI Reference

> [!abstract> Chapter Goal
> A practical command-line reference for Cisco IOS — the operating system that runs most enterprise routers and switches. Cover the EXEC mode hierarchy, essential configuration commands, diagnostic show commands, and RIP/OSPF configuration snippets.

This chapter consolidates the previously scattered CLI notes into a single reference. Use it as a quick lookup while labbing in Packet Tracer or GNS3.

##  Learning Outcomes

After this chapter you should be able to:

- Navigate between Cisco IOS modes (User EXEC → Privileged EXEC → Global Config → submodes).
- Configure hostnames, passwords, console/VTY access, and interface IPs.
- Save and restore configurations (running-config  startup-config).
- Use `show` commands to verify interface status, routing tables, ARP cache, and CAM table.
- Configure RIPv2 with no auto-summary and passive interfaces.
- Configure single-area OSPF with proper reference bandwidth.
