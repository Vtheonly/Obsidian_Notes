#  Chapter 06 — ARP & Address Resolution

> [!abstract] Chapter Goal
> Understand how a host or router finds the **MAC address** corresponding to an IP address on the same subnet. ARP (Address Resolution Protocol) is the bridge that connects Layer 3 (IP) to Layer 2 (Ethernet). Without ARP, no IP packet could ever be put into an Ethernet frame.

##  Learning Outcomes

After this chapter you should be able to:

- Explain why ARP is necessary and why it crosses L2/L3.
- Trace an ARP request from a host that doesn't have a cache entry through the broadcast/reply/unicast sequence.
- Decode an ARP packet from a hex dump.
- Distinguish ARP cache (host) from CAM table (switch).
- Explain gratuitous ARP and ARP probing and when each is used.
- Identify the security risks of ARP (spoofing, cache poisoning) and the mitigations (DAI, static entries).
- Describe how IPv6 NDP replaces ARP and why.
