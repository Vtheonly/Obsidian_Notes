#  Chapter 07 — IP Routing

> [!abstract] Chapter Goal
> Understand how a router makes a forwarding decision for every packet it sees. We cover the routing table structure, the **Administrative Distance** hierarchy, the **Longest Prefix Match** rule, static routing configuration, and the step-by-step pipeline a router runs on every packet from ingress to egress.

##  Learning Outcomes

After this chapter you should be able to:

- Read a `show ip route` output and explain every column.
- Given multiple routes to the same destination, pick the one the router will install.
- Given a destination IP and a routing table, apply Longest Prefix Match to pick the route.
- Configure static routes (next-hop, exit-interface, default) on Cisco IOS.
- Trace a packet from router ingress to egress, listing each processing step.
- Decide between static and dynamic routing for a given scenario.
