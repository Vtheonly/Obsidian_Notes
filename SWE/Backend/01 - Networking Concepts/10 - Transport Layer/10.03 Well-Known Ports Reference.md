# 10.03 — Well-Known Ports Reference

> [!abstract] Memorize These
> The most commonly tested ports. Memorize the bold ones; the rest are useful for troubleshooting. Full list at https://www.iana.org/assignments/service-names-port-numbers.

---

##  Mnemonics

> "**22** SSH, **23** Telnet — SSH is *older*? No! 22 came after 23, but SSH replaced Telnet, so they're adjacent."
>
> "**25** SMTP sends; **110** POP3 picks up; **143** IMAP interacts." — three mail protocols in order of complexity.
>
> "**53** DNS — three letters, three of five (53 ≈ 5+3=8 ≈ DNS is eight). Or just memorize it."
>
> "**80** HTTP, **443** HTTPS — 443 is 80 × 5 + 43, or just memorize it."
>
> "**161** SNMP, **162** SNMP trap — one apart, like management and alert."

##  Quick References

### `/etc/services` on Unix
```bash
grep -i http /etc/services
# http            80/tcp    www    www-http    # WorldWideWeb HTTP
# https          443/tcp           # http protocol over TLS/SSL
```

### Get a port's assigned service in Python
```python
import socket
print(socket.getservbyport(443))  # 'https'
print(socket.getservbyport(22, 'tcp'))  # 'ssh'
```

### List open ports on your machine
```bash
# Linux/macOS
ss -tlnp        # TCP listening
ss -ulnp        # UDP listening
netstat -tlnp   # older alternative
lsof -i -P -n   # per-process view

# Windows
netstat -ano | findstr LISTENING
```
