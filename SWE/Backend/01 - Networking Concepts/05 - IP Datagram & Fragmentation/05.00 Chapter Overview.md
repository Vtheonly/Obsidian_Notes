#  Chapter 05 — IP Datagram & Fragmentation

> [!abstract] Chapter Goal
> Open up an IPv4 packet and look at every header field. Then learn what happens when a packet is too big for the next link's MTU — **fragmentation**: the math, the recipe, and the pitfalls. This chapter is arithmetic-heavy; the [[14 - Memory Aids & Mnemonics/14.02 IP Fragmentation Memory Tricks|fragmentation mnemonics]] are essential.

---

##  Learning Outcomes

After this chapter you should be able to:

- Identify every field in the IPv4 header and explain its purpose.
- Compute header length in bytes given the IHL value, and vice versa.
- Given a packet size, header size, and MTU, compute the number of fragments, each fragment's length, offset, and MF flag.
- Explain why the fragment offset is measured in 8-byte blocks.
- Explain why fragmentation is bad and how PMTUD avoids it.
- Diagnose "packet too big" issues from ICMP Type 3 Code 4 messages.
