#  Chapter 02 — Reference Models (OSI & TCP/IP)

> [!abstract] Chapter Goal
> Understand *why* networks are designed as layered stacks, internalize the **7-layer OSI model** and the **4-layer TCP/IP (DoD) model**, and learn how data is **encapsulated** as it flows down the stack and **decapsulated** as it flows up. Everything from Chapter 3 onward assumes you have this mental model.

The layered model is the single most important abstraction in networking. It is what lets Wireshark, a switch, a router, a firewall, and an application all reason about the same packet *at different levels of detail* without conflicting with each other.

##  Learning Outcomes

After this chapter you should be able to:

- Explain *why* a layered model is preferable to a monolithic one.
- List all 7 OSI layers from memory and give one protocol example per layer.
- Map the 7 OSI layers onto the 4 TCP/IP layers.
- Given a Wireshark capture, identify which layer each header belongs to.
- Describe what happens to a packet at each layer as it travels from application to physical wire.
- Distinguish between same-layer communication (logical) and adjacent-layer communication (physical).
