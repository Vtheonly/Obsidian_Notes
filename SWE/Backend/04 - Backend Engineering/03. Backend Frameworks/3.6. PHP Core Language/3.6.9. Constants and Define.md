# 3.6.9. Constants and Define

> [!info] A constant in PHP is an identifier for a value that cannot be changed or undefined during script execution. Constants are the right tool for values that should never vary — database credentials, API keys, configuration flags, mathematical constants. PHP offers two ways to define them (`define()` and `const`), provides a set of magic constants whose value depends on where they are used, and as of PHP 8.1 supports `enum` as the modern alternative to "constant with constraints."

## 1. What a Constant Is

A constant is an identifier (a name) for a simple value, much like a variable, with two crucial differences. First, once a constant is defined, its value **cannot be changed or undefined** during the execution of the script. Second, by convention, constant names are always written in **UPPERCASE**.

Constants are extremely useful for storing values that should never change: database credentials, API keys, configuration settings, mathematical constants, status codes. They are globally accessible from any scope without needing the `global` keyword, which makes them ideal for values that every function in the application needs to see.

### 1.1 Constants vs C Preprocessor Macros

In languages like C, a preprocessor runs *before* the compiler and does a simple "find and replace" on macros. A C `#define PI 3.14159` literally replaces every occurrence of `PI` with the text `3.14159` before compilation. PHP is different. PHP is an interpreted language, so when the `define` statement is executed at runtime, it creates a named entry in a special memory table. When you later reference `PI`, PHP looks up its value in that table at that moment.

The key takeaway is that PHP constants are a runtime feature, not a pre-compilation text-replacement macro. They are true, immutable named values within the PHP engine itself.

## 2. The Two Ways to Define Constants

### 2.1 The `define()` Function

This is the traditional and most flexible way to define a constant. The syntax is `define(string $name, mixed $value, bool $case_insensitive = false)`. The `$name` parameter is the name of the constant as a string. The `$value` can be any scalar (integer, float, string, boolean) or an array. The `$case_insensitive` parameter is **deprecated and removed in PHP 8.0** — historically it allowed the constant to be called in any case (`PI`, `pi`, `Pi`), but this is no longer supported. Always stick to the uppercase convention.

The defining feature of `define()` is that it executes at **runtime**. You can use it anywhere — inside `if` statements, loops, or functions. This allows for **conditional creation** of constants, which `const` cannot do.

```php
<?php
define('SITE_NAME', 'My Awesome Website');
define('MAX_UPLOADS', 5);

if ($userIsLoggedIn) {
    define('USER_STATUS', 'Logged In');
} else {
    define('USER_STATUS', 'Guest');
}

echo 'Welcome to ' . SITE_NAME;
echo 'Your status is: ' . USER_STATUS;
```

### 2.2 The `const` Keyword

This is a more modern approach, introduced in PHP 5.3. It is generally preferred for its cleaner syntax and slightly better performance, but it has one major limitation. The `const` keyword must be used in the **top-level scope** or within a **class definition**. You cannot use `const` inside conditional blocks like `if` statements or loops — it is resolved at compile-time, so its value must be known and static.

```php
<?php
const DATABASE_HOST = 'localhost';
const DATABASE_USER = 'root';

// This would cause a Fatal Error:
// if (true) {
//   const MY_CONSTANT = 'error';
// }

echo 'Connecting to ' . DATABASE_HOST . ' as user ' . DATABASE_USER;
```

### 2.3 Comparison

| Feature | `define()` | `const` |
| ------- | ---------- | ------- |
| Syntax | `define('NAME', 'value');` | `const NAME = 'value';` |
| Scope | Global | Global or class-level |
| When defined | Runtime | Compile-time |
| Conditional | Yes — can be inside `if` | No — must be at top level |
| Value type | Scalars and arrays | Scalars and arrays (since PHP 5.6) |
| Readability | More verbose | Cleaner and more modern |

The best practice is to use `const` by default for global or class constants, and use `define()` only when you need to create a constant conditionally based on some runtime logic. For example, a configuration loader that reads environment variables might use `define()` because the values are only known at runtime.

## 3. Class Constants and Visibility

Since PHP 7.1, class constants support visibility modifiers — `public`, `protected`, and `private` — just like methods and properties. A `public` class constant is accessible from outside the class, a `protected` constant is accessible only inside the class and its subclasses, and a `private` constant is accessible only inside the defining class.

```php
<?php
class Configuration
{
    public    const VERSION = '1.0.0';
    protected const DB_HOST = 'localhost';
    private   const SECRET  = 'abracadabra';

    public function revealSecret(): string
    {
        return self::SECRET; // Accessible from inside the class
    }
}

echo Configuration::VERSION;        // Works (public)
// echo Configuration::DB_HOST;     // Error (protected)
// echo Configuration::SECRET;      // Error (private)
echo Configuration::revealSecret(); // Works (public method returns private constant)
```

Class constants are referenced via the `::` operator (e.g., `Configuration::VERSION`) using `self::` inside the class or `static::` for late static binding.

## 4. Magic Constants

PHP provides a number of predefined "magic" constants whose values change depending on where they are used. They are written with double underscores on both sides. They are technically not real constants because their value depends on context, but they are documented alongside constants.

| Magic constant | Description |
| -------------- | ----------- |
| `__LINE__` | The current line number in the file |
| `__FILE__` | The full path and filename of the file |
| `__DIR__` | The directory of the file (equivalent to `dirname(__FILE__)`) |
| `__FUNCTION__` | The name of the function |
| `__CLASS__` | The name of the class (including namespace) |
| `__METHOD__` | The name of the class method |
| `__NAMESPACE__` | The name of the current namespace |
| `__TRAIT__` | The name of the trait |

These are incredibly useful for debugging and logging:

```php
<?php
function log_error(string $message): void {
    error_log("Error on line " . __LINE__ . " in file " . __FILE__ . ": " . $message);
}

log_error("Something went wrong.");
// Logs: Error on line 4 in file /var/www/html/index.php: Something went wrong.
```

## 5. Enums — The Modern Alternative (PHP 8.1+)

PHP 8.1 introduced `enum`, which is the modern alternative to a set of related constants. Enums let you define a closed set of values that the type system understands, rather than a bag of unrelated constants that the type system treats as plain strings or integers.

```php
<?php
enum HttpStatus: int {
    case Ok              = 200;
    case NotFound        = 404;
    case InternalError   = 500;
}

function respond(HttpStatus $status): void {
    http_response_code($status->value);
    // ...
}

respond(HttpStatus::NotFound); // Type-safe, no typos possible
```

The advantage over constants is type safety. A function that takes `HttpStatus` cannot accidentally receive `42` or `"not_found"`. The IDE can autocomplete the cases, the static analyser can verify exhaustiveness in `match` expressions, and the enum's `cases()` method lets you iterate over all valid values. For any "constant that represents one of a closed set of options" scenario, prefer an enum.

## Summary

Constants in PHP are immutable, globally accessible named values, written in UPPERCASE by convention. They are defined either with `define()` (runtime, can be conditional) or with the `const` keyword (compile-time, cleaner, top-level only). Class constants support visibility modifiers since PHP 7.1. Magic constants like `__FILE__` and `__LINE__` provide context-dependent values useful for logging. PHP 8.1 enums are the modern, type-safe alternative for any constant that represents one of a closed set of options.
