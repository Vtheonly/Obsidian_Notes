# 3.6.15. Indexed Arrays

> [!info] An indexed array is the simplest collection type in PHP — a list of values addressed by integer position. The twist is that PHP's arrays are not really "indexed arrays" in the C or Java sense; they are ordered hash maps that can serve as indexed arrays, associative arrays, and lists all at once. This note covers creation, access, modification, the essential functions (`count`, `sort`, `array_push`, `array_pop`), and the modern `array_is_list()` function (PHP 8.1) that distinguishes a true list from a generic array.

## 1. PHP Arrays Are Ordered Hash Maps

In most languages, "indexed array" and "associative array" are different data types backed by different memory layouts. In C, an array is a contiguous block of memory; a hash map is a separate structure. In PHP, there is only one array type, and it is implemented as an ordered hash map. The same array can have integer keys, string keys, mixed keys, and even gaps in the integer sequence — PHP handles them all with the same code path.

This single design decision explains why PHP arrays can be used as lists, dictionaries, stacks, queues, sets, and trees without any ceremony. It also explains why a PHP array that looks like `[0 => 'a', 1 => 'b', 2 => 'c']` is internally a hash map with integer-like keys, not a contiguous memory block. The implication for performance is that array access is O(1) average (hash map lookup), but cache locality is worse than a true C array.

## 2. Creating Indexed Arrays

There are two common ways to create an indexed array in PHP. The modern short syntax (`[]`) is preferred.

### 2.1 Short Array Syntax (Modern, Recommended)

This method uses square brackets `[]` and is the standard in modern PHP code. It is clean and easy to read.

```php
<?php
$ninjas = ['Shaun', 'Yoshi', 'Mario'];
$scores = [20, 30, 15, 45, 50];
```

### 2.2 The `array()` Construct (Older)

This is the original way to create arrays. You will see it in older PHP projects. It functions identically to the short syntax.

```php
<?php
$ninjas = array('Shaun', 'Yoshi', 'Mario');
$scores = array(20, 30, 15, 45, 50);
```

There is no functional difference between the two — choose the short syntax for new code, but recognise the long form when you see it in legacy code.

## 3. Accessing Elements by Index

To get a single value out of the array, you use its name followed by the desired index inside square brackets `[]`. In PHP (and most programming languages), array indexes **start at 0**, not 1. The first item is at index `0`, the second is at index `1`, and so on.

For our `$ninjas = ['Shaun', 'Yoshi', 'Mario'];` array:

| Index | 0 | 1 | 2 |
| ----- | - | - | - |
| **Value** | 'Shaun' | 'Yoshi' | 'Mario' |

```php
<?php
$ninjas = ['Shaun', 'Yoshi', 'Mario'];

echo $ninjas[0]; // Shaun
echo $ninjas[2]; // Mario

echo 'The winner is ' . $ninjas[1] . '!'; // The winner is Yoshi!

// What happens if you access an index that doesn't exist?
// echo $ninjas[3]; // Notice (PHP 7) or Warning (PHP 8): Undefined array key 3
```

Trying to access an invalid index generates a Notice in PHP 7 and a Warning in PHP 8 — PHP 8 promoted many silent failures to warnings. The script continues, but it is a sign that the code has a bug.

## 4. Modifying and Adding Elements

You can also use the bracket syntax to change existing values or add new ones.

### 4.1 Modifying an Existing Element

To change a value, assign a new value to it at its specific index.

```php
<?php
$ninjas = ['Shaun', 'Yoshi', 'Mario'];
$ninjas[2] = 'Luigi';
echo $ninjas[2]; // Luigi
```

### 4.2 Adding a New Element to the End

To add a new element to the *end* of an array, use empty square brackets `[]`. PHP will automatically find the next available integer key (which is the maximum integer key plus one).

```php
<?php
$ninjas = ['Shaun', 'Yoshi', 'Mario'];
$ninjas[] = 'Peach';
echo $ninjas[3]; // Peach
```

## 5. Useful Functions for Indexed Arrays

### 5.1 `count()` — Array Size

The `count()` function returns the total number of elements in an array.

```php
<?php
$ninjas = ['Shaun', 'Yoshi', 'Mario', 'Peach'];
echo 'There are ' . count($ninjas) . ' ninjas.'; // There are 4 ninjas.
```

### 5.2 `print_r()` and `var_dump()` — Debugging

You cannot use `echo` to display an entire array; it will only show the word "Array" (and a Notice in PHP 8+). To inspect the full contents for debugging, use `print_r()` or `var_dump()`, wrapped in `<pre>` tags for readability in a browser. See [[3.6.6. Echo Print and PrintR]] for the differences.

```php
<?php
$ninjas = ['Shaun', 'Yoshi', 'Mario'];
$ninjas[1] = 'Browser';
$ninjas[]  = 'Toad';

echo '<pre>';
print_r($ninjas);
echo '</pre>';
```

Output:

```text
Array
(
    [0] => Shaun
    [1] => Browser
    [2] => Mario
    [3] => Toad
)
```

### 5.3 `sort()`, `rsort()`, `usort()`

`sort()` sorts an array in place, replacing existing keys with new sequentially numbered keys. This is appropriate for indexed arrays where the keys do not matter. `rsort()` sorts in reverse. `usort()` accepts a comparison function for custom ordering.

```php
<?php
$scores = [45, 20, 30, 15, 50];
sort($scores);
print_r($scores); // [15, 20, 30, 45, 50]

// Custom sort: descending by length of string
$names = ['Luigi', 'Mario', 'Peach'];
usort($names, fn($a, $b) => strlen($b) <=> strlen($a));
print_r($names); // ['Luigi', 'Peach', 'Mario']
```

Note that `sort()` reindexes the array — if you had keys `0, 1, 2, 5, 7`, after `sort()` they become `0, 1, 2, 3, 4`. To preserve keys, use `asort()` (ascending, preserves values' keys) or `ksort()` (sorts by key).

### 5.4 `array_push()` and `array_pop()`

`array_push($arr, $val1, $val2, ...)` appends one or more values to the end of an array, modifying it in place and returning the new count. `array_pop($arr)` removes and returns the last element. For a single element, the `$arr[] = $val` syntax is preferred over `array_push()` — it is faster because it avoids the function call overhead.

```php
<?php
$stack = [];
array_push($stack, 'a', 'b', 'c');   // $stack is ['a', 'b', 'c']
$last = array_pop($stack);            // $last is 'c', $stack is ['a', 'b']
$stack[] = 'd';                       // preferred for single element
```

### 5.5 `array_unshift()` and `array_shift()`

These work on the *beginning* of the array. `array_unshift()` prepends one or more values, **re-indexing** all numeric keys (an O(n) operation). `array_shift()` removes and returns the first element, also re-indexing. These are slow on large arrays because every element must be moved.

### 5.6 Reference Table

| Function | Action | Returns | Re-indexes? |
| -------- | ------- | ------- | ------------ |
| `count($arr)` | Count elements | int | No |
| `sort($arr)` | Sort ascending in place | bool (true) | Yes |
| `rsort($arr)` | Sort descending in place | bool (true) | Yes |
| `usort($arr, $fn)` | Sort with comparison function | bool (true) | Yes |
| `array_push($arr, $vals)` | Append to end | New count | No |
| `array_pop($arr)` | Remove from end | Removed element | No |
| `array_unshift($arr, $vals)` | Prepend to start | New count | Yes |
| `array_shift($arr)` | Remove from start | Removed element | Yes |
| `array_reverse($arr)` | Return reversed copy | New array | Yes |
| `array_slice($arr, $offset, $len)` | Extract a portion | New array | Yes |
| `array_merge($a, $b)` | Combine arrays | New array | Yes |
| `in_array($val, $arr)` | Check if value exists | bool | No |
| `array_search($val, $arr)` | Find value's key | key or false | No |

## 6. `array_is_list()` (PHP 8.1)

Because PHP arrays are general-purpose hash maps, there is no built-in way to distinguish "this array is a true sequential list" from "this array has string keys and gaps." PHP 8.1 added `array_is_list()`, which returns `true` if and only if the array's keys are exactly `0, 1, 2, ..., count-1` in order.

```php
<?php
array_is_list([]);                  // true
array_is_list(['a', 'b', 'c']);     // true
array_is_list([1 => 'a', 0 => 'b']); // false — wrong order
array_is_list(['name' => 'Alice']);  // false — string keys
array_is_list([0 => 'a', 2 => 'c']); // false — gap at key 1
```

This function is useful when you need to serialise an array as JSON — `json_encode()` produces a JSON array (`[...]`) for list-shaped arrays and a JSON object (`{...}`) for non-list arrays. If your code expects one or the other, validating with `array_is_list()` first prevents surprises.

## 7. Production Pitfalls

A few mistakes recur with PHP indexed arrays. The first is forgetting that array indices start at 0 — `for ($i = 1; $i <= count($arr); $i++)` skips the first element and reads one past the end. The correct form is `for ($i = 0; $i < count($arr); $i++)`. The second is using `array_unique()` and assuming the result is a list — `array_unique` preserves keys, so the result has gaps. Wrap it in `array_values()` to get a clean list back. The third is using `array_search()` without strict comparison: `array_search('abc', [0, 1, 2])` returns `0` if found at position 0, but `0` is falsy, so `if (array_search($x, $arr))` skips the first element. Use `if (array_search($x, $arr) !== false)` or, better, `in_array($x, $arr, true)` with strict comparison.

## Summary

PHP's indexed arrays are actually ordered hash maps that serve as lists, sets, stacks, and queues with the same syntax. They are created with `[]` (modern) or `array()` (legacy), indexed from 0, and modified with bracket syntax. The essential functions are `count`, `sort`/`rsort`/`usort` (with `asort`/`ksort` variants that preserve keys), `array_push`/`array_pop`, and `array_unshift`/`array_shift`. PHP 8.1's `array_is_list()` distinguishes true sequential lists from generic arrays, which is particularly useful before JSON serialisation. Watch out for off-by-one indexing, `array_unique`'s key-preservation behaviour, and the falsy-zero trap in `array_search`.
