# 3.6.17. Multi-Dimensional Arrays

> [!info] A multi-dimensional array is an array whose elements are themselves arrays. The most common and useful pattern is an indexed array of associative arrays — an ordered list of complex records, like a list of blog posts or a list of users with multiple fields each. This note covers creating nested arrays, drilling into them with chained square brackets, looping through them, and the stack/queue operations (`array_push`, `array_pop`, `array_unshift`, `array_shift`) that make PHP arrays act as versatile data structures.

## 1. Creating and Visualising Multi-Dimensional Arrays

A multi-dimensional array is an array where each element is another array. The most common real-world shape is an indexed array of associative arrays, which represents a list of records — each row in a database result set naturally maps to this structure.

```php
<?php
$blogs = [
    ['title' => 'mario party',        'author' => 'mario', 'content' => 'lorem', 'likes' => 30],
    ['title' => 'mario kart cheats',  'author' => 'toad',  'content' => 'lorem', 'likes' => 25],
    ['title' => 'zelda hidden chests','author' => 'link',  'content' => 'lorem', 'likes' => 50],
];
```

This can be visualised as a table where the outer array holds the rows (indexed `0`, `1`, `2`) and each inner associative array holds the data for that row.

| Index | Value (Associative Array) |
| ----- | ------------------------- |
| `0` | `['title' => 'mario party', 'author' => 'mario', ...]` |
| `1` | `['title' => 'mario kart cheats', 'author' => 'toad', ...]` |
| `2` | `['title' => 'zelda hidden chests', 'author' => 'link', ...]` |

This shape — list of records — is what every database query returns when fetched in "associative" mode. It is also the natural shape for configuration trees, JSON payloads, and any structured data that comes from a remote API.

## 2. Accessing Nested Data

To get a specific piece of data, you "drill down" through the layers using multiple sets of square brackets `[]`. The first set selects the outer array's element (the row), and the second selects the inner array's element (the specific data point).

The syntax is `$array[outer_index][inner_key]`:

```php
<?php
echo $blogs[0]['title'];   // mario party
echo $blogs[2]['author'];  // link
```

For deeper nesting, you simply add more brackets: `$array[a][b][c]`. The pattern extends to any depth.

## 3. Looping Through Multi-Dimensional Arrays

The `foreach` loop is the perfect tool for displaying all the data from a structure like this. The outer loop walks each row, and the variable holds each inner associative array in turn.

```php
<?php
echo "<h1>Blog Posts</h1>";
echo "<ul>";

foreach ($blogs as $blog) {
    echo "<li>";
    echo "<h3>" . htmlspecialchars($blog['title'])   . "</h3>";
    echo "<p>By: "   . htmlspecialchars($blog['author']) . "</p>";
    echo "</li>";
}

echo "</ul>";
```

For deeper structures, nest `foreach` loops:

```php
<?php
$departments = [
    'Engineering' => [
        'Alice' => ['role' => 'Lead',  'salary' => 120000],
        'Bob'   => ['role' => 'Junior','salary' =>  65000],
    ],
    'Sales' => [
        'Carol' => ['role' => 'Director', 'salary' => 130000],
        'Dave'  => ['role' => 'Rep',      'salary' =>  70000],
    ],
];

foreach ($departments as $deptName => $employees) {
    echo "<h2>$deptName</h2><ul>";
    foreach ($employees as $name => $info) {
        echo "<li>$name — {$info['role']} (\${$info['salary']})</li>";
    }
    echo "</ul>";
}
```

### 3.1 The Security Note — Always Escape

Notice the use of `htmlspecialchars()` on every value that comes from the data. This is a critical security function. If a user can submit data that contains HTML or JavaScript (like `<script>...`), and you `echo` it directly to the page, the browser will execute that code. This is called a **Cross-Site Scripting (XSS)** attack. The golden rule: **always** wrap data in `htmlspecialchars()` before echoing it to a page if that data could have come from an external source. See [[3.6.18. htmlspecialchars and Output Escaping]] for the full explanation.

## 4. Practical Examples

Multi-dimensional arrays are the right structure whenever you have nested or tabular data. Three common shapes appear in real code.

### 4.1 A Matrix — A Grid of Numbers

A 2D matrix is an indexed array of indexed arrays. Useful for game boards, image processing, and graph algorithms.

```php
<?php
$matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9],
];

echo $matrix[1][2]; // 6 (row index 1, col index 2)
```

### 4.2 A Table of Records — Database Result Set

The list-of-associative-arrays shape is what `PDO::FETCH_ASSOC` returns from a database query. It is the universal shape for tabular data in PHP.

```php
<?php
$users = [
    ['id' => 1, 'name' => 'Alice', 'email' => 'alice@example.com'],
    ['id' => 2, 'name' => 'Bob',   'email' => 'bob@example.com'],
    ['id' => 3, 'name' => 'Carol', 'email' => 'carol@example.com'],
];

foreach ($users as $user) {
    echo "User #{$user['id']}: {$user['name']} ({$user['email']})<br>";
}
```

### 4.3 A Configuration Tree

A deeply nested associative array is the natural shape for a configuration file. Many frameworks use this — Laravel's `config()` helper returns exactly this kind of structure.

```php
<?php
$config = [
    'database' => [
        'default' => 'mysql',
        'connections' => [
            'mysql' => [
                'host'     => 'localhost',
                'database' => 'myapp',
                'username' => 'root',
                'password' => 'secret',
            ],
        ],
    ],
    'cache' => [
        'default' => 'redis',
        'stores' => [
            'redis' => ['host' => '127.0.0.1', 'port' => 6379],
        ],
    ],
];

echo $config['database']['connections']['mysql']['host']; // localhost
```

## 5. Modifying the Array Structure

PHP arrays can be dynamically extended and reshaped. The most common operations mimic stacks (LIFO) and queues (FIFO).

### 5.1 Stack Operations (Adding/Removing from the End)

A stack works like a stack of plates. You add to the top and remove from the top — in PHP arrays, this is the **end** of the array.

```php
<?php
// Adding to the end ([] or array_push)
$blogs[] = ['title' => 'castle party', 'author' => 'peach', 'likes' => 100];

$tasks = ['code', 'eat'];
array_push($tasks, 'sleep', 'repeat'); // ['code', 'eat', 'sleep', 'repeat']

// Removing from the end (array_pop) — returns the removed element
$popped = array_pop($blogs);  // holds the 'castle party' array
                              // $blogs is back to 3 elements
```

### 5.2 Queue Operations (Adding/Removing from the Beginning)

A queue works like a line at a store. The first one in is the first one out — this involves manipulating the **beginning** of an array.

```php
<?php
// Adding to the beginning (array_unshift) — re-indexes all numeric keys
$line = ['mario', 'luigi'];
array_unshift($line, 'toad'); // ['toad', 'mario', 'luigi']

// Removing from the beginning (array_shift) — returns the removed element
$first = array_shift($line);  // 'toad'; $line is ['mario', 'luigi']
```

### 5.3 Removing From Anywhere — `unset()`

While the functions above work on the ends of an array, `unset()` can remove an element from any position using its key or index. It does **not** re-index the array, so removing from the middle of an indexed array leaves a gap.

```php
<?php
unset($blogs[1]); // Removes the 'mario kart cheats' blog post.
                  // $blogs is now [0 => ..., 2 => ...] — gap at key 1
```

If you need to close the gap, wrap the result in `array_values($blogs)` to reindex.

### 5.4 Summary Table

| Function | Action | Position | Returns | Re-indexes? |
| -------- | ------ | -------- | ------- | ------------ |
| `array_push()` | Add | End | New element count | No |
| `array_pop()` | Remove | End | The removed element | No |
| `array_unshift()` | Add | Beginning | New element count | Yes |
| `array_shift()` | Remove | Beginning | The removed element | Yes |
| `unset($arr[$key])` | Remove | Anywhere | (none) | No |

The re-indexing cost on `array_unshift` and `array_shift` is O(n), because every element after the affected position must be renumbered. For large arrays where you need to add or remove from the front frequently, consider `SplDoublyLinkedList` or `Ds\Deque` (from the `ext-ds` extension) for O(1) operations at both ends.

## 6. Production Pitfalls

A few mistakes recur with multi-dimensional arrays. The first is forgetting to escape output: a deeply nested value like `$user['profile']['bio']` is easy to `echo` without `htmlspecialchars()`, and if the bio contains a `<script>` tag, you have an XSS vulnerability. The second is assuming `array_map` recurses into nested arrays — it does not. Use `array_walk_recursive()` for that. The third is silent key typos: `$user['naame']` returns `null` with a Notice/Warning in PHP 8, but if display_errors is off, the bug manifests later as a downstream null value. The fix is strict typing at the data layer (typed classes instead of arrays) or static analysis with PHPStan/Psalm.

## Summary

Multi-dimensional arrays are PHP's universal structure for nested data. The most common shape — indexed array of associative arrays — is what every database query returns and what every JSON payload decodes to. Access nested values with chained square brackets like `$arr[0]['name']`. Loop with `foreach`, escaping every output value with `htmlspecialchars()` to prevent XSS. Use `array_push`/`array_pop` for stack behaviour and `array_unshift`/`array_shift` for queue behaviour, but remember that the latter two re-index the array (O(n) cost). For large or fixed-shape data, prefer typed classes over deeply nested arrays.
