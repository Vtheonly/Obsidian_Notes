#  Open Source Contributions & Pull Requests

**Your complete guide to making your first open source contribution.**

Welcome! If you've never contributed to open source or created a Pull Request, you're in the right place. This vault will take you from zero knowledge to confidently submitting your first PR.

---

##  How to Use This Vault

1. **Start at the top** of the learning path and work through each note in order
2. **Follow the links** at the bottom of each note to navigate to the next topic
3. **Use the backlinks** in the right sidebar to see what references each note
4. **Bookmark** the [[Pre-PR Checklist]] — you'll use it every time you submit a PR
5. **Reference** the [[Glossary]] whenever you encounter an unfamiliar term
