# 7. Interval DP

## 1. Concept Overview

Interval DP solves problems on subarrays defined by (l, r): **Matrix Chain Multiplication**, **Burst Balloons**, **Palindrome Partitioning**, and **Merge Stones**.

## 2. Why It Matters

Interval DP is essential for problems where the optimal solution for a range depends on how it's split. The O(n^3) complexity is typical.
