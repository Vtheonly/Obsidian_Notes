# 10. Bitmask DP

## 1. Concept Overview

Bitmask DP uses a bitmask as part of the state: **Traveling Salesman**, **Assignment Problems**, and **Visit All Nodes**.

## 2. Why It Matters

Bitmask DP is the standard approach for small-set problems (n <= 20). The state includes which items have been used.
