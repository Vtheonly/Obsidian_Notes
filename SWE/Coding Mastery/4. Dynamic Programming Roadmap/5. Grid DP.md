# 5. Grid DP

## 1. Concept Overview

Grid DP solves problems on 2D grids: **Unique Paths**, **Minimum Path Sum**, **Dungeon Game**, **Cherry Pickup**, **Triangle**, and **Falling Path Sum**.

## 2. Why It Matters

Grid DP is common in robotics, game pathfinding, and image processing. The 2D state and neighbor transitions are the key patterns.
