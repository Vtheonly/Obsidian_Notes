# 1. Maximum Subarray

## 1. Problem Description

Find the contiguous subarray with the largest sum.

## 2. Expected Input

Array of integers.

## 3. Expected Output

Maximum subarray sum.

## 4. Constraints

n >= 1

## 5. Examples

| Input | Output |
|---|---|
| `[-2,1,-3,4,-1,2,1,-5,4]` | `6` |

## 8. Brute-Force Approach

Check all subarrays.

## 9. Optimized Solution

```python
def maxSubArray(nums):
    best = current = nums[0]
    for x in nums[1:]:
        current = max(x, current + x)
        best = max(best, current)
    return best
```
