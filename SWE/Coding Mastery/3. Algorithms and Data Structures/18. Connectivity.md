# 18. Connectivity

## 1. Concept Overview

Connectivity algorithms determine how nodes are connected in a graph. The main types are: **Connected Components**, **SCC (Kosaraju)**, **Tarjan SCC**, **Bridges**, and **Articulation Points**.

## 2. Why It Matters

Connectivity is fundamental for understanding graph structure: finding strongly connected components, critical edges (bridges) and vertices (articulation points), and graph biconnectivity.

## 3. Formal Definition

**Connected components**: maximal sets of mutually reachable nodes (undirected). **SCC**: maximal sets where every node can reach every other (directed). **Bridges**: edges whose removal disconnects the graph. **Articulation points**: vertices whose removal disconnects the graph.

## 5. Naive Formulation

For each pair, check connectivity: O(V * (V + E)).

## 6. Optimized Formulation

Kosaraju: two DFS passes (one forward, one on the reversed graph). Tarjan: single DFS with low-link values. Bridges/articulation points: DFS with discovery times and low-link values.

## 7. Step-by-Step Derivation

1. Connected components: BFS/DFS from each unvisited node.
2. SCC: Kosaraju (two DFS) or Tarjan (one DFS).
3. Bridges: DFS, an edge (u, v) is a bridge if `low[v] > disc[u]`.
4. Articulation points: a node u is an articulation point if `low[v] >= disc[u]` for any child v.

## 8. Reference Implementation

```python
# Kosaraju's SCC
def kosaraju(n, adj):
    # Step 1: DFS, record finish order
    visited = [False] * n
    order = []
    def dfs(u):
        visited[u] = True
        for v in adj[u]:
            if not visited[v]:
                dfs(v)
        order.append(u)
    for i in range(n):
        if not visited[i]:
            dfs(i)
    
    # Step 2: Reverse graph
    radj = [[] for _ in range(n)]
    for u in range(n):
        for v in adj[u]:
            radj[v].append(u)
    
    # Step 3: DFS in reverse finish order
    visited = [False] * n
    sccs = []
    for u in reversed(order):
        if not visited[u]:
            comp = []
            stack = [u]
            visited[u] = True
            while stack:
                x = stack.pop()
                comp.append(x)
                for v in radj[x]:
                    if not visited[v]:
                        visited[v] = True
                        stack.append(v)
            sccs.append(comp)
    return sccs

# Find Bridges (Tarjan)
def find_bridges(n, adj):
    disc = [-1] * n
    low = [-1] * n
    bridges = []
    timer = [0]
    
    def dfs(u, parent):
        disc[u] = low[u] = timer[0]
        timer[0] += 1
        for v in adj[u]:
            if disc[v] == -1:
                dfs(v, u)
                low[u] = min(low[u], low[v])
                if low[v] > disc[u]:
                    bridges.append((u, v))
            elif v != parent:
                low[u] = min(low[u], disc[v])
    
    for i in range(n):
        if disc[i] == -1:
            dfs(i, -1)
    return bridges
```

## 9. Complexity Analysis

| Resource | Complexity | Reason |
|---|---|---|
| Time | O(V + E) | Each vertex and edge visited once or twice. |
| Space | O(V) | Discovery and low arrays. |

## 10. Worked Examples

### 10.1 Find SCCs
Kosaraju or Tarjan to identify strongly connected components.

### 10.2 Find Critical Edges
Bridges algorithm finds edges whose removal disconnects the graph.

### 10.2 Find Critical Vertices
Articulation points algorithm finds vertices whose removal disconnects.

## 11. Variants and Extensions

- **Biconnected components**: components without articulation points.
- **2-SAT**: reduces to SCC.
- **Online bridge finding**: dynamic graphs.

## 12. Common Mistakes

- Confusing low-link with discovery time.
- Not handling the parent edge correctly (skip parent in low update).
- Forgetting to initialize discovery to -1.

## 15. Key Takeaways

- Connected components: BFS/DFS, O(V + E).
- SCC: Kosaraju (two DFS) or Tarjan (one DFS).
- Bridges: edge with `low[v] > disc[u]`.
- Articulation points: node with `low[v] >= disc[u]`.
- Low-link tracks the earliest reachable ancestor.
