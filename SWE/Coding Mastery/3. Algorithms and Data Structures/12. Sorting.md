# 12. Sorting

## 1. Concept Overview

Sorting arranges elements in a specified order. The main algorithms are: **Merge Sort**, **Quick Sort**, **Heap Sort**, **Counting Sort**, **Radix Sort**, **Bucket Sort**, **TimSort**, and **IntroSort**.

## 2. Why It Matters

Sorting is a fundamental operation that enables binary search, removes duplicates, groups related elements, and simplifies many algorithms. Python's `sort()` uses TimSort (a hybrid of merge sort and insertion sort).

## 3. Formal Definition

A sorting algorithm rearranges elements such that for consecutive elements `a[i]` and `a[i+1]`, `a[i] <= a[i+1]` (ascending). Comparison-based sorts have a lower bound of `O(n log n)`. Non-comparison sorts (counting, radix) can achieve `O(n)` under specific conditions.

## 5. Naive Formulation

Bubble sort, selection sort, insertion sort: O(n^2).

## 6. Optimized Formulation

Merge sort: divide and conquer, O(n log n). Quick sort: partition around a pivot. Heap sort: use a max-heap. Counting sort: count occurrences of each value.

## 7. Step-by-Step Derivation

1. Simple O(n^2) sorts: bubble, selection, insertion.
2. Divide and conquer: merge sort (split, sort, merge).
3. Partition-based: quick sort (pivot, partition, recurse).
4. Heap-based: heap sort (build heap, extract max).
5. Non-comparison: counting sort (for small integer ranges).

## 8. Reference Implementation

```python
# Merge Sort
def merge_sort(arr):
    if len(arr) <= 1:
        return arr
    mid = len(arr) // 2
    left = merge_sort(arr[:mid])
    right = merge_sort(arr[mid:])
    return merge(left, right)

def merge(left, right):
    result = []
    i = j = 0
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            result.append(left[i]); i += 1
        else:
            result.append(right[j]); j += 1
    result.extend(left[i:])
    result.extend(right[j:])
    return result

# Quick Sort
def quick_sort(arr):
    if len(arr) <= 1:
        return arr
    pivot = arr[len(arr) // 2]
    left = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    return quick_sort(left) + middle + quick_sort(right)

# Python's built-in (TimSort)
arr.sort()  # in-place
sorted(arr)  # returns new list
```

## 9. Complexity Analysis

| Resource | Complexity | Reason |
|---|---|---|
| Time | O(n log n) for comparison-based | Comparison lower bound: O(n log n). |
| Space | O(n) for merge sort, O(log n) for quick sort | Auxiliary space for merge sort. |

## 10. Worked Examples

### 10.1 Sort by Custom Key
`arr.sort(key=lambda x: (x.age, x.name))` sorts by age, then name.

### 10.2 Topological Sort
Use Kahn's algorithm (BFS on in-degrees) for DAGs.

### 10.3 External Sort
For data larger than memory: sort chunks, then merge.

## 11. Variants and Extensions

- **TimSort**: hybrid merge + insertion, used in Python/Java.
- **IntroSort**: quick sort that switches to heap sort on deep recursion.
- **Parallel sort**: divide data across cores.

## 12. Common Mistakes

- Using O(n^2) sorts for large data.
- Not considering stability (equal elements' order).
- Forgetting that Python's `sort` is stable.
