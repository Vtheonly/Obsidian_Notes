# 8. Disjoint Structures

## 1. Concept Overview

Disjoint Set Union (DSU), also called Union-Find, is a data structure for maintaining a collection of disjoint sets and supporting union (merge two sets) and find (which set contains this element?) operations.

## 2. Why It Matters

DSU is essential for Kruskal's MST algorithm, connectivity queries, cycle detection, and dynamic connectivity problems. It provides near-constant-time operations with path compression and union by rank.

## 3. Formal Definition

DSU maintains a forest where each tree represents a set. The root of each tree is the set's representative. `find(x)` returns the root of x's tree. `union(x, y)` merges the trees containing x and y.

## 5. Naive Formulation

Naive: linked list per set. `find` is O(1) but `union` is O(n). Or: naive tree, `find` is O(n) in the worst case (degenerate tree).

## 6. Optimized Formulation

Path compression flattens the tree during `find` by making every node point directly to the root. Union by rank attaches the shorter tree to the taller one.

## 7. Step-by-Step Derivation

1. Naive: parent array, `find` walks to root. O(n) worst.
2. Union by rank: attach shorter to taller. O(log n).
3. Path compression: flatten during find. O(alpha(n)) amortized, where alpha is the inverse Ackermann function (effectively constant).

## 8. Reference Implementation

```python
class DSU:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n
    
    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])  # path compression
        return self.parent[x]
    
    def union(self, x, y):
        px, py = self.find(x), self.find(y)
        if px == py:
            return False  # already same set
        if self.rank[px] < self.rank[py]:
            px, py = py, px
        self.parent[py] = px
        if self.rank[px] == self.rank[py]:
            self.rank[px] += 1
        return True
```

## 9. Complexity Analysis

| Resource | Complexity | Reason |
|---|---|---|
| Time | O(alpha(n)) per operation | Near-constant due to inverse Ackermann function. |
| Space | O(n) | Parent and rank arrays. |

## 10. Worked Examples

### 10.1 Cycle Detection
For each edge (u, v), if `find(u) == find(v)`, there's a cycle. Otherwise, `union(u, v)`.

### 10.2 Kruskal's MST
Sort edges by weight. Add an edge if it connects two different sets.

### 10.3 Connected Components
After all unions, the number of distinct roots is the number of components.

## 11. Variants and Extensions

- **Rollback DSU**: supports undoing the last union.
- **Weighted DSU**: tracks differences between elements, not just equality.
- **Dynamic connectivity**: supports deletions (much harder).

## 12. Common Mistakes

- Forgetting path compression (operations become O(log n) or worse).
- Using union without rank (tree can become degenerate).
- Not checking if elements are already in the same set before union.
