# OWASP Top 10 (2021)

## The top 10

| # | Risk | Description |
|---|---|---|
| A01 | Broken Access Control | Users can access resources they shouldn't. |
| A02 | Cryptographic Failures | Weak encryption, plaintext storage. |
| A03 | Injection | SQL, NoSQL, command injection. |
| A04 | Insecure Design | Missing security controls in design. |
| A05 | Security Misconfiguration | Default configs, verbose errors. |
| A06 | Vulnerable & Outdated Components | Old deps with CVEs. |
| A07 | Identification & Authentication Failures | Weak passwords, no MFA, session bugs. |
| A08 | Software & Data Integrity Failures | Unsigned updates, insecure deserialization. |
| A09 | Security Logging & Monitoring Failures | Can't detect or respond to attacks. |
| A10 | Server-Side Request Forgery (SSRF) | Server makes requests to attacker-controlled URLs. |

## Project Connection

The project violates most of these:
- **A01** — role checked once at login, never re-validated.
- **A02** — unsalted SHA-256 for passwords.
- **A03** — SQL injection in `getMaxId` (table/column concatenation).
- **A04** — no security design at all.
- **A05** — hardcoded `system/rootroot` credentials, verbose error messages.
- **A06** — old ojdbc8, pdfbox with CVEs, deprecated javax.mail.
- **A07** — no rate limiting, no MFA, password hash displayed in update form.
- **A08** — deprecated HTMLWorker, no integrity checks.
- **A09** — `System.out.println` instead of structured logging; no audit log.
- **A10** — N/A (desktop app).
