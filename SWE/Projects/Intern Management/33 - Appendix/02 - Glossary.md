# Appendix — Glossary, Bibliography, Index

## Glossary

A quick reference for every term used in the vault.

| Term | Definition |
|---|---|
| **ACID** | Atomicity, Consistency, Isolation, Durability — transaction properties. |
| **Argon2id** | OWASP-recommended password hashing function (memory-hard). |
| **Async** | Non-blocking; the caller doesn't wait for completion. |
| **Auto-commit** | JDBC mode where each statement is its own transaction. |
| **BCrypt** | Password hashing function (cost-factor based). |
| **Bean Validation** | JSR-380, declarative validation via annotations. |
| **Big-O** | Notation for algorithmic complexity. |
| **B-tree** | Balanced tree index used by databases. |
| **Bulkhead** | Resilience pattern; limits concurrent calls. |
| **Caffeine** | High-performance Java cache. |
| **Characterization test** | Test that locks in current behavior before refactoring. |
| **Circuit Breaker** | Resilience pattern; fails fast when a service is down. |
| **Clean Architecture** | Uncle Bob's architecture; dependencies point inward. |
| **CLOB** | Character Large Object (Oracle). |
| **Composition root** | The place where dependencies are wired. |
| **Connection pool** | Cache of DB connections (HikariCP). |
| **CQRS** | Command Query Responsibility Segregation. |
| **CSRF** | Cross-Site Request Forgery. |
| **CVE** | Common Vulnerabilities and Exposures. |
| **CWE** | Common Weakness Enumeration. |
| **DDD** | Domain-Driven Design (Evans). |
| **Decorator** | Pattern; adds behavior without subclassing. |
| **Denormalization** | Deliberate violation of normal forms for performance. |
| **DI** | Dependency Injection. |
| **DIP** | Dependency Inversion Principle. |
| **DRY** | Don't Repeat Yourself. |
| **DTO** | Data Transfer Object. |
| **Enterprise Edition** | Oracle's full-featured (paid) edition. |
| **EXPLAIN PLAN** | SQL command showing the execution plan. |
| **ExecutorService** | Java thread pool. |
| **FXML** | XML markup for JavaFX UIs. |
| **Flyway** | Database migration tool. |
| **Function** | An interface with one method (java.util.function). |
| **GDPR** | General Data Protection Regulation (EU). |
| **God Class** | Anti-pattern; a class with too many responsibilities. |
| **GoF** | Gang of Four (Design Patterns book). |
| **HikariCP** | JDBC connection pool. |
| **HTTP** | HyperText Transfer Protocol. |
| **HTTPS** | HTTP over TLS. |
| **IOT** | Index-Organized Table (Oracle). |
| **ISP** | Interface Segregation Principle. |
| **IoC** | Inversion of Control. |
| **JEP** | JDK Enhancement Proposal. |
| **JFR** | JDK Flight Recorder. |
| **JIT** | Just-In-Time compiler. |
| **JLS** | Java Language Specification. |
| **JPA** | Jakarta Persistence API. |
| **JPMS** | Java Platform Module System. |
| **JWT** | JSON Web Token. |
| **KISS** | Keep It Simple, Stupid. |
| **LSP** | Liskov Substitution Principle. |
| **Materialized View** | Pre-computed query result stored as a table. |
| **Maven** | Java build tool. |
| **MFA** | Multi-Factor Authentication. |
| **Micrometer** | Metrics facade for Java. |
| **Mockito** | Java mocking framework. |
| **MVCC** | Multi-Version Concurrency Control. |
| **MVC** | Model-View-Controller. |
| **MVVM** | Model-View-ViewModel. |
| **N+1** | Anti-pattern; N+1 queries instead of 1. |
| **Normal form** | Rule for schema design (1NF, 2NF, 3NF, BCNF). |
| **OAuth2** | Delegated authorization framework. |
| **OCP** | Open-Closed Principle. |
| **OIDC** | OpenID Connect (identity on OAuth2). |
| **Optional<T>** | Java container for nullable values. |
| **ORM** | Object-Relational Mapping. |
| **OWASP** | Open Web Application Security Project. |
| **Partitioning** | Splitting a table into pieces. |
| **PII** | Personally Identifiable Information. |
| **PK** | Primary Key. |
| **Platform thread** | OS-managed thread (Java). |
| **Predicate<T>** | Function returning boolean. |
| **PreparedStatement** | Parameterized SQL statement. |
| **Prometheus** | Metrics collection system. |
| **RBAC** | Role-Based Access Control. |
| **Record** | Java 16+ immutable data class. |
| **Repository** | Pattern; collection-like interface for persistence. |
| **Resilience4j** | Java resilience library. |
| **REST** | Representational State Transfer. |
| **Retry** | Resilience pattern; try again on failure. |
| **Salt** | Random value added to a password before hashing. |
| **SCA** | Software Composition Analysis (dependency scanning). |
| **SCD** | Slowly Changing Dimension. |
| **Service Layer** | Pattern; use-case orchestration. |
| **ServiceLoader** | Java's SPI mechanism. |
| **SHA-256** | Cryptographic hash function (fast; not for passwords). |
| **SLF4J** | Simple Logging Facade for Java. |
| **Smart UI** | Anti-pattern; UI classes doing business logic. |
| **SOC 2** | Service Organization Control 2 (compliance). |
| **SPI** | Service Provider Interface. |
| **Spring** | Java application framework. |
| **Spring Boot** | Opinionated Spring. |

| **SRP** | Single Responsibility Principle. |
